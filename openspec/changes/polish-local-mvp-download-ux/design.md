# Design

## Scope

本变更只修补 M1 本地单用户下载器的可用性问题。它不新增登录、管理员、配额 UI、Cookie 托管、平台专用解析、AI 摘要、批量任务或生产化清理后台。

## Decisions

- URL 规范化放在前后端各一层：前端提升即时反馈，后端作为可信边界。
- 工作台只请求有限数量任务，并过滤 smoke/测试标题，避免测试数据占据用户主流程。
- 完整历史继续持久化在数据库中，由 `/tasks` 使用 ProTable 展示和筛选。
- 过期清理只删除对象存储文件，不删除任务记录；任务通过 `failure_code=retention_expired` 告知前端显示重试入口。
- 下载触发沿用后端签名代理 URL，前端使用浏览器导航触发附件下载，降低弹窗拦截风险。

## Non-Goals

- 不做后台定时清理服务。
- 不做批量删除、归档、标签、全文搜索或多用户历史管理。
- 不扩大下载平台能力或合规边界。
