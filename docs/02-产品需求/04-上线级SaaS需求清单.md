# 上线级 SaaS 需求清单

更新时间：2026-05-02

## 1. 上线定位

第一版上线目标是“小范围内测 SaaS”，不是完全开放的公开视频下载平台。系统需要在公网环境中可控运行，能够限制注册、限制资源消耗、处理滥用、解释失败原因，并保留清晰的合规边界。

当前确认的上线基线：

- 小范围内测 SaaS。
- 免费配额，不接入支付。
- 单机 Docker Compose + Nginx/TLS。
- 不做 AI 摘要、平台专用解析、Cookie 托管、支付会员、K8s。

## 2. 用户侧需求

上线级用户侧能力必须覆盖：

- 用户可以注册、登录、退出和查看当前账号状态。
- 注册入口支持关闭或邀请码控制。
- 用户可以在工作台粘贴公开授权视频 URL 并发起解析。
- 用户可以选择格式并创建下载任务。
- 用户可以查看任务列表、任务详情、任务状态和失败原因。
- 用户可以在任务完成后获取短期下载链接。
- 用户可以看到自己的免费配额、剩余额度和文件保留时间。
- 用户能理解合规边界：仅下载自己拥有版权、已获授权、公共领域或平台明确允许保存的内容。

## 3. 免费配额需求

第一版不接入支付，采用免费内测配额控制资源消耗。

配额项至少包括：

- 每日任务数。
- 单用户并发任务数。
- 单任务最大文件大小。
- 文件保留时间。
- 单用户总存储占用。
- 预签名下载链接有效期。

配额触发后必须返回用户可理解的错误，不允许只返回内部异常。

## 4. 管理员兜底需求

上线级 SaaS 必须具备最小管理员兜底能力：

- 查看用户列表和用户状态。
- 查看任务列表、任务状态、失败原因和资源占用。
- 调整单个用户的免费配额。
- 禁用异常用户。
- 查看疑似滥用任务。
- 处理用户反馈、滥用举报和内容投诉。

第一版管理员后台只服务安全和运营兜底，不做复杂运营、财务、团队权限或增长分析。

## 5. 安全与合规需求

上线前必须具备：

- 公网接口鉴权。
- 接口限流。
- 任务配额。
- 日志脱敏。
- 跨用户任务访问拦截。
- 文件过期清理。
- 私有对象存储。
- 服务条款、隐私说明、滥用举报和内容投诉边界。

禁止能力保持不变：

- 不规避 DRM。
- 不绕过付费墙。
- 不绕过会员限制。
- 不绕过平台访问控制。
- 不托管用户平台 Cookie。
- 不提供平台专用绕过能力。

## 6. 非目标范围

以下能力不进入第一版上线级 SaaS：

- 支付、订阅、会员套餐、发票。
- 团队、组织、复杂 RBAC。
- K8s、服务网格、多地域高可用。
- AI 摘要、问答、思维导图。
- 平台专用解析。
- Cookie 托管。
- 大规模批量抓取、频道订阅、自动同步。

## 7. 放行条件

第一版上线前必须满足：

- M1 本地 MVP 验收未完成项全部收尾。
- 注册控制和免费配额可用。
- 管理员能禁用用户和调整配额。
- 前端能展示配额、任务状态、失败原因和过期提示。
- 单机 Compose + Nginx/TLS 部署可跑通。
- API、前端、Worker、MinIO、PostgreSQL、Redis 均有健康检查或验证命令。
- 合规负向样例有明确验收记录。
