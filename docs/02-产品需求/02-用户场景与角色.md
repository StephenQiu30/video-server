# 用户场景与角色

更新时间：2026-05-02

## 目标用户

| 用户角色 | 核心诉求 | 优先级 |
| --- | --- | --- |
| 学习用户 | 下载公开课程、讲座、教程，并获取字幕或摘要 | 高 |
| 内容创作者 | 保存授权素材，提取音频、字幕、封面和元数据 | 高 |
| 自部署用户 | 在本地或私有环境中安全运行下载服务 | 高 |
| 普通临时用户 | 粘贴链接后快速下载公开视频 | 中 |
| 商业团队 | 账号、额度、审计、团队权限和成本控制 | 后置 |

## 核心场景

### 场景一：公开视频下载

用户粘贴公开视频链接，系统解析标题、封面、时长和可下载格式。用户选择清晰度后创建下载任务，任务完成后获取本地文件。

### 场景二：学习资料整理

用户下载公开课程或讲座，系统同时保留来源、字幕、封面和元数据。二期可加入 AI 摘要、章节大纲和问答。

### 场景三：授权素材归档

内容创作者保存自己拥有权限的素材，并使用统一文件命名、任务历史和标签进行归档。

### 场景四：私有化部署

开发者或团队在本地 Docker 环境中运行服务，避免将链接、素材和下载记录提交给第三方服务。

## 非目标用户

- 希望规避 DRM、付费墙或会员限制的用户。
- 希望批量抓取未授权内容的用户。
- 希望将产品用于盗版传播或账号共享的用户。
