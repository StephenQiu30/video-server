# MVP 需求清单

更新时间：2026-05-02

## 必做需求

- 链接输入与 URL 规范化。
- 平台识别与允许解析检查。
- 视频信息解析：标题、封面、时长、格式、清晰度、大小估计。
- 格式选择：视频、音频、清晰度、容器格式。
- 下载任务创建、查询、取消和重试。
- 下载进度展示：排队、解析中、下载中、合并中、完成、失败、取消。
- 文件输出与下载入口。
- 任务历史列表。
- 可理解的失败原因。
- 合规提示和基础使用声明。

## 暂不进入 MVP

- AI 摘要、问答和思维导图。
- 支付和会员。
- 团队账号与权限。
- RSS、频道订阅和自动同步。
- 用户平台 Cookie 托管。
- DRM、付费墙、会员内容和访问控制规避。
- 大规模批量抓取。

## MVP 验收底线

- 至少 3 个公开可访问样例能完成解析。
- 至少 1 个样例能完成下载、合并和文件获取。
- 常见失败原因能被明确展示。
- 技术栈和 UI 组件库已由项目负责人确认。
- 合规边界已进入产品文案和错误提示。
