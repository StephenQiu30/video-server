# 风险与合规边界

更新时间：2026-05-23

## 允许范围

- 用户拥有版权的内容。
- 用户已获得授权的内容。
- 公共领域或开放授权内容。
- 平台明确允许保存的公开视频。
- 用户自己上传并有权备份的内容。

## 禁止范围

- DRM 规避。
- 付费墙绕过。
- 会员专属内容绕过。
- 平台访问控制规避。
- 盗版传播。
- 未授权批量抓取。
- 账号共享或 Cookie 共享。

## Cookie 策略

首版不托管用户平台 Cookie。后续如果必须支持，需要先完成：

- 用户明确授权。
- 加密存储。
- 随时删除。
- 使用范围审计。
- 风险提示。
- 合规审查。

## 日志脱敏

日志不得保存完整敏感链接。以下参数必须脱敏：

- `token`
- `signature`
- `auth`
- `cookie`
- `key`
- `access_token`
- `session`

## 滥用治理

- 公网部署必须启用鉴权和限流。
- 下载任务必须有并发、大小和时长限制。
- 对高风险平台和内容类型默认拒绝或要求人工确认。
- 产品文案不得宣传“下载任意受保护内容”。
- 任务创建前必须拒绝明显无效、保留域名、内网地址或非公开可访问链接，避免后端成为探测内网或滥用平台的工具。

## 平台解析边界

后端平台画像用于识别 B 站、抖音、快手、小红书、西瓜视频、微博、TikTok、YouTube、Vimeo、Dailymotion 等平台，并为前端提供 `platform_id`、`platform_category` 和 `compliance_note`。

平台画像不代表以下能力：

- 不代表承诺支持所有视频或所有清晰度。
- 不代表绕过登录、验证码、会员、付费、版权、地区、DRM、私密或删除状态。
- 不代表托管用户平台 Cookie 或复用用户平台账号。
- 不代表允许批量抓取、搬运、二次分发或规避平台风控。

解析失败应按语义返回错误码：

| 错误码 | 处理边界 |
| --- | --- |
| `platform_restricted` | 访问受限，不继续尝试绕过 |
| `platform_rate_limited` | 平台限流或验证码，提示稍后重试 |
| `unsupported_platform` | 链接暂不支持或明显无效 |
| `platform_unavailable` | 平台临时不可访问或网络超时 |
| `parse_failed` | 公开视频解析失败，保留人工排查空间 |

## 服务条款与隐私

上线级 SaaS 内测前必须补齐：

- 服务条款：明确用户只能下载自己拥有版权、已获授权、公共领域或平台明确允许保存的内容。
- 隐私说明：说明账号信息、任务 URL、任务状态、文件元数据和日志的使用范围。
- 文件保留说明：说明下载结果的保留时间和过期删除策略。
- 滥用举报入口：允许用户或权利方提交滥用、侵权或误用反馈。
- 内容投诉处理边界：接到合理投诉后可以暂停任务、删除文件或禁用用户。

## 高风险内容处理

高风险平台、疑似受保护内容、私密链接、付费内容、会员内容或需要 Cookie 的内容默认拒绝或要求人工确认。系统不得为了提升“万能”能力而绕过这些边界。
