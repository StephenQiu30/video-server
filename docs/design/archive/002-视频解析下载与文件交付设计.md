## 1. 支持口径

只处理当前锁定 `yt-dlp` 版本中已启用的具名 extractor 所支持的公开单视频页面。禁用 Generic extractor、搜索别名、播放列表和不受控插件；没有人工确认的平台名单前，不在产品文案写“支持全部网站”。

不接受私网地址、用户信息 URL、file/ftp 等协议、Cookie、Authorization/Header、代理、浏览器凭证、文件路径或任意 yt-dlp/FFmpeg 参数。不绕过 DRM、付费墙、登录或地域授权。

## 2. Inspect 处理

1. 规范化并校验单个 HTTP(S) URL，拒绝超长 URL、用户名密码、非标准混淆地址和禁止端口。
2. 初始 DNS、每次重解析与重定向目标都拒绝 loopback、私网、链路本地、保留地址和云元数据网段；运行容器同时用网络策略禁止访问内部控制面。
3. yt-dlp 固定 `ignoreconfig`、`noplaylist`、具名 extractor 和超时，不读取主机配置，不启用运行时更新。
4. 输出必须是单视频；playlist/multi_video、live、DRM、需登录或无可用音视频组合均返回明确错误。
5. 保存 source 与标准化 format 选项，15 分钟有效；响应不含原始 URL、provider selector 或媒体直链。

Inspect 返回标题、平台、缩略图、时长和分辨率选项。标题与文件名视为不可信文本，统一长度限制、转义和文件名净化。

## 3. 分辨率标准化

UI 只选择服务端生成的 `format_id`。每个分辨率最多返回一个推荐选项：

1. 同高度优先选择同时含音视频且兼容性较好的单文件。
2. 没有合适单文件时，选择该高度的视频流与兼容音频流组合并标记 `requires_merge=true`。
3. 同档按 SDR、常见 codec/container、FPS、码率和估算大小稳定排序；最高推荐分辨率在最前。
4. 只视频、只音频、故事板、缩略图、重复档位不直接展示。

标准字段：`id`、`label`、`width`、`height`、`fps`、`container`、`video_codec`、`audio_codec`、`estimated_size_bytes|null`、`requires_merge`。大小只能是估算值，不作为下载成功条件。

## 4. 下载与合并

- 创建任务只接受仍有效且属于当前匿名会话的 `source_id + format_id`。
- Worker 从数据库读取原始 URL 密文和 provider format IDs，构造固定参数；不得接受客户端 selector。
- 下载写入 job 专属临时目录，最终文件写临时名，验证成功后原子 rename。
- 单文件直接验证；分离流由 FFmpeg stream copy/remux 合并，不重编码、不嵌入字幕或缩略图。
- ffprobe 至少验证一个视频流和一个音频流，读取容器/时长；随后计算 SHA-256 并上传 MinIO。
- 成功、失败、超时和进程退出都清理本地中间文件；只有 succeeded artifact 在 MinIO 保留 24 小时。

yt-dlp/FFmpeg 在 Worker 进程内受 OS 用户、目录、CPU/内存、时长和网络边界限制；任何命令调用都使用参数数组或受控 Python API，禁止 shell 拼接。

## 5. MinIO 文件交付

- Bucket 固定为私有 `video-artifacts`，禁止匿名 list/get；MVP 不建立第二种存储实现。
- object key 固定为 `jobs/{job_id}/{artifact_id}.{ext}`，不使用用户标题参与路径。
- 数据库保存 object key、净化文件名、MIME、大小、SHA-256 与过期时间，不保存媒体二进制。
- 文件地址接口先校验匿名会话归属、任务 succeeded 且未过期，再生成默认 15 分钟有效的预签名 GET URL。
- Web 只使用返回 URL，不拼接 Endpoint、Bucket 或 object key；文件内容不经过 API 转发。
- API 在 24 小时整立即拒绝新 URL；Worker 的单一 housekeeping 按配置周期清理已到期对象，MinIO 生命周期规则作为兜底。

## 6. 失败与重试

| 分类 | 例子 | 重试 |
| --- | --- | --- |
| 永久业务错误 | 不支持、DRM、需登录、格式失效、超限 | 否 |
| 瞬时外部错误 | 连接重置、上游 5xx | MVP 记为失败，由用户重新提交 |
| 媒体处理错误 | FFmpeg/ffprobe 失败、产物无音频 | 默认否 |
| 本地资源错误 | 空间不足、权限错误 | 否并告警 |

Worker 崩溃前未 ack 的 RabbitMQ 消息可被重新投递；消费端必须按 job 状态和唯一 artifact 约束幂等。业务失败不做自动重试，避免再建设重试队列。

## 7. Design Acceptance Criteria

| 编号 | 必须证明 | 实现后证据 |
| --- | --- | --- |
| `S002-DAC-01` | 受控公开样例能解析为稳定、无重复、含音频的分辨率选项 | 真实 yt-dlp 结果与标准化快照 |
| `S002-DAC-02` | 非 HTTP(S)、私网/重定向绕过、Generic、播放列表、登录、DRM 和超限全部安全拒绝 | SSRF/协议/媒体攻击矩阵与无内网访问证据 |
| `S002-DAC-03` | 单文件与分离流都产出可播放音视频，后者只 stream copy | yt-dlp 参数、FFmpeg 日志、ffprobe 报告 |
| `S002-DAC-04` | 不接受或泄露 selector、Cookie、Header、代理、媒体直链、URL query 和真实路径 | API/schema/日志/源码扫描 |
| `S002-DAC-05` | 所有成功/失败/超时路径遵守大小、时长、目录隔离和清理规则 | 资源边界、故障注入和目录检查 |
| `S002-DAC-06` | 文件仅对创建会话、成功且未过期任务签发 URL，MinIO 下载内容与 SHA-256 一致 | 越权/过期测试、预签名 URL 与完整文件校验 |
| `S002-DAC-07` | yt-dlp 站点变化表现为稳定错误并可通过受控依赖升级恢复 | 固定版本失败样例、升级 PR 烟测与回滚记录 |
