# 跨宿主平台来源自动恢复

> 范围说明：本文实现的是**已有**部署来源的持久分发，不能在没有来源时自动取得平台访问能力。全新开源部署的需求和验收见 [044 PRD](../prd/044-开源部署无感解析PRD.md)，访客初始化架构见 [Design](044-开源部署无感解析需求与系统设计.md)，执行见 [Plan](../plan/044-开源部署无感解析Plan.md)；043 不作为公开解析的前置条件。

普通用户只提交链接。应用重建、后端迁移和本机副本丢失不应要求用户再次导出平台 Cookie。本设计修复文件来源的部署生命周期，覆盖标准配置中的 YouTube、抖音、Reddit，以及生产配置中的优酷、腾讯视频；不声称能够生成第三方授权或迁移视频号专用浏览器 Profile。

## 持久事实与本机副本

`provider_session_sources` 是现有 PostgreSQL 中的部署级来源表，保存 Provider、单调递增修订、密文、有效期和更新时间。普通业务 API 不接收也不返回 Cookie。来源密钥独立于数据库、URL 密钥和 Runner HMAC，仅注入部署侧来源进程；数据库备份与来源密钥分开保管，换机保持原密钥。

部署者用 `provider_source_replica publish` 登记已批准的单平台文件。先验证格式、域和必要字段，再加密；密文绑定 Provider、修订和有效期。首次登记期望版本为 0，后续更新必须提供读到的版本。条件写入仅有一个并发胜者。撤销保留修订墓碑并清空密文，过时维护者不能按旧版本恢复已撤销来源。明确重新授权后可用最新修订登记新来源。有效期是部署侧的最长使用边界，不代表平台保证该时段可用。

独立 `provider-sources` 进程每 15 秒读取持久来源，平台并行同步，每次数据库往返最多等待 5 秒。它持有数据库连接和来源密钥，不下载媒体、不读取用户浏览器、不持有对象存储或队列凭据。单个本地卷上的发布用非阻塞互斥锁串行化，避免迟到读取覆盖撤销结果。

每个 Runner 只读挂载自身命名卷，既不获得数据库配置、来源密钥，也不读取其他平台文件。来源初始化容器仅负责 `10001:10001 / 0700` 目录；发布复用现有 `0600` 文件、内容校验、fsync 和原子重命名。空卷可自动恢复，不需要从旧机器拷贝目录。

## 租约与失效

本地文件携带 Provider、来源修订和短期截止时间，默认最多 90 秒，且不超过持久来源的有效期。Runner 每次操作重新读取，文件模式启用 `RUNNER_PROVIDER_SOURCE_REQUIRE_LEASE` 后拒绝无租约或到期副本。租约截止时间在计算访问上下文前剥离，持久来源修订保留：正常续租不会改变凭据版本；Cookie 变化或撤销后明确重新授权都会使旧上下文失效。

撤销、记录缺失、解密失败或来源失效会移除本机文件；数据库断连期间只允许尚在租约期内的来源。来源进程暂停或退出后，即使文件仍存在，Runner 自己也会拒绝过期租约。正常同步下撤销由下一次轮询生效；断连时新操作最多在剩余租约期内受理。已取得操作 jar 的在途任务可完成，此处不宣称撤销会立刻杀掉在途任务。

同步进程不从本机旧文件反向注册来源，避免新机残留、旧备份或删除动作触发授权复活。没有配置密钥时进程明确报告 disabled；启用了本地文件路线的统一启动入口会报告缺失配置，不生成随机替代密钥，不删除路线。

## 启动与恢复

`provider_startup` 依据部署声明启用本地 Runner，不读取 Cookie 决定是否删除能力；远端 Runner 不被当成本地来源。没有来源时路线仍存在，后续来源发布后可原地恢复。

`/health/runtime` 检查二进制、工作目录及出口依赖，供可选 Runner 的 Compose 启动使用；`/health/ready` 继续检查真实会话来源状态。API 与普通 Worker 不等待所有平台授权。来源进程心跳仅表示维护循环仍运行，不是平台接受 Cookie 的证据。

更换机器时，部署配置连接同一持久数据库（或恢复其备份）、沿用来源密钥并启动当前镜像，系统重建本地卷。若数据库本身也在旧机器上，必须先迁移持久数据；空仓库和一个全新的空数据库不能恢复不存在的授权。平台还可能根据新出口要求验证，真实 metadata/media 验收独立于文件恢复。

## 当前边界

此链路自动恢复、分发、轮换已登记来源，不会自动延长第三方登录。现有浏览器快照不自动变成全站共享账号；个人授权和部署级来源仍隔离。视频号保留专用元宝动态来源，跨宿主仍需单独处理首次登录。下载前持久意图、授权后任务自动续接、平台全量能力目录和跨主机任务工作目录交接不在本次来源协议内。

部署登记、版本查询和撤销步骤见 [008 手册](../operations/008-个人部署重启与换机手册.md)。
