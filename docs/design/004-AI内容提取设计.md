## 1. 功能边界

AI 内容提取是下载完成后的可选功能，不阻塞视频下载。它只分析视频语音，生成摘要、核心要点和章节。

- 不下载或使用平台字幕。
- 不生成可下载字幕文件。
- 不分析画面、图表、动作或人物。
- 不提供 Prompt、模型参数、API Key 或 Provider 的用户配置界面。
- 不使用 Agent、LangGraph、RAG 或向量数据库。

## 2. 处理流程

1. 仅 `succeeded` 且未过期的下载任务可以创建 AI 任务。
2. AI Worker 从 MinIO 下载视频并提取语音。
3. faster-whisper 生成带起止时间的内部转写片段。
4. LangChain 将转写交给 OpenAI-compatible Chat Model。
5. 模型输出经 Pydantic 结构化校验后写入 PostgreSQL。
6. 临时音频在成功或失败后立即删除。

默认 AI 超时 60 分钟。内部转写用于分析与审计，不通过 API 返回，不作为字幕能力。

## 3. LangChain 边界

依赖固定为 `langchain` 与 `langchain-openai`。运行配置为 `base_url`、`api_key`、`model`、`timeout`、`max_retries`；首个版本一次只配置一个 Provider。

处理链固定为：

`Timed Transcript → Prompt Template → Chat Model → Pydantic Structured Output`

优先使用 Provider 支持的结构化输出。Provider 无法生成可验证结构时，任务以 `AI_ANALYSIS_FAILED` 结束，不静默返回自由文本。

## 4. 输入与输出

`CreateAIJobRequestDTO` 只有可选 `output_language`，默认 `zh-CN`。

`VideoAnalysisVO` 固定包含：

- `language`：实际输出语言。
- `summary`：视频语音内容摘要。
- `key_points[]`：去重后的核心观点。
- `chapters[]`：标题、起止秒和章节摘要。

VO 不返回完整内部转写、模型原始响应、Prompt、Token 明细或密钥。

## 5. 失败与重试

- `TRANSCRIPTION_FAILED`：音频提取、解码或 faster-whisper 失败。
- `AI_ANALYSIS_FAILED`：Provider、超时、结构化输出或校验失败。
- 下载文件缺失或已过期时返回 `JOB_EXPIRED`，不得创建 AI 任务。
- 模型 429、网络和 5xx 可有限重试；认证、模型不存在和结构不兼容不重试。

## 6. 保留与隐私

- AI Result 默认可用 24 小时，之后进入 expired。
- 原始 URL、密钥和 Provider 原始错误不得进入 Prompt 或结果。
- 日志只记录 AI job ID、阶段、模型名、耗时和安全错误码。
- Web 必须明确提示结果只基于语音，可能存在识别和总结误差。

## 7. 执行验收标准

| 编号 | 必须证明 | 验证与证据 |
| --- | --- | --- |
| `S004-DAC-01` | succeeded 且未过期文件可创建一次 AI 任务，其他状态全部拒绝 | 全下载状态参数化测试、重复提交和 API 结果 |
| `S004-DAC-02` | 真实 FFmpeg 音频提取和 faster-whisper 可产生带时间段内部转写 | 受控视频、命令参数、真实模型运行记录和时间段样本 |
| `S004-DAC-03` | 固定 LangChain 链通过真实 OpenAI-compatible Provider 返回严格结构化结果 | Provider 配置、真实调用、Pydantic 校验和脱敏结果 |
| `S004-DAC-04` | 默认 `zh-CN`，summary、key_points、chapters 完整且章节时间合法 | 默认/指定语言测试、schema 与时间范围断言 |
| `S004-DAC-05` | 对外 VO 不含完整转写、原始响应、Prompt、Token、密钥或画面推断 | 响应 schema、日志、数据库和输出扫描 |
| `S004-DAC-06` | 429/网络/5xx 有限重试，认证、模型不存在、结构错误不重试且错误码稳定 | Provider 故障矩阵、重试计数和最终任务状态 |
| `S004-DAC-07` | 成功、失败、Worker 崩溃和下载过期时临时音频都被清理，下载产物不受 AI 失败影响 | 文件系统检查、崩溃恢复和下载对象一致性证据 |
| `S004-DAC-08` | Mock 之外至少完成一次下载产物到 AI 结果的真实端到端闭环 | 真实依赖运行记录、结果查询和对应 job/artifact 关联 |
