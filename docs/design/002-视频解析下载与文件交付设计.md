# 002 视频解析、下载与文件交付设计

- 输出：解析、格式、下载、合并和文件交付契约。

## 1. 功能边界

本功能只处理公开单视频链接。用户提交 URL 后获得视频摘要信息和可下载格式，选择一个格式创建下载任务，成功后通过 MinIO 预签名 URL 获取文件。

不处理字幕、播放列表、批量任务、音频单独下载、登录态、Cookie、DRM、视频编辑或重新编码增强。

## 2. 链接解析

1. 只接受 HTTP/HTTPS URL。
2. DNS 解析和每次重定向均拒绝 loopback、私网、链路本地和云元数据地址。
3. yt-dlp 使用 `download=False` 提取元数据，不在 API 请求内下载媒体。
4. 服务保存视频来源和标准化格式，解析结果 15 分钟有效。
5. `VideoInspectVO` 返回 source ID、标题、平台、缩略图、时长、过期时间和 formats，不返回原始 URL。

解析默认超时 30 秒；不支持、DRM、禁止地址和网络失败必须使用不同错误码。

## 3. 清晰度与格式

`VideoFormatVO` 固定包含：

- `id`、`label`、`container`、`width`、`height`、`fps`。
- `video_codec`、`audio_codec`、`estimated_size_bytes`、`requires_merge`。

服务端保存 provider format ID 或 selector，Web 只能提交 `source_id + format_id`。格式按推荐顺序排列：优先兼容性较好的单文件，其次为最佳画面与最佳音频组合；同档再按清晰度、FPS 和估算大小排序。

无音频的视频格式和音频单独格式不展示。不为统一 MP4 而转码；估算大小不可得时返回 null。

## 4. 下载与 FFmpeg

1. API 验证 source 和 format 未过期后创建下载任务。
2. Download Worker 重新使用原始 URL 与服务端 selector 调用 yt-dlp。
3. 单文件格式直接进入校验；独立音视频流分别下载后调用 FFmpeg。
4. FFmpeg 使用流复制完成封装合并，不重新编码，不处理字幕。
5. ffprobe 校验输出至少存在视频流和音频流，并读取最终容器与时长。
6. 校验成功后上传 MinIO；成功前产生的本地临时文件必须清除。

默认限制下载 30 分钟、视频时长 2 小时、最终产物 2 GiB。yt-dlp 与 FFmpeg 使用结构化参数，不拼接 shell 字符串；文件名由服务端生成。

## 5. MinIO 文件交付

- Bucket 固定为私有 `video-artifacts`。
- 对象键为 `jobs/{job_id}/video/{filename}`。
- 数据库保存对象键、文件名、MIME、大小、校验值和过期时间，不保存文件二进制。
- 下载文件默认可用 24 小时；MinIO 生命周期规则负责到期删除兜底。
- 下载地址按请求生成，默认有效 15 分钟；Web 只使用返回 URL，不拼接对象键。

## 6. 安全与过载

- 原始 URL 的查询参数在日志中脱敏，VO 不回传原始 URL。
- CORS 只允许已配置 Web Origin；密钥只来自环境或 Secret。
- 公网入口按 IP 限制解析和任务创建速率。
- API 按 PostgreSQL 中的全局活跃任务数拒绝过载，不为此引入 Redis。
- 用户界面必须提示仅下载用户拥有权利的内容，不承诺“所有网站”。

## 7. 功能错误

本功能定义：`VIDEO_URL_INVALID`、`VIDEO_URL_FORBIDDEN`、`VIDEO_UNSUPPORTED`、`VIDEO_DRM_PROTECTED`、`VIDEO_PARSE_FAILED`、`FORMAT_UNAVAILABLE`、`DOWNLOAD_FAILED`、`MEDIA_MERGE_FAILED`、`STORAGE_FAILED`、`RESOURCE_LIMIT_EXCEEDED`、`JOB_EXPIRED`。

网络、MinIO 和平台临时 5xx 可重试；不支持、DRM、格式不存在和资源超限不得自动重试。

## 8. 执行验收标准

| 编号 | 必须证明 | 验证与证据 |
| --- | --- | --- |
| `S002-DAC-01` | 受控真实公开单视频可解析，格式字段、排序和 15 分钟有效期完全符合契约 | 真实 yt-dlp 调用记录、标准化结果和过期前后 API 证据 |
| `S002-DAC-02` | 非 HTTP(S)、内网/本机、重定向绕过、播放列表、DRM、需登录和不支持来源全部被安全拒绝 | URL/重定向攻击矩阵及对应 HTTP、业务 code 和无外连证据 |
| `S002-DAC-03` | 单文件和分离音视频两条路径都能生成可播放产物，分离流只做 stream copy | 受控媒体集成测试、FFmpeg 参数、ffprobe 音视频流和 codec 报告 |
| `S002-DAC-04` | 下载链路不请求、保存、嵌入或输出字幕，也不发生非必要转码 | yt-dlp/FFmpeg 参数断言、产物流检查和依赖能力扫描 |
| `S002-DAC-05` | MinIO 私有对象、元数据、校验值、24 小时文件期限和 15 分钟 URL 均准确 | 真实 MinIO 对象、数据库记录、checksum、授权与过期验证 |
| `S002-DAC-06` | 时长、耗时、大小、并发和临时目录限制在成功、失败和超时路径都生效 | 边界/超限矩阵、任务状态、资源观测和临时目录清理证据 |
| `S002-DAC-07` | 瞬时错误只有限重试，永久错误不重试，错误码稳定且不泄露 URL 参数或路径 | 故障注入、重试次数、最终状态及日志/响应扫描 |
| `S002-DAC-08` | inspect → job → Worker → MinIO → download URL 的完整链路可重复成功 | 真实依赖端到端记录、最终文件下载和校验值比对 |
