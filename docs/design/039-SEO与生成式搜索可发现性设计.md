# SEO 与生成式搜索可发现性

## 目标与设计约束

帧取 FrameFetch 的公开说明面向创作者、内容研究者和自托管开发者，围绕视频解析、本地素材导入、AI 视频/分镜分析、剧本文档处理与报告导出回答实际问题。GitHub 是源码与实现事实入口，Web 是产品理解与使用入口。GEO 指生成式搜索可发现性，不指地域优化。

页面沿用根 `design.md` 的官方 Next.js/shadcn、neutral 明暗主题、无边框留白和 BasicLayout。不为了关键词增加平台目录页、重复落地页、隐藏正文或未经验证的宣传数字。已有工作区、登录与媒体处理交互继续保持原业务边界。

## 需求、实现与验收契约

| 需求 | 实现位置 | 验收条件 |
| --- | --- | --- |
| 匿名首屏无需 JS 可读 | `HomeExperience.initialPublic`，由首页服务端 Cookie 存在性决定 | 原始 HTML 含唯一 h1、正文、FAQ 与指南链接；会话恢复请求尚未完成时也可阅读 |
| 会话与公共说明隔离 | 首页 `generateMetadata` 与服务端条件渲染 | access/refresh Cookie 任一存在则保持启动状态、noindex，无公开 JSON-LD；Cookie 存在性不是身份鉴权 |
| 明确公开索引意图 | `SITE_INDEXABLE`，默认 false | 仅明确 true 时首页和指南允许 index、snippet，sitemap 只含这两页；工作区页面仍默认 noindex |
| 可抓取元数据 | Next.js Metadata API、`htmlLimitedBots: /.*/` | 普通浏览器、HTML-only 与搜索 UA 均在 head 收到最终 robots/canonical；不按 UA 修改正文 |
| 一致实体说明 | `siteConfig`、首页 JSON-LD、中英文 README | 帧取/FrameFetch、服务端/App 分工、许可与费用范围一致；不存在虚构评分、价格或语言版本 |
| 可引用答案与依据 | 首页六组问答、`/guide/`、源码链接 | FAQ 可见正文与 JSON-LD 来自同一份内容；指南可直达且带稳定章节锚点 |
| 分享与内部导航 | OpenGraph、Twitter、页脚指南、指南面包屑 | 图片返回 image/png；链接有效；390px 与桌面、明暗主题无横向溢出 |

实施顺序为修复 SSR 与索引配置、补充内容及实体关系、同步 GitHub 文档、执行自动检查与浏览器验收。验证结果与上线步骤记录在 [SEO 与 GEO 运行手册](../operations/010-SEO与GEO运行手册.md)，不以本地检查替代搜索引擎收录。

## 索引与数据边界

- 公开 HTML 页面只有 `/`（匿名视图）和 `/guide/`。其余页面继承根布局 noindex、nofollow、nosnippet，不发布工作区 canonical 或用户数据 sitemap。
- 私有实例仍可读取公共说明，但默认 noindex 且 sitemap 为空。robots.txt 允许读取 HTML，避免爬虫无法发现 noindex；身份认证与网络访问控制负责真正的数据保护。
- `/api` 与 `/health` 不允许机器人抓取，覆盖无尾斜杠入口。通用搜索爬虫与 OAI-SearchBot 共享这组边界，避免专用 UA 意外放开接口。
- OpenAI 搜索爬虫与训练爬虫属于不同用途。此次显式声明 OAI-SearchBot 搜索规则；未额外变更既有训练爬虫策略。任何机器协议都不是访问控制。
- `SITE_URL` 必须是无凭据的 HTTP(S) 绝对地址，canonical、sitemap 与分享地址共用其 origin，不从不可信 Host 请求头推导。公开站需使用稳定 HTTPS 域名；本地/Tailnet 地址不能提交给搜索引擎。
- 索引开关和域名在构建与运行时都传入前端；静态指南、sitemap 与分享资源依赖构建配置。变更后重建镜像并 recreate，仅 restart 不足以更新静态产物。

## 结构化数据与内容事实

首页关联 WebSite、WebPage、SoftwareApplication、SoftwareSourceCode 与 FAQPage。`codeRepository` 归属于 SoftwareSourceCode；软件实体通过 sameAs 链接仓库。仅源代码声明免费可访问，移除“免费运行服务”的 Offer 暗示。Web 页面真实语言为 zh-CN，不把英文 README 标成不存在的英文 Web hreflang 页面。

FAQ 用于表达真实可见问答，不作为 Google FAQ 富结果优化（Google 自 2026-05-07 停止展示，2026-06-15 移除相应文档）。未添加虚构评价、聚合评分、使用人数、发布日期或每日刷新的 lastmod。指南使用与可见导航一致的 BreadcrumbList。

生成式搜索仍依赖可抓取、可索引、允许摘要并能提供依据的正文。本次不把 llms.txt、特殊 AI Schema 或关键词堆叠作为收录/引用的必要条件。以后若有独立机器文档分发需求，再实现相应入口并维护事实一致性。

## 官方依据

核对日期：2026-09-21。

- [Google AI features and your website](https://developers.google.com/search/docs/appearance/ai-features)：可索引、摘要资格、文本内容及可见正文与结构化数据一致性。
- [Google noindex](https://developers.google.com/search/docs/crawling-indexing/block-indexing)：爬虫必须能读取页面才能看到 noindex。
- [OpenAI crawler documentation](https://developers.openai.com/api/docs/bots)：OAI-SearchBot 与 GPTBot 独立控制，网络层也需允许搜索抓取。
- [Next.js generateMetadata](https://nextjs.org/docs/app/api-reference/functions/generate-metadata)：Metadata API、嵌套字段覆盖与流式 metadata。
- [GitHub repository topics](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/classifying-your-repository-with-topics)：以准确 topics 支持项目发现。

- [Google 生成式搜索优化指南](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide)：2026 年更新的内容质量、技术结构、Search Console 生成式 AI 设置与效果报告。
- [Google Search 文档变更记录](https://developers.google.com/search/updates)：FAQ 富结果停用及 llms.txt 说明。
