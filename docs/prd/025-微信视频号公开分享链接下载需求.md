# 025 微信视频号公开分享链接下载需求

- 状态：Implemented，Production Verification Pending
- 日期：2026-08-29
- 对应设计：`docs/design/025-微信视频号公开分享链接下载设计.md`

## 1. 用户价值

面向 C 端的任意用户可提交公开微信视频号单作品分享链接。当第一方公开响应直接
提供可下载、非加密媒体时，服务返回真实格式并进入通用下载与 AI 分析链路。当平台
只返回播放元数据、需登录或存在保护时，产品准确拒绝并提供“上传自有/已授权文件”路径。

## 2. 功能需求

### FR-025-01 URL 准入

- 仅接受 `https://weixin.qq.com/sph/{id}` 单作品链接。
- 拒绝主页、直播、搜索、批量入口、query、fragment 与非默认端口。
- 已识别的微信域名不得回退 Generic extractor。

### FR-025-02 公开媒体证明

- inspection 与下载前重解析都只访问第一方公开预览页和 feed 接口。
- 只有成功响应中直接存在批准的 clear H.264/H.265 媒体 URL 才可下载。
- 仅有元数据、链接失效、私密、验证挑战或保护字段时必须 fail closed。

### FR-025-03 C 端通用性

- 任意部署不依赖开发者电脑、Chrome Profile、Keychain、Codex Worker 或某个微信/元宝账号。
- 不读取、上传、保存或共享用户 Cookie，不使用服务公用账号扩张用户权益。
- 未来只有平台公开的 OAuth/资产 API 能作为登录态连接器；不得以消费端 Cookie 仿冒官方授权。

### FR-025-04 媒体与状态

- 媒体 URL 只允许批准的腾讯 HTTPS host/path，任意保护字段或 FFprobe 失败都拒绝。
- Provider 状态为 `degraded`，明确表达“仅支持第一方直接公开媒体”。
- 未完成真实 metadata + media + Artifact canary 前不得提升为 `verified`。

## 3. 非目标

- 私密/关注可见作品、直播、作者主页、批量下载、付费或地域权益绕过。
- 元宝解析私有接口、消费端 Cookie、公共 Worker、第三方解析站、MITM、注入或解密。
- 把腾讯云点播中客户自有媒资的 API 当作任意视频号分享链接下载 API。

## 4. 验收指标

- 严格 URL、公开性、媒体域、保护与错误测试通过。
- 一个自有或明确授权的直接公开样本完成 inspection → 下载 → FFprobe → Artifact。
- 无任何宿主机浏览器、Cookie Secret 或解析账号依赖；负例产生零媒体 Artifact。
