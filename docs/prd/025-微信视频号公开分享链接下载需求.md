# 025 微信视频号公开分享链接下载需求

- 状态：Implemented，Production Verification Pending
- 日期：2026-08-27
- 对应设计：`docs/design/025-微信视频号公开分享链接下载设计.md`

## 1. 用户价值

用户粘贴一个仍可匿名访问的微信视频号单作品分享链接后，可以像其他 Provider 一样查看标题与真实可用格式并创建下载。服务未配置隔离会话、链接失效或媒体受保护时，用户得到明确且安全的原因，不会被引导上传 Cookie 或使用第三方解析站。

## 2. 功能需求

### FR-025-01 URL 准入

- 仅接受 `https://weixin.qq.com/sph/{id}`。
- 拒绝主页、直播、搜索、评论、批量入口、query、fragment、非默认端口。
- 微信已识别域名不得落入 Generic。

### FR-025-02 公开性证明

- 每次 inspection 和下载前重解析都先匿名访问第一方预览接口。
- 只有成功返回非空公开 `feedInfo` 才能进入隔离会话。
- 无效、删除、私密或挑战状态不得调用元宝 resolver。

### FR-025-03 隔离会话

- 只允许项目运维账号的服务端会话，不接受普通用户 Cookie。
- Secret 仅允许 `yuanbao.tencent.com`，并要求 `hy_user`、`hy_token` 同时存在。
- `wechat_channels` 使用独立 Runner、单凭据并发限制和 endpoint。
- Cookie、token、export id、签名 URL 与原始响应不得持久化或返回客户端。

### FR-025-04 明文媒体

- 只接受批准的腾讯 HTTPS 媒体 host/path。
- 支持响应真实提供的 H.264/H.265 单视频格式。
- 任意保护字段、未知媒体域、空格式或 FFprobe 失败必须拒绝。
- 不实现解密、保护前缀转换、无水印处理或 CDN 猜测。

### FR-025-05 错误与状态

- 未配置隔离会话返回 `provider_auth_required`，而非通用 unsupported。
- 会话过期、链接失效、DRM 和上游临时失败必须可区分。
- Provider 页面显示“需受控会话”，并明确不支持私密、加密、直播和付费内容。
- 未完成真实 canary 前状态不得提升为 `verified`。

### FR-025-06 运维

- 提供浏览器 Cookie 最小化导出命令和 Compose 配置说明。
- 会话轮换失败保留最后一个有效只读版本，但不得在日志输出敏感值。
- 账号告警、条款变化、Cookie 泄漏或权益边界异常时可立即移除路由并停止 Runner。

## 3. 非目标

- 腾讯视频 VIP、购买、试看或缓存导出。
- 视频号私密/关注可见作品、直播、回放、作者主页或批量下载。
- 用户侧 Cookie 上传、微信客户端抓包、证书/代理、页面注入、缓存读取。
- decodeKey、DRM license、密钥获取、加密内容转换。
- 公共 Worker、第三方解析服务或未审计二进制依赖。

## 4. 验收指标

- 严格 URL、公开性、会话、域名、保护和错误测试全部通过。
- 授权公开样本完成 inspection → 下载 → FFprobe → Artifact。
- 负例产生零媒体 Artifact、零 Secret 泄漏、零跨 Provider Cookie。
- 桌面与移动 UI 可理解，无控制台错误和横向溢出。
