# 009 前端体验重构需求

- 状态：Accepted
- 日期：2026-08-09
- 关联 Design：`docs/design/009-Next前端与蓝白视觉系统设计.md`

## 背景与用户问题

现有 Umi Max + Ant Design Pro 前端能够完成下载、分析和账户管理，但后台模板式导航、容器层级与产品的单一核心任务不匹配；移动端表格依赖横向滚动，页面之间的信息密度和视觉表达也不统一。接口客户端依赖 Umi 插件生成，使框架迁移与契约生成耦合。

本次重构保持业务能力不变，把“粘贴公开链接并安全完成下载”变成首屏唯一主线，同时建立适合桌面与 390px 手机的蓝白视觉系统和可持续的 OpenAPI 契约流程。

## 用户与核心任务

- 普通用户：粘贴有权处理的公开视频链接，选择格式，查看任务进度，获取文件，并在下载完成后生成 AI 摘要与思维导图。
- 回访用户：搜索和筛选历史任务，继续查看、取消、重试或获取已经完成的文件。
- 管理员：在不离开统一产品视觉的前提下查询账号、调整他人角色与启用状态。

## 产品目标

1. 用方案 2 的短文案、大留白和无边框结构降低首次下载的理解成本。
2. 以 Next.js App Router + Radix UI + Tailwind CSS 建立唯一前端实现方式。
3. 在保留 FastAPI 同源静态交付的同时覆盖全部现有路由与刷新场景。
4. 让 FastAPI OpenAPI 成为唯一接口契约，并由 `@umijs/openapi` 生成类型安全客户端。
5. 在 390px 视口、键盘操作和屏幕阅读器下完成核心流程，不把无障碍作为视觉后的补丁。

## 非目标

- 不新增下载平台、认证方式、AI 模型、支付、分享或暗色主题。
- 不改变后端任务状态、权限规则、幂等、取消、取件与分析语义。
- 不运行 Next.js 服务端，不引入 SSR、Server Actions、Middleware 或独立前端容器。
- 不保留 Umi/Ant Design 页面作为备用入口或兼容层。

## 功能需求

### FR-009-01 唯一前端栈

前端必须使用 Next.js App Router、React、Radix UI、Tailwind CSS 和 `@umijs/openapi`。交付时移除 Umi Max、Ant Design、Ant Design Pro、Less 及其配置、入口、类型和依赖；不得同时维护两套路由或组件系统。

### FR-009-02 路由等价迁移

必须保留 `/`、`/history`、`/account`、`/admin/users`、`/user/login`、`/user/register` 和 404 能力。下载详情 canonical 地址改为 `/downloads/detail?jobId=<id>`；旧 `/downloads/{jobId}` 由 FastAPI 以 308 重定向，所有新内部链接直接使用 canonical 地址。

### FR-009-03 首页下载主流程

用户可以输入、清除并提交公开 HTTP(S) 视频地址；页面校验输入、显示解析状态和错误，成功后展示真实媒体信息与所有语义格式。用户可以用单选控件选择格式并幂等创建下载任务，成功后进入该任务详情。

首页需要明确展示“链接 → 格式 → 下载”的阶段、合法使用提示和解析时间。URL 无效、平台不支持、没有格式、网络失败与重复提交必须有可恢复反馈。

### FR-009-04 下载历史

用户可以按标题搜索、按状态筛选、刷新和分页浏览自己的任务。每项必须展示视频、格式、状态/进度和创建时间；成功任务可获取文件，其他任务可进入详情。桌面使用语义表格，390px 使用不横向滚动的任务列表。

### FR-009-05 下载与分析详情

页面从查询参数读取 `jobId`，显示加载、无效参数、无权限/不存在、任务错误和正常状态。活跃下载可取消，成功下载可获取文件并启动 AI 分析；分析支持语言/模板选择、取消、重试，并展示摘要、关键观点、章节和思维导图。轮询在终态、离开页面或认证失效后停止。

### FR-009-06 认证与账户

登录、注册、会话恢复、一次 Refresh 轮换和退出行为保持可用。未登录用户访问受保护地址时携带安全站内 `redirect` 前往登录；登录后返回原目标。个人资料支持修改用户名并立即更新导航显示，邮箱与角色只读。

### FR-009-07 管理员用户管理

管理员可以按用户名/邮箱、角色和启用状态查询用户，并修改他人的角色与启用状态。普通用户不得看到入口或访问页面；管理员不能降级或停用自己。390px 下不得依赖横向表格才能完成管理。

### FR-009-08 静态导出与同源服务

Next.js 必须输出可由 FastAPI 直接托管的 `frontend/out/`，覆盖所有有限页面、静态资源和 404。生产镜像不启动 Next Node 进程。页面、API、健康检查与 OpenAPI 文档继续使用同一源；API 404 不得返回页面 HTML。

### FR-009-09 OpenAPI 唯一契约

所有前端 API 类型和调用函数由 `@umijs/openapi` 直接根据 FastAPI `/openapi.json` 生成。后端公开操作必须拥有唯一稳定 `operationId`。生成目录禁止手改，CI 重新生成后必须无差异；不得提交第二份人工维护的 OpenAPI 或重复 DTO。

### FR-009-10 视觉一致性

首页必须遵循方案 2 的布局与内容优先级；其他页面沿用同一轻量导航、蓝白 token、短文案、发丝分隔和大留白。纯黑不得作为主色，不使用黑色主按钮、侧栏、重阴影或卡片套卡片。所有关键交互必须覆盖 hover、focus、disabled、loading、selected、empty、error 和 success 状态。

### FR-009-11 响应式与无障碍

全部页面在 390×844 无页面级横向溢出，核心控件触控区域至少 44×44px。产品达到 WCAG 2.2 AA：语义结构、可见标签、键盘全流程、可见焦点、对比度、状态播报、错误关联、200% 缩放和减少动态效果均须验收。

### FR-009-12 设计 QA

首页解析成功态必须在参考图原始 1487×1058 视口进行同图对比。全部路由在桌面和 390×844 检查关键状态；修复 P0/P1/P2 后，根目录 `design-qa.md` 必须记录 `final result: passed`。

## 非功能需求

- NFR-009-01：生产静态 HTML 不包含用户资料、访问凭据、任务数据或环境 Secret。
- NFR-009-02：认证刷新并发合并，失败后只跳转一次；轮询请求在卸载时取消或失效。
- NFR-009-03：构建产物中的脚本和样式使用内容哈希；HTML 可重新验证，静态资源可长期缓存。
- NFR-009-04：用户可见错误使用稳定中文说明与恢复动作，不直接展示后端堆栈或不受控异常文本。
- NFR-009-05：核心页面不能因缩略图加载失败、长标题、空字段或慢接口发生布局坍塌。

## 验收标准

- AC-009-01：依赖、目录和构建入口只保留 Next App Router + Radix UI + Tailwind CSS + `@umijs/openapi`，不存在 Umi/Ant Design/Less 运行时代码。
- AC-009-02：全部现有页面能力均有 App Router 对应页面；受保护路由、管理员路由、认证页和 404 权限行为正确。
- AC-009-03：首页可以从有效链接完成“解析 → 选择格式 → 创建任务 → 进入详情”，并覆盖规定的加载、错误和空状态。
- AC-009-04：历史、详情、AI 分析、个人资料和用户管理的现有功能与权限不回退。
- AC-009-05：`npm run build` 产出 `frontend/out/`，所有有限路由可直接刷新；生产运行时无 Next 服务。
- AC-009-06：旧 `/downloads/{jobId}` 返回 308 并安全指向 canonical 查询参数地址，后端 API 与文档路径不受静态回退影响。
- AC-009-07：`npm run openapi` 可重现生成客户端，所有 `operationId` 唯一，`npm run openapi:check` 无漂移。
- AC-009-08：首页在 1487×1058 达到方案 2 的结构和视觉层级，所有页面统一使用 Apple 蓝白 token 与无边框内容流。
- AC-009-09：所有路由在 390×844 无横向滚动，首页输入、结果、列表、表单和弹窗完成移动布局。
- AC-009-10：自动化 axe 无 serious/critical 问题，键盘可以完成登录、解析、格式选择、创建下载、筛选历史和用户编辑。
- AC-009-11：前端单元/集成测试、生产构建、后端静态服务测试、统一镜像构建和 Compose 解析通过。
- AC-009-12：根目录 `design-qa.md` 记录相同视口与状态的参考/实现比较，P0/P1/P2 清零并写明 `final result: passed`。

## 发布成功信号

- 用户无需打开菜单即可识别首页唯一主任务，并能从粘贴链接连续完成到任务详情。
- 390px 下完成核心任务不需要横向滚动或缩小页面。
- 接口变更若未重新生成客户端会在 CI 明确失败，而不是在运行时暴露类型漂移。
- 生产镜像继续只暴露 FastAPI 服务，同时页面刷新、旧详情链接和 API 404 行为稳定。
