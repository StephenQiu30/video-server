# 035 平台访问与会话恢复能力需求

- 状态：用户已批准开始实施；范围逐切片验收，G1/G2/G3/G5 不因实施指令自动通过。
- 日期：2026-09-12；个人单部署使用，不开放多用户凭据托管。
- 关联：[Design](../design/035-平台访问与会话恢复能力设计.md) · [Plan](../plans/035-平台访问与会话恢复能力计划.md) · [Acceptance](../acceptance/035-平台访问与会话恢复能力验收.md)。

## 1. 要解决的用户问题

用户希望在重启项目或换一台电脑后继续解析和下载声明支持的内容，不必反复修改解析器、重新试各种 Cookie 或猜测平台为什么失败。这个目标不等于仅让所有容器 healthy，也不等于无账号访问私人/付费/DRM 内容。

成功体验分三类：公开内容首次安装可用；有效个人来源重启后可复用；来源失效时明确重新授权，完成后可重新解析，不能无限显示“平台不稳定”。

## 2. 用户旅程

本机 YouTube 授权补充：2026-09-13 用户允许按需读取 Chrome YouTube 会话。普通解析和下载不再要求手工 Cookie 文件；自动取得已有授权不等于自动登录、验证码处理或永久有效。入口仍只输入链接，macOS 已登录来源和新电脑首次授权分别验收。

### J1 新电脑首次使用公开能力

部署者安装批准镜像、提供已有基础设施和服务地址；无需导入私人浏览器状态。用户粘贴公开链接，默认策略解析、选真实规格、下载并在 Web/手机保存。只对已通过该环境验收的能力显示可用；缺必要访客来源时明确说明，而不是暗中借用账号。

### J2 已配置个人来源后的日常重启

停止后启动项目，读取相同持久来源，按需重建临时证明。现有 Artifact 不重新下载；中断任务按既有预算恢复。没有真实账号过期/撤销时，不要求用户再次导出 Cookie。

### J3 来源更新或过期

来源变更后旧 inspection 不偷偷使用新授权。用户看到“会话已更新，请重新解析”，新 inspection 返回当前真实格式。账号需重新验证时，由部署者使用批准的单平台流程完成；前端不索取平台密码或原始 Cookie。

### J4 整机迁移

部署者排空旧部署，迁移批准版本、配置、必要私有来源与业务数据，在新机恢复并验证。先隔离机器差异，再验证新出口。手机连接新入口并取到完整文件；迁移过程中不让新旧两台机器同时消费同一批任务。

### J5 某个平台故障

其他下载、上传、历史查询继续工作。用户看到可行动的原因，部署者能区分服务缺失、来源不可用、平台拒绝、解析器回归和内容失效。证据过期不显示为一次已发生的失败。

## 4. 非功能指标与预算

以下为初始验收目标，不是已有测量结果：

- API 核心 readiness 不依赖所有 Provider 成功；单平台依赖故障不能阻止历史查询或其他平台服务。
- 本轮本地性能基线为 20 个并发请求、200 次请求，分别记录延迟与成功率；不是生产容量承诺，不向第三方平台施压。状态展示在 30 秒内可复用同一快照，刷新失败不继续提供已过期缓存，取消不毒化 single-flight 锁。
- 本设计仍是单部署；进程崩溃恢复、持久预算和平台故障隔离不等于多机高可用。数据库、对象存储、消息队列、入口的多副本与故障转移需目标拓扑和独立演练后才能宣称通过。
- 本地纯策略选择不得增加外部请求；`probe` 最长 2 秒，来源导出/领取最长 15 秒，单次候选维护最长 30 秒；未完成则失败关闭，不无限等待。
- 每来源最多一个活动操作/维护者；不以复制 Runner 扩大账号并发。来源维护等待排空最长 60 秒，超时保留旧版。
- 撤销后停止新租约，并在 60 秒内终止旧 epoch 操作；离线 Runner 无法确认撤销时不得继续领取/续租。
- 复用现有每 job 默认最多 3 次执行 attempt；只有 G3 批准自动修复时才增加共享一次修复预算。429 路径冷却跨进程、跨任务持久，删除任务或新 inspection 均不能解除冷却。半开 metadata 最长 30 秒并受剩余持久租约约束，不执行长下载探针；到期不是已经恢复。具体 Provider 允许更小预算，不能为通过验收调大到无界。
- 性能记录 p50/p95、首字节时间、下载时间、字节数和错误阶段；网络速度不设所有平台统一达标值，长样本采用预先声明预算，超时记录“未完成”，不得临时换低清晰度充数。
- Secret 不进入普通 API、任务 JSON、DB、日志、截图、AI 或可下载诊断包；来源备份加密，恢复密钥分离。

## 5. 产品边界和失败体验

| 情况 | 用户看到 | 可执行动作 |
| --- | --- | --- |
| 近期证据缺失/过期 | 尚未重新验证 | 按批准策略发起真实解析；不伪造平台故障 |
| 运行服务缺失 | 当前部署未配置完整 | 部署者修复依赖；不要求普通用户换账号 |
| 来源失效/已撤销 | 平台会话需重新授权 | 部署者处理后重新解析 |
| 来源已有新修订 | 当前解析信息需更新 | 新建 inspection，重新选择格式 |
| 平台限流 | 暂时受限及可重试时间 | 等待；按钮不能绕过 cooldown |
| 内容删除/不支持/受保护 | 具体内容原因 | 复制其他合法链接或导入已合法取得的文件 |
| 下载器回归 | 当前版本无法处理，部署者需检查 | 候选修复验证，不让用户反复导 Cookie |

不提供：自动账号登录/验证码处理、账号池、共享私人权益、破解 DRM、跨地域规避、全平台万能刷新、自动恢复被平台撤销的授权、实时直播或无限合集的新能力。

## 6. 完成标准

浏览器交付补充：服务端完成只显示文件就绪及保存动作，不宣称已保存到设备；浏览器组织策略阻断不能被误记为 Provider 失败。用户报告的两项文件必须在原浏览器正常保存并校验，方可关闭本地交付问题；策略来源不明时不降低安全保护。

视频号专用会话增量已获用户批准：首次在帧取专用元宝窗口登录，之后解析自动按需复用；正常关闭和服务重建不能删除该来源。登录期间后台读取应有界失败且不能关闭用户窗口，未登录/失效不得伪造成功，授权不得扩大到其他 Chrome Profile。

本需求的“设计完成”指契约、所有权、失败与恢复、实验和安全边界完整并可审查。产品实现必须另获用户批准；至少按平台完成 G1/G2，自动来源能力还需 G3。未通过项保留 No-Go，不用说明文档中的理想行为替代真实验收。

部署验收补充：同一镜像设置不同运行时 `BACKEND_ORIGIN` 后，实际业务请求必须进入选定 API；保留用户登录和 POST 请求体。页面存在新组件、镜像构建成功、readiness 通过均不能替代这项断言。用户报告的失败 URL 应单独复测，不能用固定矩阵其他视频替代。

完整媒体补充：声明有独立音轨但缺少编码信息的源，必须自动探测并合并确认的音轨；不能把静音制品标为该源完整验收通过。不增加用户策略选择、Cookie 输入或兼容选项；真实无音轨内容仍可下载。

限定来源补充：用户授权的抖音、Reddit、视频号分别验收真实文件，不能以能读取会话或 Runner healthy 代替成功。慢平台不能阻塞其他平台的 probe 或新到达导出；取消必须清理临时浏览器。网页已登录但来源无法恢复时，归因于来源实现缺口，不继续要求用户重复授权同一会话。

## 重启可靠性专项补充（2026-09-15）

依据见 [021 深度调研](../research/021-下载可靠性与重启会话故障深度调研.md)。新增可验收要求：

- 在来源仍有效时，正常重启、容器重建和已验收的异常恢复路径不得要求交互登录；本次发现的 Squid PID 循环必须关闭。
- 出口断连、来源离线、空 JSON、限流、挑战和明确授权失效有不同处理；平台 422/429/503 不得导致 FrameFetch 账号退出。
- 持久部署输入必须完整，缺失 Runner/配置直接诊断；生产监测为空必须显示未配置，不能以历史绿色证据替代。
- 连续操作复用已验证来源修订；解析后切换主体必须拒绝旧 context，正常轮换不能静默更换冻结身份。
- 服务端产出、对象存储取回、客户端下载/播放分别验收。23 平台维护清单不等于当前成功清单。

公共出口和重复登录误分类已有分项实现与生产证据，见 035 验收第 23–26 节；独立来源、全平台与新机验收继续未完成。021 第 13 节保留研究时的基线。

## 2026-09-15 YouTube 独立文件来源修复

复用部署者已经登录的 Chrome，禁止通过要求登录测试浏览器解决本次故障。一次性采集必须保留来源权限拒绝分类，不能伪装成会话过期。文件发布拒绝跨平台、过期、损坏、链接和宽松权限来源。来源自然过期或撤销不作永久有效承诺。分别记录独立来源、真实解析、完整文件、重启与换机；字段存在和退出码 0 都不是平台通过证据。

混合来源部署中，已切文件的平台不得残留 browser sync 配置；启动后直接检查真实容器 env/mount。未触及的平台和业务服务配置必须保持一致，源码无 Cookie、Profile 或私有配置。


持续性验收补充：YouTube 静态文件已实测会在容器不变时失效；S3 必须覆盖至少一次真实上游轮换及维护后的新任务。解析、文件格式校验、重启后单次成功均不能替代该门禁；用户明确使用既有 Chrome 时，不得把另开测试浏览器登录作为修复完成条件。当前尚无自动续期能力，状态与交付须如实说明。
