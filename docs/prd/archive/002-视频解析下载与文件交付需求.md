## 1. 用户价值

用户提交一个自己有权使用的公开视频页面链接后，应得到可理解的分辨率选项，并能取得与所选分辨率一致、含音频且可播放的文件，而无需理解 yt-dlp selector、媒体分离流或 FFmpeg。

## 2. 核心旅程

1. 服务校验一个 HTTP(S) 页面链接及每次 DNS/重定向目标。
2. yt-dlp 解析单视频元数据，服务标准化为无重复分辨率选项。
3. 用户只提交服务端签发的 `source_id + format_id`。
4. Worker 下载单文件，或以 FFmpeg stream copy 合并分离音视频。
5. ffprobe 与 SHA-256 校验通过后上传 MinIO 私有 Bucket。
6. 当前匿名会话在文件期限内取得短期预签名 URL。

## 3. 产品规则

- 只使用锁定 yt-dlp 版本中服务端启用的具名 extractor；Generic、播放列表、live、登录、DRM 和插件均拒绝。
- 每个分辨率最多一个推荐项；优先兼容的音视频单文件，否则返回可合并组合。
- 大小允许未知；未知不伪装为 0，也不作为成功条件。
- 客户端不能提交 selector、Cookie、Header、代理、路径或 yt-dlp/FFmpeg 参数。
- 最终文件必须含至少一个视频流和一个音频流；MVP 不转码、不嵌字幕或缩略图。
- 文件成功、失败、超时和进程退出都清理本地中间文件；MinIO 产物按配置期限过期。

## 4. 失败与恢复

非法协议、SSRF、禁止端口、不支持、登录、DRM、播放列表、超限、FFmpeg 失败、MinIO 故障必须返回稳定错误分类。MVP 不自动重试业务失败；用户可重新提交。上游站点变化通过受控依赖升级、烟测与镜像回滚处理。

## 5. Product Acceptance Criteria

| 编号 | 验收行为 |
| --- | --- |
| `S002-AC-01` | 受控真实平台样例能返回稳定、无重复、含音频方案的分辨率列表 |
| `S002-AC-02` | 非 HTTP(S)、私网与重定向绕过、不支持、播放列表、登录、DRM 和超限被安全拒绝且无内网访问 |
| `S002-AC-03` | 创建任务只接受当前会话中未过期的 source/format ID，不接受底层下载参数 |
| `S002-AC-04` | 单文件与分离流样例最终都有音频、视频且可播放，分离流只做 stream copy |
| `S002-AC-05` | 所有结果遵守大小、时长、目录隔离、超时和中间文件清理边界 |
| `S002-AC-06` | 仅创建会话可在期限内获得 URL，真实 MinIO 文件与数据库 SHA-256 一致 |
| `S002-AC-07` | 固定版本站点失效表现为稳定错误，受控升级烟测通过且可回滚上一镜像 |

## 6. 非目标

不支持私有/付费媒体、Cookie 登录、地域绕过、字幕、音频提取、播放列表、批量、转码编辑或第三方公共下载 API。
