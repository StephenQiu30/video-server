## 1. 用户目标

解析凭据过期后，用户仍能在下载详情和历史中看到任务的标题、来源、时长、格式与封面；封面不得依赖短时 Provider URL 或公开对象地址。

## 2. 功能需求

- FR-021-01：封面以用户私有对象写入 MinIO，PostgreSQL 保存对象引用、MIME、大小和 SHA-256。
- FR-021-02：API 返回同源、需登录的封面端点，并执行 owner 授权、完整性校验、private cache、ETag 与 `nosniff`。
- FR-021-03：新解析移除数据库内联 Data URL；旧解析在首次读取时幂等迁移。
- FR-021-04：封面失败不得使媒体解析或下载失败，短期格式凭据 TTL 不得被延长。
- FR-021-05：只接受 AVIF/JPEG/PNG/WebP，验证 Base64、文件签名、大小上限和内容哈希。

## 3. 成功标准

新旧解析、过期格式、owner 隔离、损坏对象、OpenAPI、前端详情/历史展示、schema 幂等升级和 MinIO 最小权限均通过验收。
