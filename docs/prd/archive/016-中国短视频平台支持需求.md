## 1. 用户目标

用户可以在不上传 Cookie、账号或任意下载参数的前提下，解析并下载抖音与快手第一方公开单视频；系统对图集、失效链接、受限内容和身份不一致链接保持 fail closed。

## 2. 功能需求

- FR-016-01：保留已验证的抖音公开分享页插件能力，不因官方开放平台缺少下载接口而错误降级。
- FR-016-02：支持快手公开作品直链和第一方短链，重定向只能落在受信任的快手域名族。
- FR-016-03：验证作品 ID、视频内容类型和 HTTPS MP4 格式；图集不得伪装成单视频。
- FR-016-04：使用固定匿名 Provider Profile，不接受 Cookie、账号、公共解析 API 或任意 yt-dlp 参数。
- FR-016-05：下载前重新解析，完成 FFmpeg/ffprobe、大小、时长和 SHA-256 校验后写入 MinIO。
- FR-016-06：Provider API 与页面展示 registered/extractor/verified 的当前事实和证据基线。

## 3. 非功能需求

- 私网阻断、固定客户端、资源上限、稳定错误码和完整日志脱敏必须沿用现有 Runner 安全边界。
- 真实验收仅使用项目自有、明确授权或公开测试样本，不记录短时签名 URL 和页面原文。
- 微信视频号、红果设备会话和其他需用户设备能力的范围由 019 独立交付；持续 Provider canary 由 005 维护，不阻塞本期公开单视频范围归档。

## 4. 成功标准

抖音回归无退化；快手直链和短链完成真实 metadata、完整媒体、Compose API 到 MinIO、浏览器状态页与全量质量门禁验收。
