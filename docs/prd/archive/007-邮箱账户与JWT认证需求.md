# 007 邮箱账户与 JWT 认证需求

- 状态：Accepted
- 日期：2026-08-09
- 关联 Design：`docs/design/archive/007-邮箱账户与JWT认证设计.md`

## 用户价值

用户可以使用邮箱创建账户，在受信任设备上保持登录，刷新页面或短期 Access JWT 过期时不需要重复输入密码，并能在退出登录后立即撤销长期会话。

## 验收标准

- AC-007-01：唯一用户名、邮箱和至少 8 个字符的密码可以完成注册，重复用户名或邮箱返回稳定冲突错误。
- AC-007-02：正确邮箱密码可以登录，错误邮箱与错误密码使用相同错误提示。
- AC-007-03：刷新页面仍显示当前用户；Access 失效时自动刷新并重试原请求。
- AC-007-04：注销后 Refresh 会话被撤销，再访问业务路由返回登录页。
- AC-007-05：业务数据按用户隔离，JWT 和密码哈希不出现在 API、日志或前端存储中。
- AC-007-06：桌面和窄屏登录注册页无横向溢出，导航展示当前用户名和账户菜单。
