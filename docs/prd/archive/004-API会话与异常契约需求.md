## 1. 用户价值

Web 需要一个稳定、可生成客户端且不会泄露敏感信息的 HTTP 契约。匿名用户刷新后能访问自己的任务，但不能读取其他会话的任务或文件。

## 2. 接口范围

业务接口固定为 inspect、create download、get download、create download URL 四个 operation；运行接口固定为 liveness、readiness。资源成功响应使用真实模型，不包 `code/message/data`；错误统一使用 Problem Details 与真实 HTTP 状态。

## 3. 会话与幂等

- 首次 inspect 创建 256-bit 匿名 Cookie；HttpOnly、Secure、SameSite=Lax，数据库只存 hash。
- source、format、job 和文件地址都校验当前会话归属。
- 所有 POST 校验 Origin；生产 CORS 不允许通配。
- `client_request_id` 在同会话同 payload 下幂等重放，冲突 payload 返回 409。

## 4. 可观测与故障

- liveness 只表示进程存活；readiness 独立检查 PostgreSQL、RabbitMQ、MinIO。
- 依赖故障返回准确的 503 或业务 Problem，不把故障伪装成成功。
- 响应与日志不得包含 URL query、Cookie、selector、MinIO key、预签名 URL、文件路径、SQL 或堆栈。
- `/docs` Swagger UI 供开发者人工查看和试调，`/openapi.json` 是 video-web 代码生成的唯一机器契约；二者不得混用。
- operation ID 与模型必须稳定，使 Ant Design Pro 前端能通过 `npm run openapi` 重复生成并提交 `src/services/video/`，不得维护第二份 API/DTO/路径。

## 5. Product Acceptance Criteria

| 编号 | 验收行为 |
| --- | --- |
| `S004-AC-01` | 四个业务接口和两个健康接口的方法、路径、模型、状态及 operation ID 与 OpenAPI 一致 |
| `S004-AC-02` | 成功响应无自定义 envelope，全部错误符合 Problem Details 和真实 HTTP 状态 |
| `S004-AC-03` | Cookie 可恢复本会话任务，跨会话查询、创建任务或签发文件 URL 均被拒绝 |
| `S004-AC-04` | 重复 client_request_id 不重复创建任务，冲突 payload 稳定返回 409 |
| `S004-AC-05` | PostgreSQL、RabbitMQ、MinIO 任一故障时 readiness 与业务响应准确，liveness 独立 |
| `S004-AC-06` | 日志和响应不泄露 URL、Cookie、selector、对象键、预签名地址、路径或 Secret |
| `S004-AC-07` | `/docs` 可人工审阅，真实 `/openapi.json` 可通过 `npm run openapi` 重复生成 video-web Service，前后端不存在第二份 API/DTO/路径 |

## 6. 非目标

不提供登录、API Key、后台管理、WebSocket/SSE、任务列表、取消/重试接口、第三方开放 API 或兼容旧 envelope。
