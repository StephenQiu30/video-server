# 008 用户资料与角色管理需求

- 状态：Accepted
- 日期：2026-08-09
- 关联 Design：`docs/design/archive/008-用户资料与角色管理设计.md`

## 用户价值

用户可以用稳定用户名标识自己并维护资料；管理员可以区分管理身份与普通身份，查询账号、分配角色并停用异常账号。

## 验收标准

- AC-008-01：注册必须填写 2–32 字符的唯一用户名，邮箱仍是登录凭据。
- AC-008-02：登录用户可修改自己的用户名，并在导航中立即看到新名称。
- AC-008-03：普通用户不能访问用户列表或修改他人身份，接口返回 403。
- AC-008-04：管理员可搜索和筛选用户，调整角色并启用或停用账号。
- AC-008-05：停用账号立即失去业务接口访问能力，长期会话被撤销。
- AC-008-06：管理员不能降级或停用自己。
- AC-008-07：历史、个人资料和用户管理页面使用统一的 Next.js + shadcn/Radix UI 标题、筛选、刷新和工具栏能力，遵循 009 方案 3 的 Vercel Home 无边框规范：`#FAFAFA` 画布、Geist、72px 无边框 Header、导航/主体统一的 1376px 隐形网格与 80/32/16px 响应式 gutter、近黑主操作、无边框填充控件、发丝 Separator 和 Phosphor 图标；页内无可见 PageShell/Card/ring 外壳，Radix 覆盖层仍保留官方焦点行为。
