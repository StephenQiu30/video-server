# PRD002 分辨率选择与无水印优先

## 1. 背景

MVP 阶段已实现基础解析和下载闭环，但用户在选择清晰度和格式时缺乏结构化引导。当前解析结果返回平台原始格式列表和推荐下载预设，但缺少统一的清晰度预设体系、高级格式标识和水印状态提示。需要在不增加后端转码的前提下，为用户提供清晰的分辨率选择和无水印优先策略。

## 2. 目标

```gherkin
Given 用户粘贴一个公开视频链接并触发解析
When 系统返回解析结果
Then 结果应包含推荐、最高 1080p、最高 720p、最高 480p、最高 360p 五类清晰度预设
And 每个预设包含 quality_label、available 和 note 字段
And 平台未提供对应清晰度时提示不可用或自动降级
And 不执行后端转码

Given 解析结果中存在多种格式
When 用户查看格式列表
Then 系统应标识原始格式（raw）和推荐格式（recommended）
And 对于可能包含水印的来源，在 note 中提示水印状态
And 产品表述限定为优先可公开获取的无水印或原始源
```

## 3. 非目标

- 不做后端视频转码、压缩或格式转换。
- 不做主动去水印、画面裁剪或 AI 修复。
- 不做 DRM 规避、付费墙绕过或会员内容访问。
- 不做平台账号 Cookie 托管（除本机 B 站单用户例外）。
- 不做移动端适配。

## 4. 核心内容

### 4.1 清晰度预设体系

解析结果必须返回以下五类清晰度预设，按优先级排列：

| 预设 | quality_label | format_id 模式 | 说明 |
| --- | --- | --- | --- |
| 推荐 | 推荐 | `bestvideo+bestaudio/best` | 自动选择最佳音视频并合并 |
| 最高 1080p | 最高 1080p | `bv*[height<=1080]+ba/b[height<=1080]` | 选择平台已有 ≤1080p 源 |
| 最高 720p | 最高 720p | `bv*[height<=720]+ba/b[height<=720]` | 选择平台已有 ≤720p 源 |
| 最高 480p | 最高 480p | `bv*[height<=480]+ba/b[height<=480]` | 选择平台已有 ≤480p 源 |
| 最高 360p | 最高 360p | `bv*[height<=360]+ba/b[height<=360]` | 选择平台已有 ≤360p 源 |

每个预设包含：
- `quality_label`：人类可读的清晰度标签。
- `available`：布尔值，表示平台是否提供该清晰度或更低清晰度的视频流。
- `note`：提示信息，如"选择平台已有较低清晰度源，不做后端转码"或"该来源未提供此清晰度或更低的视频流"。

### 4.2 高级格式标识

解析结果中的格式分为三类：
- `kind: "recommended"`：推荐格式，自动选择最佳音视频。
- `kind: "video"`：清晰度预设格式，基于 yt-dlp selector 选择。
- `kind: "raw"`：平台原始格式，直接来自 yt-dlp 解析结果。

### 4.3 无水印优先策略

产品策略为"优先选择可公开获取的无水印或原始源"：
- 系统优先推荐无水印或原始画质的视频源。
- 对于已知带有水印的来源（如抖音、快手等短视频平台的默认下载源），在 `note` 字段中提示"该来源可能包含平台水印"。
- 系统不执行去水印、裁剪或 AI 修复操作。
- 用户可自行选择是否接受带水印的版本。

### 4.4 降级与不可用处理

- 平台提供 720p 但不提供 1080p 时，1080p 预设 `available: true`，`note` 提示"该来源最高可用 720p，将自动降级下载"。
- 用户选择低于平台最低可用清晰度时（如平台仅有 720p/1080p 但用户选 480p），该预设 `available: false`，`note` 提示"该来源未提供此清晰度的视频流"。yt-dlp selector `bv*[height<=480]` 是严格过滤，不匹配时不自动升级到更高分辨率。
- 平台完全不提供视频流时，所有预设 `available: false`，`note` 提示"该来源未提供此清晰度或更低的视频流"。
- 不做后端转码伪造"更高清晰度"。

## 6. 验收门禁

- 解析结果稳定返回推荐、最高 1080p、720p、480p、360p 五类预设。
- 每个预设包含 `quality_label`、`available` 和 `note`。
- 平台未提供对应清晰度时提示不可用或自动降级。
- 产品表述不包含主动去水印能力。
- 相关测试通过验证命令。

## 7. 风险与边界

- 不同平台的 yt-dlp 格式元数据质量不一，部分平台可能缺少分辨率信息。
- 水印状态判断依赖平台已知特征，无法覆盖所有来源。
- 本机 B 站下载链路需要 Chrome 登录态，属于已知例外。
