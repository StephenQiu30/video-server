# 分辨率选择与无水印优先 PRD

## 1. 背景

用户希望自己选择下载分辨率，并尽量获得无水印视频。当前后端已有推荐格式、最高 1080p/720p/480p/360p 预设和原始格式列表。本需求将“无水印”限定为优先选择平台可公开获取的原始或无水印源，不主动消除已嵌入水印。

## 2. 目标

1. 普通用户可通过预设档位选择推荐、最高 1080p、720p、480p、360p。
2. 高级用户可展开平台原始格式列表，查看 format_id、编码、分辨率、文件大小和音视频类型。
3. 系统优先展示或选择可公开获取的无水印或原始源；不可用时明确提示原因。

```gherkin
Given 平台返回多个视频格式
When 用户查看解析结果
Then 系统优先展示推荐档位和可用清晰度
And 用户可切换高级模式选择原始格式
And 水印能力以可用性提示表达，不承诺主动去水印
```

## 3. 非目标

- 不对视频画面执行去水印、裁剪水印或 AI 修复。
- 不绕过平台风控获取隐藏无水印源。
- 不后端转码生成平台未提供的分辨率。
- 不保证所有平台都能返回文件大小估计。

## 4. 核心用户故事

| 用户 | 场景 | 验收标准 |
| --- | --- | --- |
| 普通用户 | 想快速下载清晰视频 | 默认看到推荐和常见清晰度预设 |
| 高级用户 | 想控制格式和编码 | 可选择原始格式并创建任务 |
| 合规审核者 | 关注无水印表述风险 | 产品文案说明“优先无水印，不主动去水印” |

## 5. 格式展示规则

1. `recommended` 用于自动选择最佳可用音视频并合并。
2. `video` 用于常见清晰度预设，按平台已有源自动降级。
3. `raw` 用于高级模式，保留平台原始 format_id。
4. 每个不可用预设必须带 `available=false` 和 `note`。
5. 水印状态应使用能力字段或提示文案表达，例如“平台未提供可确认的无水印源”。

## 6. 数据与权限边界

- `format_id` 长度受限，避免用户提交超长 yt-dlp selector。
- 任务创建时只接受解析阶段返回或后端允许的格式选择。
- 不记录用户对水印的非法规避意图。

## 7. 首版验收门禁

- 解析结果同时包含预设格式和高级原始格式。
- 无可用清晰度时能解释不可用或自动降级原因。
- 无水印策略在 PRD、计划和测试计划中保持一致。
- 所有文案避免“去水印”“绕过水印”等主动规避表达。

## 8. 风险与边界

不同平台对“水印”的定义不同，有些水印已嵌入视频画面，有些来自分享页包装。首版只处理可公开解析到的源，不处理画面级水印。
