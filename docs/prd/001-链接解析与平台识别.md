# PRD001 链接解析与平台识别

## 1. 背景

万能视频下载器 MVP 的核心入口是用户粘贴视频链接后触发解析。系统需要完成链接规范化、平台识别、合规提示和解析入口边界控制，以确保：

- 用户输入的链接经过清洗和规范化后才进入解析流程。
- 系统能识别主流视频平台并返回平台画像信息。
- 高风险平台或受限内容有明确的合规提示。
- 无效、内网、保留地址或明显非法链接在入口处被拒绝。

当前后端已具备基于 `yt-dlp` 的通用解析能力和 `PlatformProfile` 平台画像注册表，但 PRD 层面缺少完整的产品边界定义。

## 2. 目标

```gherkin
Given 用户在下载器页面粘贴一个视频链接
When 系统接收到链接输入
Then 系统应完成 URL 规范化（trim、补协议）
And 识别链接所属平台并返回平台画像（platform_id、display_name、category）
And 对高风险平台返回合规提示（compliance_note）
And 无效、内网、保留地址被拒绝并返回明确错误码
And 解析结果通过 POST /api/parse 契约返回给前端
```

### 2.1 具体目标

1. **URL 规范化**：用户输入经过 trim、协议补全、scheme 校验后输出规范 URL。
2. **平台识别**：支持抖音、快手、小红书、西瓜视频、微博、B 站、YouTube、TikTok、Vimeo、Dailymotion 共 10 个平台的画像识别。
3. **合规提示**：高风险平台返回 `compliance_note`，前端可展示给用户。
4. **入口安全**：拒绝无效 URL、本机地址（localhost/127.x）、内网地址（10.x/172.16-31.x/192.168.x）、保留地址。
5. **错误语义**：解析失败按业务错误码分类，错误响应不泄露敏感参数。

## 3. 非目标

- 不承诺所有网站永久可解析。
- 不绕过登录、验证码、地区限制、DRM、付费墙、会员或私密内容。
- 不托管用户平台 Cookie。
- 不做批量抓取或平台专用绕过。
- 不做后端转码，清晰度选择只使用平台已有流。

## 4. 核心内容

### 4.1 用户故事

| ID | 故事 | 验收要点 |
| --- | --- | --- |
| US-01 | 用户粘贴带空格的链接，系统自动清洗并解析 | trim + 补协议 + 正常返回解析结果 |
| US-02 | 用户粘贴抖音/B 站/YouTube 链接，系统识别平台 | 返回 platform_id、display_name、category |
| US-03 | 用户粘贴高风险平台链接，系统展示合规提示 | 返回 compliance_note |
| US-04 | 用户粘贴 localhost 或内网地址，系统拒绝 | 返回 invalid_url 错误码 |
| US-05 | 用户粘贴需要登录的链接，系统返回明确错误 | 返回 platform_restricted 错误码 |
| US-06 | 用户粘贴不支持的平台链接，系统返回明确错误 | 返回 unsupported_platform 错误码 |

### 4.2 产品边界

1. **平台画像不代表能力承诺**：平台被识别不代表支持所有视频、所有清晰度或绕过访问限制。
2. **合规边界硬编码**：DRM、付费墙、会员内容、私密链接、Cookie 托管和平台专用绕过不得出现。
3. **错误响应脱敏**：错误响应和日志不得泄露 token、signature、auth、cookie、key、access_token、session 等敏感参数。
4. **未知平台降级**：未知公共 host 不被平台画像拒绝，仍可进入 yt-dlp best-effort 解析。

### 4.3 API 契约

`POST /api/parse` 响应新增字段（向后兼容）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `platform_id` | string | 机器可读平台 ID，如 `douyin` |
| `platform_category` | string | 平台类型，如 `domestic_short_video` |
| `compliance_note` | string? | 高风险平台的合规边界说明 |

### 4.4 错误码分类

| 错误码 | HTTP 状态 | 含义 |
| --- | --- | --- |
| `invalid_url` | 422 | URL 无效、内网、保留地址或 scheme 不合法 |
| `platform_restricted` | 403 | 登录、会员、付费、版权、DRM、地区或私密内容受限 |
| `platform_rate_limited` | 429 | 平台限流、验证码或访问频率触发风控 |
| `unsupported_platform` | 422 | 链接不是当前支持的视频平台或明显无效 |
| `platform_unavailable` | 503 | 平台暂不可访问、网络超时或临时故障 |
| `parse_failed` | 422 | 公开视频解析失败或平台暂不支持 |

## 6. 验收门禁

- [ ] 平台画像覆盖 10 个平台（抖音、快手、小红书、西瓜、微博、B 站、YouTube、TikTok、Vimeo、Dailymotion）。
- [ ] 每个平台返回 `id`、`display_name`、`category`，高风险平台返回 `compliance_note`。
- [ ] URL 规范化拒绝无效 scheme、内网地址、保留地址。
- [ ] 错误响应不泄露敏感参数。
- [ ] 未知公共 host 不被平台画像误拒绝。
- [ ] 子计划 1（STE-54）和子计划 2（STE-55）的验收标准均已满足。

## 7. 风险与边界

- 平台策略变化可能导致解析失败，系统应降级为 `parse_failed` 而非崩溃。
- yt-dlp 版本升级可能影响平台支持范围，需定期回归。
- 国内平台（抖音、快手等）风控策略不确定，best-effort 模式下可能频繁失败。
