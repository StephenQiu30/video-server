# 003 AI 分析与思维导图需求

- 状态：Accepted
- 关联 Design：`docs/design/003-AI分析与思维导图设计.md`

## 目标用户流程

用户在成功下载任务中启动 AI 分析，选择输出语言，看到转录/分析阶段进度，最终获得摘要、关键观点、行动项、章节和可定位时间点的思维导图。

## 必须满足

- 仅成功且未过期的当前用户制品可创建分析任务。
- AI 任务独立于下载任务；AI 失败不改变下载成功状态。
- 后端以固定 FFmpeg 路径提取 16 kHz 单声道音频，按时长和 25 MB Provider 上限分块后执行 ASR。
- 摘要、观点、章节和导图节点必须引用真实 transcript segment。
- 模型输出只接受严格 JSON；非法证据、时间戳、大小或树深度必须拒绝。
- 分析任务支持幂等、取消、重试、lease/heartbeat 和稳定错误码。
- Provider 密钥仅存在于 AI Worker；浏览器、API 响应和日志不得泄漏。

## 成功指标

- 固定转录 fixture 的结构化结果 schema 通过率 100%。
- 所有证据 ID 和章节时间均可映射到输入转录。
- Provider 超时/限流/非法 JSON 不产生部分成功结果，任务可安全重试。
- 点击章节或带时间的导图节点可定位到对应视频时间；证据 ID 必须在服务端映射到本次真实转录。

## 首期不包含

视频问答、向量数据库、跨视频知识库、用户自定义 Prompt、多 provider 控制台和自动发布内容。
