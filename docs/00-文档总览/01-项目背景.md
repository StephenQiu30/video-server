# 项目背景

更新时间：2026-05-02

## 项目目标

本项目希望开发一款合规、安全、可自部署的万能视频下载与内容整理工具。用户可以将需要下载的视频页面链接粘贴到搜索栏，系统解析可用资源，展示视频信息、格式和清晰度，并创建可跟踪的下载任务。

## 参考方向

项目参考鱼皮的“AI 万能视频下载总结器”思路，但不直接照搬其范围。当前阶段重点是完成市场调研、需求边界、架构候选、角色分工和执行计划，关键技术选型必须由项目负责人手动确认后才能进入正式实现。

## 核心约束

- 不做 DRM、付费墙、会员限制或访问控制规避。
- 不默认托管用户平台 Cookie。
- 不承诺支持所有平台。
- 所有下载任务必须有大小、并发、时长和过期清理限制。
- 所有日志必须脱敏，避免泄露 Cookie、token、签名 URL。
