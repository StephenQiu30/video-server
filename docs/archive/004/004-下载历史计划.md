## 实施顺序

1. 后端先写历史查询的应用模型、repository 契约和 API 契约测试。
2. 在现有 SQLAlchemy repository 中增加 owner-scoped join 查询、筛选和分页计数。
3. 增加 FastAPI `/api/downloads/history` 路由，并运行 OpenAPI 生成。
4. 前端增加历史服务封装、路由和导航菜单。
5. 实现历史页的统计、筛选、分页、任务跳转和成功文件获取。
6. 增加前后端单测，运行 lint、typecheck、测试、构建和后端门禁。
