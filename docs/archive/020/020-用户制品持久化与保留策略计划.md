## 实施步骤

1. 将下载制品和分析报告配置默认值从一天改为 7 天，并支持显式延长到 30 天。
2. 在开发与生产 Compose 中把下载保留/GC 配置传给 Download Worker，把报告保留/GC 配置传给 Report Worker，把短时 URL TTL 传给 API。
3. 在当前态 Schema 中幂等延长仍存在的旧一天对象，不改变已配置的 7 天或更长对象。
4. 保持 API 按对象剩余时间与 5 分钟上限签发 URL，保持前端展示数据库实际截止时间。
5. 增加配置、Compose、Schema、下载 URL、报告发布和 GC 回归测试。
6. 执行后端静态检查与测试、前端门禁、Compose 解析，并回填 Acceptance。
