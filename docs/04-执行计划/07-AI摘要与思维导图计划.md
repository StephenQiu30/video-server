# AI 摘要与思维导图计划

## 1. 目标

实现下载成功后的 AI 摘要生成和 Mermaid 思维导图能力，作为异步增强功能，不阻塞主视频下载流程。

### 1.1 TDD 要求

本计划采用测试驱动开发，必须覆盖以下状态：

| 状态 | 测试场景 | 验证方式 |
| --- | --- | --- |
| `skipped` | 无字幕视频触发 AI 分析 | 返回 `skipped` 状态，不阻塞主流程 |
| `completed` | 有字幕视频 AI 分析成功 | 返回摘要、关键要点、思维导图 |
| `failed` | AI 模型调用失败或超时 | 返回 `failed` 状态和错误信息 |
| `processing` | AI 分析进行中 | 返回 `processing` 状态 |
| `pending` | 等待处理 | 返回 `pending` 状态 |

### 1.2 验证命令

```bash
pytest apps/api/tests/test_ai_intelligence.py apps/api/tests/test_worker_jobs.py -q
```

## 2. 任务拆解

### 2.1 数据模型层

- [ ] 2.1.1 创建 `ai_analysis` 数据库表
  - 字段：id, task_id, status, summary, key_points, chapters, mindmap, keywords, error_message, model_used, processing_time_ms, created_at, updated_at
  - 状态枚举：pending, processing, completed, failed, skipped

- [ ] 2.1.2 扩展 `tasks` 表
  - 新增 `ai_status` 字段（VARCHAR(20)，默认 'pending'）
  - 新增 `ai_analysis_id` 外键

- [ ] 2.1.3 创建数据库迁移脚本
  - 使用 Alembic 管理迁移
  - 包含回滚脚本

### 2.2 AI 服务层

- [ ] 2.2.1 定义 AI 服务接口
  - `generate_summary(text: str) -> AISummary`
  - `generate_mindmap(summary: AISummary) -> str`
  - 支持本地模型和 API 双模式

- [ ] 2.2.2 实现字幕提取服务
  - 从视频文件提取字幕轨道
  - 支持 SRT、VTT 格式解析
  - 无字幕时返回 None

- [ ] 2.2.3 实现本地 AI 模型适配器
  - 支持 llama.cpp 或 Ollama 本地模型
  - 配置模型路径和参数
  - 处理模型加载和推理

- [ ] 2.2.4 实现云端 AI API 适配器
  - 支持 OpenAI、Anthropic 等 API
  - 处理 API 密钥和认证
  - 实现重试和超时机制

### 2.3 Worker 任务层

- [ ] 2.3.1 创建 AI 分析 Worker 任务
  - 接收 task_id 参数
  - 检查任务状态和字幕可用性
  - 调用 AI 服务生成摘要
  - 保存结果到 ai_analysis 表
  - 更新任务 ai_status 字段

- [ ] 2.3.2 实现失败处理逻辑
  - 无字幕：标记为 skipped
  - AI 失败：标记为 failed，记录错误
  - 超时：标记为 failed，支持重试

- [ ] 2.3.3 实现 SSE 事件推送
  - AI 分析开始事件
  - AI 分析完成事件
  - AI 分析失败事件

### 2.4 API 接口层

- [ ] 2.4.1 实现触发 AI 分析接口
  - `POST /api/tasks/{task_id}/analyze`
  - 参数：force（是否强制重新分析）
  - 返回：ai_status 和消息

- [ ] 2.4.2 实现获取 AI 分析结果接口
  - `GET /api/tasks/{task_id}/analysis`
  - 返回：完整分析结果或状态

- [ ] 2.4.3 实现重试 AI 分析接口
  - `POST /api/tasks/{task_id}/analysis/retry`
  - 仅当 ai_status 为 failed 时可用

### 2.5 测试层

- [ ] 2.5.1 单元测试：AI 服务
  - 测试摘要生成
  - 测试思维导图生成
  - 测试无字幕处理
  - 测试 AI 失败处理

- [ ] 2.5.2 集成测试：Worker 任务
  - 测试完整 AI 分析流程
  - 测试状态流转
  - 测试 SSE 事件推送

- [ ] 2.5.3 API 测试：接口契约
  - 测试触发分析接口
  - 测试获取结果接口
  - 测试重试接口

## 3. 验收条件

### 3.1 功能验收

| 验收项 | 验证方式 | 预期结果 |
| --- | --- | --- |
| 有字幕视频 AI 分析 | 触发分析后等待完成 | 状态为 completed，返回摘要和思维导图 |
| 无字幕视频 AI 分析 | 触发分析 | 状态为 skipped，不阻塞主流程 |
| AI 失败处理 | 模拟 AI 服务失败 | 状态为 failed，返回错误信息 |
| 重试机制 | 失败后重试 | 重新触发分析 |
| SSE 事件 | 监听任务流 | 收到 AI 状态变更事件 |

### 3.2 边界验收

| 边界场景 | 验证方式 | 预期结果 |
| --- | --- | --- |
| AI 跳过不影响主流程 | 下载成功后跳过 AI | 任务状态仍为 succeeded |
| AI 失败不影响主流程 | AI 分析失败 | 任务状态仍为 succeeded |
| 并发分析 | 多个任务同时分析 | 各自独立处理 |
| 长文本处理 | 超长字幕 | 截断或分块处理 |

## 5. 风险与缓解

| 风险 | 影响 | 缓解措施 |
| --- | --- | --- |
| AI 模型不可用 | 无法生成摘要 | 支持多模型切换，优雅降级 |
| 字幕提取失败 | 无法分析内容 | 标记为 skipped，不阻塞 |
| 处理时间过长 | 用户体验差 | 异步处理，超时机制 |
| 成本过高 | 资源消耗大 | 限制文本长度，缓存结果 |
