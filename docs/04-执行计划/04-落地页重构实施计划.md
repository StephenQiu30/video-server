# 落地页重构实施计划

## 1. 目标
- 将首页改为完整 SaaS 落地页：Hero、价值主张、功能、社会证明、FAQ、定价与终端 CTA。
- 采用 `ui-ux-pro-max` 的蓝白 iOS 风格、简约布局、最小装饰。
- 通过 OpenSpec（proposal/specs/design/tasks）形成归档可追踪链路。

## 2. 任务
1. 建立页面结构与语义化区块。
2. 统一视觉变量与字体加载，补齐动效与可访问性边界。
3. 新增/更新结构与 a11y 测试。
4. 补齐验收与 review 文档。
5. 执行 openspec 全流程（new -> proposal -> specs -> design -> tasks -> verify -> archive）。

## 3. 验收条件
- 页面包含并可导航到区块：hero、features、proof、pricing、faq、final-cta。
- 关键主操作具备清晰文案、focus-visible 与触达尺寸（44px 级别）。
- 配色与背景以蓝白为主，避免高饱和、不必要装饰。
- 至少两类测试覆盖结构与可访问性。
- OpenSpec change 成功归档。

## 4. 执行闭环记录
- OpenSpec 变更：`landing-page-ios-blue-white-redesign`。
- 归档结果：`openspec/changes/archive/2026-05-18-landing-page-ios-blue-white-redesign/`。
- 验证命令：`cd apps/web && npm run test:landing`（8/8 通过）。
