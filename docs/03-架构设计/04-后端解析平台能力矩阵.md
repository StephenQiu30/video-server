更新时间：2026-05-23

## 1. 目标

后端解析层以 `yt-dlp` 为通用内核，以平台画像注册表和专用适配器补齐国内主流平台的识别、错误分类和合规提示。平台被识别不代表承诺绕过访问限制；系统只处理公开可访问内容。

## 3. API 响应契约

`POST /api/parse` 在原有字段基础上新增以下向后兼容字段：

- `platform_id`：机器可读平台 ID，例如 `douyin`。
- `platform_category`：平台类型，例如 `domestic_short_video`。
- `compliance_note`：当前平台的合规边界说明。

前端仍可继续读取 `source_site`、`extractor` 和 `formats`，新增字段不会破坏旧契约。

## 4. 错误码分类

| 错误码 | HTTP 状态 | 含义 |
| --- | --- | --- |
| `platform_restricted` | 403 | 登录、会员、付费、版权、DRM、地区或私密内容受限 |
| `platform_rate_limited` | 429 | 平台限流、验证码或访问频率触发风控 |
| `unsupported_platform` | 422 | 链接不是当前支持的视频平台或明显无效 |
| `platform_unavailable` | 503 | 平台暂不可访问、网络超时或临时故障 |
| `parse_failed` | 422 | 公开视频解析失败或平台暂不支持 |

## 5. 测试策略

- 单元测试使用 monkeypatch，不依赖真实平台网络。
- 默认 `npm test` 必须覆盖平台画像、解析错误分类、API 契约、任务前置校验。
- 真实平台解析能力通过手动 smoke 脚本执行，样例文件不得包含 Cookie、token、私密链接或未授权内容。
