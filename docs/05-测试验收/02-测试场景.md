# 测试场景

更新时间：2026-05-02

## 成功场景

- 输入公开视频链接，解析出标题、封面、时长和格式列表。
- 选择 MP4 格式后创建下载任务。
- 下载任务从排队进入运行，再进入完成。
- 下载完成后能获取文件。
- 文件名不包含非法字符或路径穿越片段。

## 失败场景

- 输入空链接，提示用户补充链接。
- 输入非 URL 文本，提示格式错误。
- 输入不支持平台链接，提示当前平台不在支持范围。
- 平台解析失败，提示平台规则可能变化。
- 下载超时，提示可重试。
- 文件超过大小限制，提示当前限制。

## 合规场景

- 输入明显涉及 DRM、付费墙或会员内容的链接时拒绝处理或提示风险。
- 用户提交含 token、signature、auth、cookie、key 参数的链接时，日志必须脱敏。
- 默认测试样例不得包含受保护、付费、隐私或盗版内容。
