# 测试场景

更新时间：2026-05-03

## 后端 Smoke 场景

服务启动后执行：

```bash
./scripts/dev_install.sh
./scripts/dev_test.sh
BASE_URL=http://localhost:8000 ./scripts/smoke_api.sh
BASE_URL=http://localhost:8000 ./scripts/smoke_parse_samples.sh
BASE_URL=http://localhost:8000 ./scripts/smoke_compliance_negative.sh
BASE_URL=http://localhost:8000 ./scripts/smoke_download_task.sh
BASE_URL=http://localhost:8000 ./scripts/smoke_bilibili_chrome.sh
```

该脚本验证：

- `/health` 可访问。
- `/ready` 可访问，并确认 PostgreSQL、Redis、MinIO / S3、FFmpeg / ffprobe 在本地均可用。
- M1 本地单用户模式下无需登录即可创建任务、查询任务列表、查询任务详情、查询事件、取消任务和重试失败/取消任务。
- 未完成任务请求下载链接时返回 `409`。
- 小文件下载样例可以从 queued / running 流转到 succeeded，获取后端短期签名下载链接，并实际下载到非空文件。
- 伪造下载签名返回 `403`，下载链接不能包含 MinIO / S3 内部地址。
- `GET /api/tasks` 支持 `state` 和 `limit` 参数，用于工作台轻量展示和任务历史筛选。
- B 站本机链路可以解析真实 B 站链接，默认生成推荐下载格式，并由本机 Worker 下载、上传和通过后端代理返回非空文件。

## 待补齐自动化场景

后续应将以下场景补齐为脚本或测试用例：

- Redis / RQ 不可用时任务创建失败并返回 `queue_unavailable`。
- 未完成任务请求下载链接时返回 `invalid_state`。
- 过期文件请求下载链接时返回 `retention_expired`。
- 超时的 queued / running 任务会被标记为 `task_timeout`，不继续占用并发名额。
- 含 `token`、`signature`、`auth`、`cookie`、`key`、`access_token`、`session` 参数的 URL 在日志或错误中必须脱敏。
- 文件名含路径穿越片段时必须被清洗。
- 输入 `bilibili.com/video/...` 这类无协议链接时，前后端应自动补 `https://` 或返回明确中文错误，不允许静默失败。
- 输入 B 站链接时，解析结果中的 `duration_seconds` 必须为整数，不能因 yt-dlp 返回浮点时长导致 API 500。
- B 站格式列表优先展示“推荐下载”，避免用户误选纯视频或纯音频格式。
- Chrome 登录态不可读时，任务失败原因必须提示本机浏览器登录态不可读和处理路径。
- 过期对象清理后，任务历史仍保留，文件入口显示 `retention_expired` 并提示重试。

## 成功场景

- 输入公开视频链接，解析出标题、封面、时长和格式列表。
- 输入无协议域名链接时自动补全协议再解析。
- 选择 MP4 格式后创建下载任务。
- 下载任务从排队进入运行，再进入完成。
- 下载完成后能通过后端短期签名代理 URL 获取文件。
- 成功任务在前端显示下载文件入口、文件大小和过期时间。
- 失败、取消或过期任务可以创建新的重试任务，旧任务保留历史事件。
- 文件名不包含非法字符或路径穿越片段。
- 本地必须支持 FFmpeg / ffprobe，下载任务完成时必须执行媒体文件校验。
- 本机 Chrome 已登录 B 站时，Worker 可读取本机登录态下载当前用户自己可访问且有权保存的内容；该过程不保存 Cookie。

当前已通过的小文件下载样例：

- `https://commons.wikimedia.org/wiki/File:%22Movbild-fizika%22_falo_en_Big_Buck_Bunny.webm`

当前已通过的公开解析样例：

- `https://vimeo.com/777912896`：Twenty Years of Creative Commons (in Sixty Seconds)，CC BY 4.0。
- `https://vimeo.com/13864570`：A Shared Culture，Creative Commons channel。
- `https://vimeo.com/12548408`：Public Domain Video for SAW Video by RS and VC，Public Domain channel。

## 失败场景

- 输入空链接，提示用户补充链接。
- 输入非 URL 文本，提示格式错误。
- 输入不支持平台链接，提示当前平台不在支持范围。
- 平台解析失败，提示平台规则可能变化。
- 下载超时，提示可重试。
- 文件超过大小限制，提示当前限制。
- Redis / RQ 不可用时，任务创建失败并返回 `queue_unavailable`。

## 前端交互场景

- 工作台只展示新建下载、当前任务和少量最近关键任务，不把完整历史作为主内容。
- 工作台使用单列居中下载器布局，桌面和移动端都不出现左右分栏。
- 成功任务展示文件名、大小、过期时间和下载入口，但不使用大块绿色成功面板。
- smoke / 负向测试任务不应占据工作台重点区域。
- 任务历史页使用 ProTable 展示持久化任务，支持分页、状态筛选、详情、下载、重试和取消。
- 解析、创建任务、下载、重试、取消按钮在请求期间显示 loading 或 disabled。
- 任何异步失败都必须显示中文错误提示。
- 合规页允许和禁止边界使用单列上下展示。

## 合规场景

- 输入明显涉及 DRM、付费墙或会员内容的链接时拒绝处理或提示风险。
- 用户提交含 token、signature、auth、cookie、key 参数的链接时，日志必须脱敏。
- 默认测试样例不得包含受保护、付费、隐私或盗版内容。
- `scripts/smoke_compliance_negative.sh` 覆盖未完成任务获取下载链接、URL 脱敏、Cookie / DRM / 付费墙 / 平台绕过相关运行时代码扫描。
- 合规脚本只允许本机 Worker 使用 `cookiesfrombrowser`，不允许前端上传 Cookie、API 接收 Cookie、数据库保存 Cookie 或日志输出 Cookie。

## 上线级 SaaS 专用场景

以下场景不作为 M1 本地 MVP 阻塞项，后续通过 `production-saas-readiness` 单独恢复和验收：

- 注册重复邮箱时返回 `email_exists`。
- 登录密码错误时返回 `invalid_credentials`。
- 未登录访问解析、任务和下载链接接口时返回 `unauthorized`。
- 用户只能查询自己的任务。
- 管理员可以查看用户、调整用户配额，普通用户不能访问管理员接口。
- 用户配额超限时返回 `429`。
- `scripts/smoke_admin_quota.sh` 仅用于上线级 SaaS 验收。

## 合法样例管理规则

- 解析样例至少 3 个，必须是公开可访问、允许测试或来源明确的内容。
- 下载样例至少 1 个，必须控制文件大小，避免消耗过多带宽和磁盘。
- 样例 URL 不写入私密 token、Cookie、签名参数或个人账号信息。
- 如果平台规则变化导致样例失效，应替换样例并记录替换原因。
