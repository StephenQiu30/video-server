# 上线级 SaaS 验收标准

更新时间：2026-05-02

## 1. 验收目标

本文件用于判断系统是否达到“小范围内测 SaaS”的上线标准。它不替代 M1 本地验收；M1 验收继续以 [01-验收标准.md](01-验收标准.md) 为准。

上线级验收必须覆盖：

- API。
- 前端。
- 下载任务。
- 部署。
- 安全。
- 合规。
- 运维。

## 2. API 验收

| 验收项 | 标准 |
| --- | --- |
| 注册控制 | 注册入口可关闭或要求邀请码 |
| 登录鉴权 | 用户可登录，未登录不能访问任务 API |
| 当前用户 | 当前用户接口能返回账号状态和配额 |
| 任务归属 | 用户只能查看和操作自己的任务 |
| 配额限制 | 超过每日任务数、并发数、文件大小、存储占用时返回明确错误 |
| 管理员接口 | 管理员可查看用户、任务、调整配额、禁用用户 |
| 错误结构 | 失败响应可被前端展示，不泄露内部堆栈 |

当前脚本状态：

- `scripts/smoke_admin_quota.sh`：历史参考脚本，当前 M1 默认应用不挂载登录和管理员接口；重新启用上线级 SaaS 前必须同步修订。

## 3. 下载验收

| 验收项 | 标准 |
| --- | --- |
| 解析样例 | 至少 3 个合法公开视频样例解析成功 |
| 下载样例 | 至少 1 个小文件样例完成下载、合并、ffprobe 校验、上传和下载链接获取 |
| 状态流转 | 覆盖 queued、running、succeeded、failed、canceled |
| 失败样例 | URL 不可访问、格式不可用、文件过大、任务超时、存储失败均能归类 |
| 清理策略 | 超过保留时间的对象可被清理 |
| 下载链接 | 链接由后端授权生成，过期后不可继续使用 |

## 4. 前端验收

| 验收项 | 标准 |
| --- | --- |
| 登录注册 | 支持登录、注册控制提示和错误反馈 |
| 工作台 | 可粘贴 URL、解析、选择格式、创建任务 |
| 任务列表 | 可查看任务状态、失败原因和下载入口 |
| 任务详情 | 可查看任务阶段、文件信息、错误信息和下载链接状态 |
| 配额展示 | 用户能看到当前配额、剩余额度和保留时间 |
| 移动端 | 基础布局不重叠，核心操作可用 |

## 5. 部署验收

| 验收项 | 标准 |
| --- | --- |
| Compose | Web、API、Worker、PostgreSQL、Redis、MinIO 可通过 Compose 启动 |
| Nginx | HTTPS 入口可访问前端和 API |
| 健康检查 | `/health`、`/ready` 能反映数据库、队列、存储、媒体工具状态 |
| Worker | Worker 可消费任务并输出可追踪日志 |
| 对象存储 | bucket 私有，下载只能通过后端预签名 URL |
| 生产密钥 | JWT、数据库、MinIO 凭证必须替换默认值 |

## 6. 安全验收

| 验收项 | 标准 |
| --- | --- |
| 限流 | 登录、解析、创建任务等接口具备限流或配额限制 |
| 跨用户访问 | 用户不能读取、取消或下载其他用户任务 |
| 日志脱敏 | token、signature、auth、cookie、key、Authorization 不以明文落日志 |
| 文件名安全 | 文件名清洗，禁止路径穿越 |
| 私有存储 | 前端不持有 MinIO 管理密钥 |
| 过期链接 | 预签名 URL 有短期 TTL |

## 7. 合规验收

必须验证以下能力不被支持：

- DRM 规避。
- 付费墙绕过。
- 会员专属内容绕过。
- 私密链接或访问控制绕过。
- 用户平台 Cookie 托管。
- 平台专用绕过解析。
- 盗版传播或批量滥采。

产品页面和错误提示必须体现：

- 用户只能下载自己拥有版权、已获授权、公共领域或平台明确允许保存的内容。
- 系统不承诺支持所有平台。
- 高风险内容可能被拒绝或要求人工确认。

## 8. 放行标准

上线前必须同时满足：

- M1 本地验收通过。
- `production-saas-readiness` 任务中上线门禁全部通过。
- 后端测试、前端 lint/build、OpenSpec validation、Compose config 校验通过。
- 部署、备份、日志、清理、合规负向样例均有记录。
