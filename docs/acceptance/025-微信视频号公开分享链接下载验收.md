# 025 微信视频号公开分享链接下载验收

<!-- acceptance: in-progress -->

- 状态：In Progress
- 日期：2026-08-29

## 1. 自动化与安全门禁

- [x] 仅接受公开 `/sph/{id}` 单视频 URL，无效微信路径不回退 Generic。
- [x] Profile 为 `wechat-channels-public-v2` / `degraded` / anonymous-only。
- [x] 只调用第一方公开预览与 feed 接口，没有元宝、Cookie 或浏览器回退。
- [x] 媒体 URL 仅允许 `finder.video.qq.com/251/.../stodownload`。
- [x] `decodeKey`、DRM 与 encryption 非空时拒绝。
- [x] 第一方未公开媒体时返回受限状态，不产生 Artifact。
- [x] 不存在微信专用 Operator Runner、宿主机会话进程、Chrome Profile 或 Cookie 导出代码。
- [x] 下载仍经过重新 inspection、FFprobe、大小/时长和完整性验证。

## 2. C 端行为

- [x] Provider 页显示“仅直接公开媒体”和上传自有/已授权文件建议。
- [x] `agent-browser` 实测平台页将视频号显示为“支持下载 · 当前降级”、anonymous-only，且文案与 Registry 一致。
- [x] 全新部署无需任何个人微信/元宝登录态即可启动。
- [x] 开发者电脑离线不影响匿名解析、下载制品和后续 AI 任务。
- [x] 1280 宽屏与 390×844 均实测公开链接受限提示和本地 MP4 回退上传；移动端无页面级横向溢出，浏览器 console/error 为空。

## 3. 真实媒体门禁

- [ ] 至少一个项目自有或明确授权样本在公开 feed 中直接提供 clear 媒体。
- [ ] 样本完成 inspection、完整下载、FFprobe、SHA-256 与 Artifact 验证。
- [ ] 仅元数据、删除链接、恶意域名与保护字段负例均为零 Artifact。

## 4. 发布判断

当前可发布为 `degraded` 部分能力，不宣称任意视频号分享链接可下载。第 3 节完成前，不得提升为 `verified`。

2026-08-29 `agent-browser` 证据：固定公开分享页在 390×844 正确收敛为“平台未提供可直接下载的公开媒体”，不启动 Chrome、元宝或 Cookie 获取；随后同一移动流程上传独立生成的 2 秒 H.264 MP4，完成分片上传、服务端验证、Artifact 晋升与预览。该上传只证明 C 端合法回退路径，不会提升视频号 Provider canary。
