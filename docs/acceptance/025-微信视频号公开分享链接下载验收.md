# 025 微信视频号公开分享链接下载验收

<!-- acceptance: in-progress -->

- 状态：In Progress
- 日期：2026-08-27

## 1. 自动化门禁

- [x] 只接受公开 `/sph/{id}` 单视频 URL，无效微信路径不回退 Generic。
- [x] Profile 已注册，状态为 `access_required`，能力为 single/short video。
- [x] 匿名公开预检发生在元宝调用之前。
- [x] 匿名公开预检失败不读取/调用 operator resolver。
- [x] 无会话稳定返回 credential-required。
- [x] `hy_user`、`hy_token` 缺一不可，其他域 Cookie 被过滤。
- [x] playable URL 的 scheme/host/path/query 严格校验。
- [x] 媒体 URL 仅允许 `finder.video.qq.com/251/.../stodownload`。
- [x] `decodeKey`、DRM 与 encryption 非空时拒绝。
- [x] Provider status API 显示 registered/extractor/access-required。
- [x] 视频号相关测试 118 项通过；后端全量 1042 项通过（另有 1 项 Windows 预期跳过）。

## 2. 安全门禁

- [x] 普通 API 和前端没有 Cookie 上传入口。
- [x] 未加入公共 Worker、第三方解析站、MITM、根证书、代理抓包、注入或解密模块。
- [x] Cookie allowlist 只含元宝域，Operator Provider 已加入权益防火墙。
- [x] 解析 token、eid 与 Cookie 不进入持久化模型或用户响应。
- [x] 下载仍经过现有重新 inspection 与 FFprobe 完整性检查。
- [ ] 对运行日志、DB、MQ、trace、错误响应做真实会话 Secret 扫描。

## 3. 浏览器验收

- [x] Provider 页面显示“微信视频号 / 需受控会话”及正确行动建议。
- [x] 未部署 operator endpoint 时，公开链接显示清晰的隔离会话不可用提示。
- [x] 非 `/sph/` 微信链接显示不支持，不能出现下载格式。
- [x] 1280×900 与 390×844 无横向溢出，关键控件可见可操作。
- [x] 浏览器控制台无新增 error/warning。
- [x] `dogfood-output` 报告包含步骤、截图与 issue 统计。

## 4. 真实媒体门禁

- [ ] 运维通过本地导出器生成只读元宝 Secret，敏感值未进入聊天/终端日志/Git。
- [ ] 项目自有或明确授权公开样本完成匿名 metadata → operator resolve。
- [ ] 至少一个 H.264 或 H.265 clear 格式通过 FFprobe。
- [ ] 完整下载通过大小、时长、容器、轨道、SHA-256 与 Artifact 验证。
- [ ] 下载前重解析成功；旧签名 URL 未被复用。
- [ ] 无会话、过期会话、删除链接、恶意域名与保护字段负例均无媒体 Artifact。

## 5. 发布判断

自动化和 UI 门禁可以在无真实 Cookie 的环境完成，但不能替代真实媒体门禁。在第 4 节完成前，代码可发布为 `access_required`，不得把微信视频号标记为 `verified` 或对外承诺生产可用率。
