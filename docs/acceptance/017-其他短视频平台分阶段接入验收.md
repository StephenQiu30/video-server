## 1. 本批次范围

本批次验收 Rutube、VK Clips、批准实例 PeerTube 的安全入口，以及把已有完整视频异步分析链路转化为 Provider 发布证明。默认不配置任何第三方目标或 PeerTube 实例，不把代码存在、extractor 存在或 metadata 成功宣传为真实可用。

Agent 原则不变：生产分析交付完整视频文件，Agent 自主遍历完整时间轴并在疑似边界/高光附近细化观察；固定抽帧不能替代完整视频输入。

## 4. 真实发布操作

1. 只在未跟踪的 Secret 环境配置项目自有或明确授权 target。
2. 完成 metadata/media 后，通过正常 API 创建完整视频分析，等待 RabbitMQ、Agent、数据库与报告 Worker 成功。
3. 执行 `python -m app.workers.canary.attest --target-id ... --analysis-job-id ...`。
4. 确认三阶段窗口满足后，才把对应 key 加入 `PROVIDER_VERIFIED_KEYS`。
5. 生产状态、浏览器、监控和 CI 全部通过后更新本文件；所有已登记平台通过 `archive_ready` 前不得归档。

## 5. 发布边界

本批次可以发布控制面、严格 Profile、PeerTube 白名单与 analysis 证明能力，但不能宣称 AcFun、Rutube、VK、PeerTube 或其他 pending 平台已真实支持下载/AI 分析。Snapchat、西瓜视频和可信插件候选仍按 Design/PRD 的安全前置条件实施。
