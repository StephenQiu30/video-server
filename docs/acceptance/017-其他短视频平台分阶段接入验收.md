## 1. 本批次范围

本批次验收批准实例 PeerTube 的安全入口，以及把已有完整视频异步分析链路转化为 Provider 发布证明。默认不配置任何第三方目标或 PeerTube 实例，不把代码存在、extractor 存在或 metadata 成功宣传为真实可用。

Agent 原则不变：生产分析交付完整视频文件，Agent 自主遍历完整时间轴并在疑似边界/高光附近细化观察；固定抽帧不能替代完整视频输入。

## 4. 真实发布操作

1. 只在未跟踪的 Secret 环境配置项目自有或明确授权 target。
2. 完成 metadata/media 后，通过正常 API 创建完整视频分析，等待 RabbitMQ、Agent、数据库与报告 Worker 成功。
3. 执行 `python -m app.workers.canary.attest --target-id ... --analysis-job-id ...`。
4. 确认三阶段窗口满足后，才把对应 key 加入 `PROVIDER_VERIFIED_KEYS`。
5. 生产状态、浏览器、监控和 CI 全部通过后更新本文件，并将顶部唯一机器标记从 `acceptance: pending` 改为 `acceptance: accepted`。
6. 先执行 `python -m app.workers.canary.archive` 只读复核，再执行 `python -m app.workers.canary.archive --apply`；命令会在运行时门禁和验收标记同时通过后移动四份文档并更新索引。

## 5. 发布边界

本批次可以发布控制面、PeerTube 白名单与 analysis 证明能力，但不能宣称 PeerTube 或其他 pending 平台已真实支持下载/AI 分析。AcFun、Rutube、VK Clips、Dailymotion 和 NicoNico 明确不支持；Snapchat、西瓜视频和可信插件候选仍按 Design/PRD 的安全前置条件实施。注：Snapchat Spotlight 已于 2026-08-12 通过下载层（metadata/最小媒体/ffprobe/SHA-256）验证，详见 §8；西瓜视频受控会话与完整三阶段发布证明仍为 Pending。
