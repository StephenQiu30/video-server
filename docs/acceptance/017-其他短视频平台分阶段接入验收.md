## 1. 本批次范围

本批次只验收通用 Provider 探针控制面与 AcFun Profile，不把 AcFun 或其他新增平台声明为真实可用。探针目标默认 `[]`，没有项目自有或明确授权 URL 时不会访问第三方。

完整视频 AI 原则不变：生产分析继续由既有 API → Outbox → RabbitMQ → Agent → 数据库/MinIO → WebSocket 链路处理完整视频，不以固定抽帧替代。当前 Provider 探针只完成下载层 metadata/media 验证，没有在本批次重新执行 AcFun 完整视频 Agent E2E。

## 4. 发布边界

本批次可以发布探针控制面和 AcFun 的 `unknown` Profile，但不能宣传 AcFun 已支持下载或 AI 分析。生产启用某个 target 前，必须确认目标归项目所有或已明确授权，并把真实 URL 仅放在未跟踪的 Secret 环境。

只有以下事实全部成立后，才能单独批准 AcFun `verified`：新鲜授权 metadata、完整媒体下载、ffprobe/SHA-256、MinIO 原始视频、RabbitMQ、Agent 读取完整视频、分镜/高光报告、数据库、MD/DOCX、WebSocket、原任务重试和 CI。Rutube、VK、PeerTube、西瓜视频及插件候选不在本批次实现范围。
