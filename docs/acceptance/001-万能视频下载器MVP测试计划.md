## 5. 残余风险

1. **外部平台反爬**：yt-dlp 依赖的视频平台可能更新反爬策略，导致下载失败。需要持续监控和更新 yt-dlp 版本。
2. **S3 服务可用性**：对象存储服务不可用时，所有上传和下载操作将失败。
3. **AI API 限额**：Groq 和 DeepSeek API 的速率限制可能影响高并发场景下的 AI 摘要生成。
4. **浏览器 Cookie 兼容性**：不同操作系统和浏览器版本的 Cookie 提取可能存在兼容性问题。
