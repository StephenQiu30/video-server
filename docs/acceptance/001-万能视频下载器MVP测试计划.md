# 万能视频下载器 MVP 测试计划

## 1. 背景

本文档定义万能视频下载器 MVP 阶段的测试计划，覆盖解析、格式选择、下载、错误处理和合规性等核心功能。

## 2. 测试范围

### 2.1 解析功能

| 测试场景 | 验证内容 | 预期结果 |
| --- | --- | --- |
| 公开视频解析 | 标题、封面、时长、格式列表 | 至少 3 个公开样例解析成功 |
| 清晰度预设 | 推荐、1080p、720p、480p、360p | 五类预设均返回，包含 quality_label、available、note |
| 降级处理 | 平台不提供高清晰度 | 提示不可用或自动降级 |
| 不可用处理 | 平台不提供视频流 | 所有预设 available: false |

### 2.2 格式选择

| 测试场景 | 验证内容 | 预期结果 |
| --- | --- | --- |
| raw 格式 | format_id、分辨率、文件大小 | 包含完整元数据 |
| recommended 格式 | 标识和说明 | 标注为"推荐下载" |
| video 格式 | 清晰度预设 | 正确映射到预设 |

### 2.3 无水印策略

| 测试场景 | 验证内容 | 预期结果 |
| --- | --- | --- |
| 已知带水印平台 | note 字段 | 提示"该来源可能包含平台水印" |
| 无水印来源 | note 字段 | 不包含水印提示 |
| 去水印能力 | 代码扫描 | 不包含主动去水印逻辑 |

### 2.4 下载功能

| 测试场景 | 验证内容 | 预期结果 |
| --- | --- | --- |
| 小文件下载 | 创建任务、下载、上传、代理下载 | 至少 1 个样例完成全流程 |
| 任务状态 | queued、running、succeeded、failed、canceled | 状态正确流转 |
| 进度更新 | SSE 进度推送 | 实时更新下载进度 |

### 2.5 错误处理

| 测试场景 | 验证内容 | 预期结果 |
| --- | --- | --- |
| 不支持平台 | 错误提示 | 明确提示"该链接暂不支持解析" |
| 网络失败 | 错误提示 | 明确提示"平台暂时不可访问" |
| 格式不可用 | 错误提示 | 明确提示"该来源未提供此清晰度" |
| 文件过大 | 错误提示 | 明确提示文件大小限制 |
| 超时 | 错误提示 | 明确提示超时原因 |

### 2.6 合规性

| 测试场景 | 验证内容 | 预期结果 |
| --- | --- | --- |
| URL 脱敏 | 日志和错误输出 | 不暴露原始 URL |
| 文件名清洗 | 存储文件名 | 不包含特殊字符 |
| 合规提示 | 下载前提示 | 体现授权和合法使用边界 |
| DRM/付费墙 | 代码扫描 | 不包含规避逻辑 |

## 3. 测试命令

### 3.1 清晰度预设测试

```bash
PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_download_adapter.py -q
```

### 3.2 高级格式与水印提示测试

```bash
PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_download_adapter.py apps/api/tests/test_openapi_contract.py -q
```

### 3.3 全量测试

```bash
PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/ -q
```

### 3.4 合规负向测试

```bash
BASE_URL=http://127.0.0.1:8000 PYTHON_BIN=.venv/bin/python ./scripts/smoke_compliance_negative.sh
```

## 4. 验收标准

- 解析结果稳定返回推荐、最高 1080p、720p、480p、360p 五类预设。
- 每个预设包含 `quality_label`、`available` 和 `note`。
- 平台未提供对应清晰度时提示不可用或自动降级。
- 产品表述限定为优先可公开获取的无水印或原始源。
- 不包含主动去水印、裁剪或 AI 修复能力。
- 相关测试通过验证命令。

## 5. 风险与边界

- 不同平台的 yt-dlp 格式元数据质量不一。
- 水印状态判断依赖平台已知特征。
- 本机 B 站下载链路需要 Chrome 登录态。
