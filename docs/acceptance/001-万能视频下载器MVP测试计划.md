# 测试计划 001：万能视频下载器 MVP

更新时间：2026-06-02
关联 Issue：STE-51, STE-58, STE-59
父 PRD：`docs/prd/003-下载任务与产物归档.md`

## 1. 测试范围

本测试计划覆盖 PRD003 定义的下载任务生命周期、主视频产物和增强产物归档。

## 2. 主链路正向测试

### 2.1 解析与创建任务

| ID | 用例 | 步骤 | 预期结果 |
|---|---|---|---|
| T-001 | 公开视频解析 | POST /api/parse，URL=公开视频 | 返回 title、formats、duration_seconds |
| T-002 | 创建下载任务 | POST /api/tasks，format_id=recommended | 返回 state=queued, progress=0 |
| T-003 | 查询任务状态 | GET /api/tasks/{id} | 返回最新状态和进度 |
| T-004 | 查询任务事件 | GET /api/tasks/{id}/events | 返回按时间排序的事件列表 |

### 2.2 下载与交付

| ID | 用例 | 步骤 | 预期结果 |
|---|---|---|---|
| T-005 | 任务完成 | 等待 Worker 处理 | state=succeeded, progress=100 |
| T-006 | 获取下载链接 | GET /api/tasks/{id}/download-link | 返回短期预签名 URL |
| T-007 | 下载文件 | 访问预签名 URL | 返回有效视频文件 |
| T-008 | 文件过期 | 等待 retention_hours | object_key 清空，failure_code=retention_expired |

### 2.3 重试与取消

| ID | 用例 | 步骤 | 预期结果 |
|---|---|---|---|
| T-009 | 取消排队任务 | POST /api/tasks/{id}/cancel | state=canceled |
| T-010 | 重试失败任务 | POST /api/tasks/{id}/retry | 创建新任务，retry_of_task_id 有值 |
| T-011 | 重试链路 | 连续重试 3 次 | 每次 attempt_no 递增，链路完整 |

## 3. 主链路失败测试

### 3.1 环境失败

| ID | 用例 | 步骤 | 预期结果 |
|---|---|---|---|
| T-020 | FFmpeg 缺失 | 移除 ffmpeg 路径 | failure_code=media_tools_missing |
| T-021 | FFprobe 缺失 | 移除 ffprobe 路径 | failure_code=media_tools_missing |
| T-022 | 文件过大 | 下载超过 max_file_size | failure_code=file_too_large |

### 3.2 下载失败

| ID | 用例 | 步骤 | 预期结果 |
|---|---|---|---|
| T-030 | 无效 URL | 创建任务，URL 无效 | failure_code=download_failed |
| T-031 | 格式不可用 | 选择不存在的 format_id | failure_code=format_unavailable |
| T-032 | 不支持平台 | 使用不支持的 URL | failure_code=unsupported_platform |
| T-033 | 任务超时 | 超过 max_task_runtime | failure_code=task_timeout |

### 3.3 存储失败

| ID | 用例 | 步骤 | 预期结果 |
|---|---|---|---|
| T-040 | 对象存储不可用 | 停止 MinIO | failure_code=storage_failed |
| T-041 | 队列不可用 | 停止 Redis | failure_code=queue_unavailable |

### 3.4 错误消息

| ID | 用例 | 预期结果 |
|---|---|---|
| T-050 | 失败有中文描述 | failure_reason 为用户友好的中文 |
| T-051 | URL 脱敏 | failure_reason 不暴露 token/signature |
| T-052 | 错误码可分类 | failure_code 在预定义枚举中 |

## 4. 增强产物测试

### 4.1 正向测试

| ID | 用例 | 步骤 | 预期结果 |

| T-061 | 封面可用 | 下载带封面的视频 | thumbnail_key 有值 |

## 5. 合规与边界测试

### 5.1 配额限制

| ID | 用例 | 步骤 | 预期结果 |
|---|---|---|---|
| T-090 | 日额度超限 | 创建 daily_task_quota+1 个任务 | 返回 429 |
| T-091 | 并发超限 | 同时创建 concurrent+1 个任务 | 返回 429 |
| T-092 | 存储超限 | 超过 storage_quota_bytes | 返回 429 |

### 5.2 权限边界

| ID | 用例 | 步骤 | 预期结果 |
|---|---|---|---|
| T-100 | 无权访问他人任务 | 查询他人 task_id | 返回 404 |
| T-101 | 无权下载他人文件 | 获取他人下载链接 | 返回 404 |
| T-102 | 未登录访问 | 无 token 访问 API | 返回 401 |

### 5.3 合规负向

| ID | 用例 | 步骤 | 预期结果 |
|---|---|---|---|
| T-110 | 无 DRM 绕过 | 扫描代码 | 无 DRM 相关实现 |
| T-111 | 无付费墙绕过 | 扫描代码 | 无付费墙绕过实现 |
| T-112 | Cookie 不入库 | 检查数据库 | Cookie 不存储在任何字段 |
