# 万能视频下载器 MVP 测试计划

## 1. 背景

本测试计划覆盖万能视频下载器 MVP 阶段的核心验收场景，包括：

1. 自部署浏览器 Cookie 配置（PRD005-01）
2. 限流配额与合规负向（PRD005-02）

测试计划与 Linear 子任务 STE-62 和 STE-63 对齐。

## 2. 测试范围

### 2.1 PRD005-01 自部署浏览器 Cookie 配置

对应子任务：STE-62

| 编号 | 测试场景 | 前置条件 | 测试步骤 | 预期结果 |
| --- | --- | --- | --- | --- |
| TC-01-01 | 支持浏览器类型 - chrome | 设置 `YT_DLP_COOKIES_BROWSER=chrome` | 调用 `build_cookie_args()` | 返回 `["--cookies-from-browser", "chrome"]` |
| TC-01-02 | 支持浏览器类型 - firefox | 设置 `YT_DLP_COOKIES_BROWSER=firefox` | 调用 `build_cookie_args()` | 返回 `["--cookies-from-browser", "firefox"]` |
| TC-01-03 | 支持浏览器类型 - 大小写不敏感 | 设置 `YT_DLP_COOKIES_BROWSER=Firefox` | 调用 `build_cookie_args()` | 返回 `["--cookies-from-browser", "firefox"]` |
| TC-01-04 | 无效浏览器类型 | 设置 `YT_DLP_COOKIES_BROWSER=invalid` | 调用 `build_cookie_args()` | 返回 `[]`，记录警告日志 |
| TC-01-05 | 有效 Cookie 文件 | 设置 `YT_DLP_COOKIES_FILE=/path/to/cookies.txt`，文件存在 | 调用 `build_cookie_args()` | 返回 `["--cookies", "/path/to/cookies.txt"]` |
| TC-01-06 | 无效 Cookie 文件路径 | 设置 `YT_DLP_COOKIES_FILE=/nonexistent` | 调用 `build_cookie_args()` | 返回 `[]`，记录警告日志 |
| TC-01-07 | 文件优先于浏览器 | 同时设置两个变量 | 调用 `build_cookie_args()` | 使用文件方式 |
| TC-01-08 | 未配置 Cookie | 两个变量均为空 | 调用 `build_cookie_args()` | 返回 `[]`，行为不变 |

### 2.2 PRD005-02 限流配额与合规负向

对应子任务：STE-63

| 编号 | 测试场景 | 前置条件 | 测试步骤 | 预期结果 |
| --- | --- | --- | --- | --- |
| TC-02-01 | 生产配置 - JWT_SECRET_KEY 缺失 | 删除 `JWT_SECRET_KEY` | 运行 `validate_prod_env.py` | 报错 |
| TC-02-02 | 生产配置 - JWT_SECRET_KEY 占位值 | 设置 `JWT_SECRET_KEY=CHANGE_ME` | 运行 `validate_prod_env.py` | 报错 |
| TC-02-03 | 生产配置 - JWT_SECRET_KEY 过短 | 设置 `JWT_SECRET_KEY=short` | 运行 `validate_prod_env.py` | 报错（< 32 位） |
| TC-02-04 | 生产配置 - localhost 连接 | 数据库连接指向 `localhost` | 运行 `validate_prod_env.py` | 警告 |
| TC-02-05 | 合规负向 - 无效协议 | 提交 `ftp://example.com/video.mp4` | 创建任务 | 返回 422，错误码 `invalid_url` |
| TC-02-06 | 合规负向 - localhost | 提交 `http://localhost:8000/video` | 创建任务 | 返回 422，错误码 `reserved_domain` |
| TC-02-07 | 合规负向 - 内网地址 | 提交 `http://192.168.1.1/video.mp4` | 创建任务 | 返回 422，错误码 `private_network` |
| TC-02-08 | 合规负向 - .local 域名 | 提交 `http://myserver.local/video.mp4` | 创建任务 | 返回 422，错误码 `reserved_domain` |
| TC-02-09 | 合规负向 - 127.0.0.1 | 提交 `http://127.0.0.1/video.mp4` | 创建任务 | 返回 422，错误码 `reserved_domain` |
| TC-02-10 | 限流 - parse 接口 | 1 分钟内第 61 次调用 `/api/parse` | 发送请求 | 返回 429，错误码 `rate_limited` |
| TC-02-11 | 限流 - create_task 接口 | 1 分钟内第 21 次调用 `/api/tasks` | 发送请求 | 返回 429，错误码 `rate_limited` |
| TC-02-12 | 限流 - Redis 不可用 fallback | Redis 不可用 | 调用限流接口 | 请求通过（fail-open），记录告警 |

## 4. 验收标准

### 4.1 PRD005-01 验收标准

- [ ] `build_cookie_args()` 覆盖支持浏览器、关闭值和无效值。
- [ ] Cookie 仅在自部署本机环境使用，SaaS 无 Cookie 上传/托管入口。
- [ ] Cookie 不写入日志、数据库或对象存储。
- [ ] 配置校验对无效值记录警告但不阻断 Worker。
- [ ] 单元测试全部通过。

### 4.2 PRD005-02 验收标准

- [ ] 生产配置校验覆盖 JWT_SECRET_KEY、占位值、连接地址等检查项。
- [ ] 合规负向检查覆盖无效协议、localhost、内网地址、.local 域名。
- [ ] 限流在 `/api/parse`、`/api/tasks`、登录、注册接口均有测试覆盖。
- [ ] Redis 不可用时 fallback 行为有测试覆盖。
- [ ] Smoke 脚本 `scripts/smoke_compliance_negative.sh` 执行通过。
- [ ] 所有测试通过。

### 4.3 边界验收标准

- [ ] Cookie 仅允许自部署本机环境配置，不提供 SaaS 上传、托管、共享或账号池。
- [ ] 合规负向检查防止后端成为探测内网或滥用平台的工具。
- [ ] 产品文案不宣传"下载任意受保护内容"。

## 5. 风险与残余问题

| 风险 | 影响 | 缓解措施 |
| --- | --- | --- |
| yt-dlp `--cookies-from-browser` 兼容性 | 部分浏览器/OS 可能不支持 | 测试覆盖主流浏览器，不支持时降级为无 Cookie 模式 |
| Redis fail-open 降低防滥用强度 | 限流可能被绕过 | 可配置切换 fail-closed |
| 合规负向检查不能覆盖所有边界 | 可能遗漏新型攻击向量 | 持续迭代，日志监控 |
| Smoke 脚本依赖运行中服务 | 不适合默认 CI | 仅在验收环境执行 |
