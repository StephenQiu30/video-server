# 测试计划：万能视频下载器 MVP — 链接解析与平台识别

## 1. 测试范围

本测试计划覆盖 PRD001 链接解析与平台识别的全部验收标准，包括：

- URL 规范化与安全校验
- 平台画像识别
- 解析错误语义分类
- 合规边界与脱敏

## 2. 测试场景

### 2.1 URL 规范化（test_url_normalization.py）

| 编号 | 场景 | 输入 | 预期结果 |
| --- | --- | --- | --- |
| URL-01 | trim 空格并补协议 | `"  bilibili.com/video  "` | `https://bilibili.com/video` |
| URL-02 | 保留已有 https | `https://bilibili.com/video` | `https://bilibili.com/video` |
| URL-03 | 拒绝 ftp scheme | `ftp://example.com/video` | AppError `invalid_url` 422 |
| URL-04 | 拒绝纯文本 | `"hello world"` | AppError `invalid_url` 422 |
| URL-05 | 拒绝 localhost | `http://localhost/video` | AppError `invalid_url` 422 |
| URL-06 | 拒绝 127.x 本机地址 | `http://127.0.0.1/video` | AppError `invalid_url` 422 |
| URL-07 | 拒绝 10.x 内网地址 | `http://10.0.0.1/video` | AppError `invalid_url` 422 |
| URL-08 | 拒绝 172.16.x 内网地址 | `http://172.16.0.1/video` | AppError `invalid_url` 422 |
| URL-09 | 拒绝 192.168.x 内网地址 | `http://192.168.1.1/video` | AppError `invalid_url` 422 |

### 2.2 平台画像识别（test_platform_profiles.py）

| 编号 | 平台 | 示例域名 | 预期 platform_id | 预期 category |
| --- | --- | --- | --- | --- |
| PF-01 | 抖音 | douyin.com | douyin | domestic_short_video |
| PF-02 | 快手 | kuaishou.com | kuaishou | domestic_short_video |
| PF-03 | 小红书 | xiaohongshu.com | xiaohongshu | domestic_short_video |
| PF-04 | 西瓜视频 | ixigua.com | ixigua | domestic_short_video |
| PF-05 | 微博 | weibo.com | weibo | domestic_short_video |
| PF-06 | B 站 | bilibili.com | bilibili | long_video |
| PF-07 | YouTube | youtube.com | youtube | long_video |
| PF-08 | TikTok | tiktok.com | tiktok | short_video |
| PF-09 | Vimeo | vimeo.com | vimeo | long_video |
| PF-10 | Dailymotion | dailymotion.com | dailymotion | long_video |

每个平台断言字段完整性：`id`、`display_name`、`category`。
高风险平台额外断言 `compliance_note` 非空。

### 2.3 错误语义分类（test_parse_error_classification.py）

| 编号 | 场景 | 错误消息关键词 | 预期错误码 | 预期 HTTP |
| --- | --- | --- | --- | --- |
| ERR-01 | 登录要求 | "Login required" | platform_restricted | 403 |
| ERR-02 | DRM/付费 | "DRM", "premium" | platform_restricted | 403 |
| ERR-03 | 会员内容 | "members only" | platform_restricted | 403 |
| ERR-04 | 限流 | HTTP 429 | platform_rate_limited | 429 |
| ERR-05 | 验证码 | "captcha", "verification" | platform_rate_limited | 429 |
| ERR-06 | 不支持 URL | "Unsupported URL" | unsupported_platform | 422 |
| ERR-07 | 通用失败 | 其他 | parse_failed | 422 |

### 2.4 合规边界与脱敏

| 编号 | 场景 | 验证方式 |
| --- | --- | --- |
| CMP-01 | 错误响应不含 token/signature/auth/cookie/key/access_token/session | 检查错误响应 body |
| CMP-02 | 日志不含完整敏感链接 | 代码审查（运行时扫描） |
| CMP-03 | 不包含 DRM 规避代码 | 运行时代码扫描 |
| CMP-04 | 不包含 Cookie 托管代码 | 运行时代码扫描 |
| CMP-05 | 不包含付费墙绕过代码 | 运行时代码扫描 |
