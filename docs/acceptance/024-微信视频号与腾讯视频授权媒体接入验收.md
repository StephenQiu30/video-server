## 1. 验收边界

验收分为文档/安全基线、统一决策、公众号文章、视频号文件导入、腾讯消费站、腾讯云 VOD、数据/队列、安全隐私、API/UI 和真实运行十个独立门禁。某一执行模式通过不能批准另一模式：

- 公众号原生视频成功不能批准视频号链接下载。
- 视频号本地文件成功不能写平台下载 canary。
- VOD 自有媒资成功不能批准腾讯视频会员导出。
- fake SDK、fixture、HTTP 200、metadata、M3U8 或片段成功都不是完整媒体验收。
- 腾讯公开视频机制未获批时必须保持 disabled，不能以其他阶段成功替代。

## 4. 微信公众号文章 discovery 与原生视频

### 4.1 URL、获取和静态解析

- [x] `mp.weixin.qq.com` 文章和 `weixin.qq.com/sph/...` 视频号准确分流。
- [x] 只接受批准的 `/s/{opaque}` 和 query allowlist；credentials、非默认端口、ticket 和未知 query 拒绝。
- [x] Adapter 只使用标准 HTTP、普通 UA、人类阅读速率和有界响应，不执行页面 JS。
- [x] 挑战、验证码、登录、关注、付费、异常/过大 HTML 返回 `article_access_restricted`，没有 headless/stealth/Cookie/第三方 API 回退。
- [x] 原始 HTML、inline data、article ticket、iframe/CDN signed URL 不进入日志、错误、DB、MQ、trace 或响应。

### 4.2 Discovery 和选择

- [x] 零视频文章返回空 discovery，不创建 inspection。
- [x] 单个和多个视频都返回有界 item 列表并要求用户确认，绝不默认第一项。
- [x] item 正确分类为 `official_account_native/tencent_video/wechat_channels/unknown`。
- [x] 腾讯 iframe 遵循 qqvideo disabled/审批状态，视频号 embed 返回 export-required，unknown 不进入 Generic。
- [x] discovery/item ref 随机、owner-scoped、有 TTL；过期、重复、跨 owner 和猜测 ref 负例通过。

### 4.3 原生媒体身份和完整 E2E

- [x] 只有 `mpvid/internal media id/representation` 唯一绑定时生成候选；不使用 DOM/数组顺序猜测。
- [x] 数量错配、重复 id、映射歧义、schema drift 返回 `article_video_identity_unverified`，零媒体正文。
- [ ] CDN 仅允许批准的 HTTPS host/path，每跳重做 DNS/IP/redirect admission，不携带任意用户 header/Cookie。
- [ ] 下载前重取文章并验证 article/item/media identity；删除、变化或短时 URL 过期不复用旧地址。
- [ ] `article_native` 使用独立 outbox/queue/DLQ/Article Media Worker；消息只含内部 id，Download Worker 不 claim，Article Worker 不访问 Generic/Cookie/VOD Secret。
- [ ] Article Worker 写 quarantine 后通过共享 `ImportIntakePort` 幂等创建 import/attempt，再由无外网 Import Worker 复验；重复消息和崩溃不产生第二个 Artifact。
- [ ] 多清晰度来自当次真实绑定表示，不固定最低清晰度、不虚构格式。
- [ ] 项目自有/授权单视频和多视频文章完成 discovery → 选择 → inspection → 完整下载 → ffprobe/SHA-256 → Artifact → Analysis → MD/DOCX → WebSocket。
- [x] signed URL 泄漏扫描为零，供应链无 Camoufox/第三方文章服务运行依赖。
- [ ] 新鲜独立 canary 和显式批准前，文章 native download 不显示 verified。

## 14. 当前结论

当前已完成 Phase 0 的主要安全切片、公众号公开文章 discovery/显式选择、视频号 `export_required` 路由和自有 clear MP4 导入闭环；公众号原生媒体仍只返回 blocked 候选，腾讯消费站只完成 `playback_only` 安全解析，腾讯云 VOD 官方连接器尚未实现。本验收保持 `in-progress`：可以宣称“公众号文章视频可安全发现并选择、视频号自有/获授权明文 MP4 可导入”，不得宣称视频号分享链接、公众号原生视频、腾讯 VIP 或腾讯云 VOD 已支持下载。
