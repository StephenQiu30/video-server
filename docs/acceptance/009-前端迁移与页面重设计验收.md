## 验收前置

- 使用与生产一致的 Node.js、npm、Python 和锁文件安装依赖。
- FastAPI 使用可重复测试数据；至少准备普通用户、管理员、活跃下载、成功下载、失败下载和成功 AI 分析。
- 视觉首页使用用户选定方案 2 原图 `exec-093b654f-524e-4641-aeb6-a196aa75c23c.png`（1487×1058）作为唯一参考。
- 浏览器验证至少覆盖 1487×1058 桌面视口和 390×844 移动视口。

## 逐项验收

### A1 技术栈与目录（AC-009-01）

- [ ] `frontend/src/app/` 是唯一页面入口，路由使用 App Router；不存在 Pages Router 或 Umi 路由。
- [ ] 运行依赖包含 Next.js、React、Radix UI、Tailwind CSS；开发依赖直接包含 `@umijs/openapi`。
- [ ] `@umijs/max`、`antd`、`@ant-design/*`、Ant Design Pro、Umi OpenAPI 插件和 Less 已从依赖与源码移除。
- [ ] `src/components/ui/` 只封装 Radix/原生语义控件，页面没有第二套主题或组件系统。

### A2 路由、认证与权限（AC-009-02）

- [ ] `/`、`/history`、`/account`、`/admin/users`、`/downloads/detail?jobId=`、`/user/login`、`/user/register` 和 404 均可直接打开与刷新。
- [ ] 未登录访问受保护页面会跳到登录并携带安全站内 `redirect`；登录后返回原目标。
- [ ] 外部、协议相对、反斜杠和认证页循环 redirect 被拒绝。
- [ ] 普通用户看不到且无法渲染管理员页面；管理员权限变更从后端最新账户状态生效。

### A3 首页核心流程（AC-009-03）

- [ ] 有效公开链接可完成解析，返回真实媒体摘要和可用语义格式。
- [ ] 格式列表使用可键盘操作的单选语义，默认选择明确，开始下载使用该格式。
- [ ] 重复提交受到禁用/幂等保护，成功创建任务后进入 `/downloads/detail?jobId=<id>`。
- [ ] 初始、URL 校验失败、解析中、解析失败、无格式、已解析、创建中七种状态均有稳定布局和恢复动作。
- [ ] 合法使用提示与解析时间可见，错误不暴露堆栈、Secret 或不受控后端文本。

### A4 现有业务能力（AC-009-04）

- [ ] 历史支持标题搜索、状态筛选、刷新、分页、打开任务和成功任务取件。
- [ ] 详情正确处理无 `jobId`、非法 ID、不存在/无权限、加载、活跃和所有终态。
- [ ] 活跃下载可以取消，成功下载可以获取短时文件地址；离开详情或到达终态后停止轮询。
- [ ] 成功下载可创建 AI 分析；分析支持语言/模板、取消、重试、摘要、关键观点、章节和思维导图。
- [ ] 个人资料更新用户名后导航立即同步；邮箱和角色不可编辑。
- [ ] 管理员可查询、筛选和分页管理用户，可修改他人角色/状态，不能修改自己；普通用户接口仍为 403。

### A5 静态导出（AC-009-05）

- [ ] `npm run build` 成功生成 `frontend/out/index.html`、`404.html` 及所有有限路由目录的 HTML。
- [ ] 导出过程不使用 Server Actions、Route Handlers、Middleware、ISR、请求时动态渲染或图片优化服务。
- [ ] 生产镜像只启动 FastAPI，不执行 `next start`，也不暴露独立前端端口。
- [ ] 静态 HTML 不包含用户资料、任务数据、Cookie、令牌、API Key 或其他 Secret。

### A6 FastAPI 同源与旧链接（AC-009-06）

- [ ] `/downloads/<jobId>` 返回 308，`Location` 为安全编码的 `/downloads/detail?jobId=<jobId>`；重定向后任务正常加载。
- [ ] `/downloads/detail` 不被兼容规则重定向，`/api/downloads/*` 不受影响。
- [ ] `/api/*`、`/health/*`、`/docs`、`/redoc` 和 `/openapi.json` 始终由 FastAPI 处理，未知 API 返回 JSON 404 而不是 HTML。
- [ ] 未知 UI 地址返回品牌 404 页面与 HTTP 404；导出页面刷新不产生 307 目录跳转循环。
- [ ] HTML 使用可重新验证缓存，带内容哈希的静态资源可长期缓存。

### A7 OpenAPI 契约（AC-009-07）

- [ ] 所有公开 FastAPI 操作拥有非空、稳定、全局唯一 `operationId` 和明确 tag，契约测试通过。
- [ ] `npm run openapi` 通过 `@umijs/openapi` 提供的 `openapi2ts` 生成 `src/services/video/`，请求统一导入 `src/lib/request.ts`。
- [ ] 生成目录无手工修改、无平行 DTO 或提交的第二份人工 OpenAPI。
- [ ] `npm run openapi:check` 从当前 FastAPI 契约重新生成后无 Git 差异。
- [ ] 401 并发请求只触发一次 Refresh；刷新失败只跳转一次且不会循环。

### A8 方案 2 视觉还原（AC-009-08）

- [ ] 1487×1058 首页首屏的轻量 Header、居中标题/短描述、URL Bar、三步提示、格式/预览两栏和底部说明与方案 2 信息层级一致。
- [ ] 页面使用白色画布、`#007AFF` 主蓝、`#1D1D1F` 正文、灰色辅助信息与淡蓝选中态；没有黑色主按钮或大面积黑底。
- [ ] 导航无侧栏，页面无面包屑卡片、重阴影、装饰性大边框或卡片套卡片。
- [ ] 输入、分隔、焦点与错误仍保留必要功能边界；“无边框”没有损害可辨识性。
- [ ] 所有路由延续同一字体、宽度、间距、圆角、按钮和状态规则。

### A9 390px 响应式（AC-009-09）

- [ ] 在 390×844 下每条路由满足 `document.documentElement.scrollWidth <= document.documentElement.clientWidth`。
- [ ] 首页输入/按钮上下排列，媒体摘要、格式和下载动作单列显示，16:9 封面不拉伸。
- [ ] 历史与用户管理使用移动任务/摘要列表，不要求横向滚动查看核心字段或操作。
- [ ] 登录、注册、资料、筛选、分页和 Dialog 不被软键盘/视口裁切，错误字段可滚入视野。
- [ ] 主操作和图标控件触控区域至少 44×44px，200% 缩放仍可完成核心流程。

### A10 可访问性（AC-009-10）

- [ ] 自动化 axe 在所有路由关键状态无 serious/critical 违规。
- [ ] 纯键盘可完成登录、粘贴/输入链接、解析、选择格式、创建下载、筛选历史、打开详情和编辑用户。
- [ ] 页面有 skip link、landmark、唯一 `h1`、顺序标题、真实 label/button/radio/table 与可见 2px 焦点环。
- [ ] Dialog/Select/Menu 打开后焦点正确进入，Escape 可关闭，关闭后焦点返回触发器。
- [ ] 加载、错误和下载/分析关键阶段由节流 live region 播报；状态不只依赖颜色或图标。
- [ ] 正文、控件、焦点和状态颜色达到 WCAG 2.2 AA 对比度；reduced motion 下无非必要动画。

### A11 工程与运行门禁（AC-009-11）

- [ ] 前端 lint、格式、类型、Vitest/Testing Library 和生产构建全部通过。
- [ ] 后端格式、静态检查、严格类型、契约/集成测试全部通过。
- [ ] 根统一镜像构建通过，容器内页面与 `/api/*` 同源可用。
- [ ] 本地 Compose 与生产 Compose 叠加配置均可解析，验收未提交 `.env`、缓存或构建产物。

### A12 设计 QA（AC-009-12）

- [ ] 参考图与最新首页截图以相同 1487×1058 视口、相同解析成功状态放入同一比较输入。
- [ ] 导航位置、首屏纵向节奏、输入尺寸、步骤连线、两栏比例、封面裁切、格式行、字体重量、留白和圆角逐项记录。
- [ ] 全部路由的桌面与 390×844 关键状态已检查，菜单、Dialog、错误、空与加载态包含在内。
- [ ] P0/P1/P2 已修复并重新截图比较；剩余 P3 仅作为明确后续微调记录。
- [ ] 根目录 `design-qa.md` 存在并写明 `final result: passed`。
