## 验收前置

- 使用与生产一致的 Node.js、npm、Python 和锁文件安装依赖。
- FastAPI 使用可重复测试数据；至少准备普通用户、管理员、活跃下载、成功下载、失败下载和成功 AI 分析。
- 首页信息层级使用用户选定方案 3 无边框修订稿 `/Users/stephenqiu/.codex/generated_images/019fe657-3556-7102-a4d8-f0f95698076b/exec-6ad65a6b-a139-48c1-a789-730a53116807.png`（1487×1058）作为第一视觉基准。
- 结构对照 [Vercel 首页](https://vercel.com/home)、[Geist 排版](https://vercel.com/geist/typography)、[shadcn Radix 组件](https://ui.shadcn.com/docs/components)与 [Radix 无障碍指南](https://www.radix-ui.com/primitives/docs/overview/accessibility)，并以方案 3 的近黑前景/主操作为当前真值。
- 浏览器验证至少覆盖 1280px 常见桌面视口、1487×1058 方案 3 视口和 390×844 移动视口。
- Header、main 与 footer 统一使用 `.content-shell = min(calc(100% - 160px), 1376px)`，让导航与主体共享对齐线；641–1023px 的内容 gutter 各 32px，640px 及以下 gutter 为 16px。认证双栏可使用更宽的 `.page-shell`，但两种网格都不得呈现为可见页面外壳，窄表单只在其内二次收窄。

## 逐项验收

### A1 技术栈与目录（AC-009-01）

- [ ] `frontend/src/app/` 是唯一页面入口，路由使用 App Router；不存在 Pages Router 或 Umi 路由。
- [ ] 运行依赖包含 Next.js、React、Radix UI、Tailwind CSS；开发依赖直接包含 `@umijs/openapi`。
- [ ] `@umijs/max`、`antd`、`@ant-design/*`、Ant Design Pro、Umi OpenAPI 插件和 Less 已从依赖与源码移除。
- [ ] `frontend/components.json` 使用 shadcn `radix-nova`、Radix base、neutral CSS variables；`src/components/ui/` 保留 registry 组件语义，页面没有第二套主题或组件系统。
- [ ] Table、Sheet、Tooltip、Avatar、Field、InputGroup、Item、Empty、Pagination、AlertDialog、AspectRatio、Separator 和 RadioGroup 来自官方 shadcn/Radix 实现，页面不为相同语义另造可点击 `div` 或自制覆盖层。功能图标使用项目已有的 Phosphor 图标库，品牌标识通过 Next.js 图片能力使用 `public/logo.svg`。

### A2 路由、认证与权限（AC-009-02）

- [ ] `/`、`/history`、`/account`、`/admin/users`、`/downloads/detail?jobId=`、`/user/login`、`/user/register` 和 404 均可直接打开与刷新。
- [ ] 桌面 Header 中有可读的“帧取首页”（`href="/"`）和“下载记录”（`href="/history"`）链接；移动 Sheet 包含历史、账户和主题操作，关闭后焦点返回触发器。
- [ ] `/history` 仅“下载记录”标记 `aria-current="page"`；非当前导航项和品牌链接不误报当前页。
- [ ] 未登录访问受保护页面会跳到登录并携带安全站内 `redirect`；登录后返回原目标。
- [ ] 外部、协议相对、反斜杠和认证页循环 redirect 被拒绝。
- [ ] 普通用户看不到且无法渲染管理员页面；管理员权限变更从后端最新账户状态生效。

### A3 首页核心流程（AC-009-03）

- [ ] 有效公开链接可完成解析，返回真实媒体摘要和可用语义格式。
- [ ] 格式列表使用可键盘操作的单选语义，默认选择明确，开始下载使用该格式。
- [ ] RadioGroup 的每一项直接来自 API `MediaFormat`，显示分辨率、容器、编码与帧率；没有伪画质预设、伪字幕/容器选择器或静态封面上的伪播放按钮。
- [ ] 重复提交受到禁用/幂等保护，成功创建任务后进入 `/downloads/detail?jobId=<id>`。
- [ ] 初始、URL 校验失败、解析中、解析失败、无格式、已解析、创建中七种状态均有稳定布局和恢复动作。
- [ ] 合法使用与隐私提示可见；界面不伪造契约未提供的解析耗时，错误不暴露堆栈、Secret 或不受控后端文本。

### A4 现有业务能力（AC-009-04）

- [ ] 历史支持标题搜索、状态筛选、刷新、分页、打开任务和成功任务取件。
- [ ] 详情正确处理无 `jobId`、非法 ID、不存在/无权限、加载、活跃和所有终态。
- [ ] 活跃下载可以取消，成功下载可以获取短时文件地址；离开详情或到达终态后停止轮询。
- [ ] 成功下载可创建 AI 分析；分析支持语言/模板、取消、重试、视觉摘要、分镜、高光和资产。
- [ ] 个人资料更新用户名后导航立即同步；邮箱和角色不可编辑。
- [ ] 管理员可查询、筛选和分页管理用户，可修改他人角色/状态，不能修改自己；普通用户接口仍为 403。

### A5 静态导出（AC-009-05）

- [ ] `npm run build` 成功生成 `frontend/out/index.html`、`404.html` 及所有有限路由目录的 HTML。
- [ ] 导出过程不使用 Server Actions、Route Handlers、Middleware、ISR、请求时动态渲染或图片优化服务。
- [ ] 生产镜像只启动 FastAPI，不执行 `next start`，也不暴露独立前端端口。
- [ ] 静态 HTML 不包含用户资料、任务数据、Cookie、令牌、API Key 或其他 Secret。

### A6 FastAPI 同源与旧链接（AC-009-06）

- [ ] `/downloads/<jobId>` 返回 308，`Location` 为安全编码的 `/downloads/detail?jobId=<jobId>`；重定向后任务正常加载。
- [ ] `/downloads/detail` 不被兼容规则重定向，`/api/downloads/*` 不受影响。
- [ ] `/api/*`、`/health/*`、`/docs`、`/redoc` 和 `/openapi.json` 始终由 FastAPI 处理，未知 API 返回 JSON 404 而不是 HTML。
- [ ] 未知 UI 地址返回品牌 404 页面与 HTTP 404；导出页面刷新不产生 307 目录跳转循环。
- [ ] HTML 使用可重新验证缓存，带内容哈希的静态资源可长期缓存。

### A7 OpenAPI 契约（AC-009-07）

- [ ] 所有公开 FastAPI 操作拥有非空、稳定、全局唯一 `operationId` 和明确 tag，契约测试通过。
- [ ] `npm run openapi` 通过 `@umijs/openapi` 提供的 `openapi2ts` 生成 `src/services/video/`，请求统一导入 `src/lib/request.ts`。
- [ ] 生成目录无手工修改、无平行 DTO 或提交的第二份人工 OpenAPI。
- [ ] `npm run openapi:check` 从当前 FastAPI 契约重新生成后无 Git 差异。
- [ ] 401 并发请求只触发一次 Refresh；刷新失败只跳转一次且不会循环。

### A8 方案 3 与 Vercel/Geist 无边框视觉收敛（AC-009-08）

- [ ] 1487×1058 首页首屏的 80px 无边框 Header、“01 / 解析媒体”眉题、“把视频，带回本地。”大尺寸编辑式 Hero、URL 填充面、媒体/格式双栏和底部说明与方案 3 信息层级一致。
- [ ] 页面使用 `#FAFAFA` 画布、`#0A0A0A` 前景、primary `#111111`、hover `#2B2B2B`、白色主按钮文字、灰色辅助信息与中性选中态。
- [ ] Header 在桌面和 390px 下均为 80px 视觉高度，不显示下边线、外框、ring 或阴影；Header 与 main/footer 共用最大 1376px 的 `.content-shell`，桌面 gutter 为 80px，641–1023px 内容 gutter 为 32px，移动端 gutter 为 16px，导航与主体左右边线一致。
- [ ] 常规内页统一通过 `.inner-page` 使用移动 40px、平板 56px、桌面 64px 的上下留白；账户、平台状态、用户管理、平台目录、下载分析、历史与详情不再各自叠加 `py-20`/`py-24`，BackLink 与 PageHeader 间距为 20/24px。
- [ ] Geist 及中文系统回退字体生效；首页 H1 使用流动大尺寸与紧凑行高，内页使用响应式标题阶梯，正文、标签/元数据的字号、行高和字重分层一致，中文不截断或发虚。
- [ ] 页面根、标题区、筛选区、列表区和表单区没有可见 PageShell/Card 外壳、装饰 ring、重阴影、装饰性大边框或卡片套卡片。
- [ ] 输入、选择器与按钮使用无边框实心填充面；内容分组只使用必要的 1px 发丝 Separator。键盘焦点轮廓、错误边界和 Radix 覆盖层的表面/遮罩仍清晰可辨。
- [ ] 首页只使用 API `MediaFormat` 驱动的 Radix RadioGroup，不存在旧三步 UI、伪画质预设、伪字幕/容器选择器或伪播放按钮。
- [ ] `frontend/public/images/media-preview-mountain.webp`（约 221 KiB）在演示/回归状态中正确裁切且不变形，真实解析封面仍优先；功能图标使用 Phosphor，品牌链接与 metadata 使用已经设计好的 Logo，没有 emoji、临时手绘 SVG 或 CSS 图形替代品。
- [ ] 认证、历史、账户、管理和下载详情均使用无外壳连续内容；历史使用 Item/ItemGroup，管理员桌面端使用 Table，下载详情使用 Separator。
- [ ] 平台状态使用共享 PageHeader 与 Item/ItemGroup；AI 分镜、高光和资产使用 Tabs + Item/ItemGroup + Separator；业务页面不保留可由 shadcn Button 替代的原生按钮，也不以逐项可见边框模拟 Card。
- [ ] AlertDialog 只用于取消下载/分析；管理员角色和状态编辑使用普通 Dialog。

### A9 390px 响应式（AC-009-09）

- [ ] 在 390×844 下每条路由满足 `document.documentElement.scrollWidth <= document.documentElement.clientWidth`。
- [ ] 首页 Hero 在窄屏自然换行，输入/按钮上下排列，媒体摘要、真实格式 RadioGroup 和下载动作单列显示，1.86:1 封面不拉伸。
- [ ] 历史在桌面与移动端均使用 Item/ItemGroup；管理员桌面 Table 在 390px 下切换为 Item 摘要列表，不要求横向滚动查看核心字段或操作。
- [ ] 移动导航 Sheet 明确显示下载记录、账户与主题操作，宽度不超视口且长内容可滚动；打开/关闭时页面不跳动，关闭时焦点返回触发器。
- [ ] 登录、注册、资料、筛选、Pagination、Dialog 和 AlertDialog 不被软键盘/视口裁切，错误字段可滚入视野。
- [ ] Pagination 在 390px 下保留上/下页与当前页信息；Tooltip 隐藏或无法 hover 时不会丢失必要说明。
- [ ] 主操作和图标控件触控区域至少 44×44px，200% 缩放仍可完成核心流程。

### A10 可访问性（AC-009-10）

- [ ] 自动化 axe 在所有路由关键状态无 serious/critical 违规。
- [ ] 纯键盘可完成登录、粘贴/输入链接、解析、选择格式、创建下载、筛选历史、打开详情和编辑用户。
- [ ] 在 `/history`，桌面与 390px 下均可用 Tab 聚焦可读的“帧取首页”品牌链接并按 Enter 到达 `/`，无需使用浏览器后退。
- [ ] 页面有 skip link、landmark、唯一 `h1`、顺序标题、真实 label/button/radio/table 与可见 2px 焦点轮廓；“无装饰 ring”不影响键盘焦点可见性。
- [ ] Dialog/Sheet/Select/Menu 打开后焦点正确进入，Escape 可关闭，关闭后焦点返回触发器；AlertDialog 需明确选择取消或确认。
- [ ] Tooltip 在图标触发器获得键盘焦点或 hover 时显示，不抢占焦点；触发器有自身可读名称。
- [ ] 使用 Radix `asChild` 的 leaf component 透传 props/ref，触发元素可聚焦；未出现嵌套按钮、丢失 `aria-*` 或无法激活的组合。
- [ ] 加载、错误和下载/分析关键阶段由节流 live region 播报；状态不只依赖颜色或图标。
- [ ] 正文、控件、焦点和状态颜色达到 WCAG 2.2 AA 对比度；reduced motion 下无非必要动画。
