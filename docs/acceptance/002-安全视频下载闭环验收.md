## 真实受控 E2E 证据（2026-08-06）

- 输入为项目明确受控的直链 MP4；Runner 通过 egress proxy 访问，yt-dlp 识别为 `Generic`，并使用同一代理约束下的 ffprobe 补全媒体元数据。
- 解析结果提供 `360p MP4 H264/AAC`，实际选择该语义格式并创建一次下载任务；任务进入 `succeeded`。
- 制品上传 MinIO 后，由 API 签发短时 URL 并成功取回；PostgreSQL 中记录的 SHA-256 与取回文件重新计算的 SHA-256 完全一致。
- 对取回文件执行 ffprobe：视频为 **640×360 / H.264**，音频为 **AAC**，时长为 **3.702993 秒**。
- 真实浏览器完成 URL 解析并进入对应下载任务页；页面 console 与错误 overlay 均无错误。浏览器通过 `app_ingress` 访问 API，签名文件地址由同一交付网络中的 MinIO 提供。
