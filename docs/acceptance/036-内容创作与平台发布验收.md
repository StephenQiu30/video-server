## 3. 发布门禁

- **G1 / M1：** A00–A08、A10、A21/A23/A24 对应 M1 子集通过，质量集覆盖当期视觉/文字范围；文章与小红书导出才可标可用。
- **G2 / M2：** A09/A11 及对应配额/恢复通过，才启用 ASR 或 AI 图像；缺少任一 Provider 不阻止 M1。
- **G3 / M3：** A12–A18 通过；草稿模式可先按 A14 单独开放，但公开发布必须有真实账号权限、具体内容授权及最终回执。
- **G4 / M4：** A19 与 A20 分别开关；官方交接通过不等于个人自动发布通过。没有可信帖子回执，个人适配保持“待核实”。
- **G5 / 迁移：** A22 通过才可承诺该配置的换机恢复；浏览器会话平台拒绝时记录重新授权，不伪报自动恢复。

单测/Fake adapter 通过不代替真实草稿/帖子；真实单账号一次通过不代替所有账号和平台。所有验收记录保留非通过项、日期、版本与能力范围。
