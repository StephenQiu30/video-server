## 4. 证据模板

每条实验记录至少包含以下内容，未取得结果的字段留“未执行”，不得填推测值：

```text
experiment_id / requirement_ids / executed_at_utc
provider_key / profile_version / access_policy_id / capability
sample_target_id + version / sample_authorization_reference
host_role + OS + architecture / image_digest / engine_bundle
source_kind / opaque_revision / egress_generation (不含真实账号/IP)
control_case / changed_variable / attempt_budget / timeout_budget
inspection_outcome / first_byte_ms / media_outcome / artifact_outcome
bytes / media_duration / codecs / ffprobe_result / checksum
restart_or_restore_steps / old_host_write_fenced / persisted_budget
Web_result / mobile_device_result / screenshot_or_video_reference
stable_error / error_stage / manual_cancellation / cleanup_result
decision: Go | Conditional | No-Go | Inconclusive
reviewer / unresolved_items / approved_next_scope
```

选择样本后不能为求通过静默换 URL/账号/格式；样本删除或权益变化只能升级版本并保留原因。长样本预算必须在执行前声明，本轮腾讯的主动取消不记为上游失败。正式实验数量与存储/流量成本先批准；23 个媒体样本 × 3 个冷启动循环已是 69 次下载，不能把该数量隐含在普通健康检查中。

## 5. Go/No-Go 规则

- 所有选定平台：安全负例零越界，3 个冷启动循环均完成完整制品，目标机器至少一次恢复成功，真实客户端获取结果明确。
- G1 只有直接引擎成功而应用失败才支持“改应用链路”；两者都失败先定位平台/引擎/来源，不先重构架构。
- G3 自动访客来源必须证明无账号材料和正常第一方建立流程；账号来源必须证明同主体更新与撤销。材料、接口或证据缺失就 No-Go，继续 manual_file/用户重新授权。
- 一项可自动恢复不代表所有来源可自动恢复；用户可批准部分平台实现，但不得据此关闭其他平台的缺口。
- 账号/权益/DRM/地域等限制维持原边界。任何“只有绕过限制才能成功”的实验结果都不能作为 Go。
- 单测、源码审查、第三方 README 和官方 issue 修复记录都是证据输入，不能单独通过 G2/G3/G5。
