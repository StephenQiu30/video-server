# 008 用户资料与角色管理验收

- 状态：Accepted
- 日期：2026-08-09
- 关联 Design：`docs/design/008-用户资料与角色管理设计.md`
- 关联 PRD：`docs/prd/008-用户资料与角色管理需求.md`

## 逐项验收

- [x] A1：注册用户名唯一，首位或配置邮箱正确获得管理员角色。
- [x] A2：个人资料更新后 `/api/auth/me` 与导航显示一致。
- [x] A3：普通用户访问管理员接口返回 403。
- [x] A4：管理员查询、角色调整、停用和会话撤销可用。
- [x] A5：管理员自我降级或停用返回稳定冲突错误。
- [x] A6：历史、资料和用户管理页使用 Next.js App Router、Radix UI 与 Tailwind CSS，符合方案 2 的蓝白弱边框布局且窄屏无溢出。
- [x] A7：后端与前端全量门禁、生产构建和 Compose 解析通过。

## 验收证据

- 后端：`ruff check`、`ruff format --check`、`mypy app` 通过，`pytest` 355 项通过。
- 前端：Biome、TypeScript、Vitest 34 项和 Next.js production build 通过；认证与用户服务由 `@umijs/openapi` 生成。
- 浏览器：验证管理员资料更新、普通用户路由 403、管理员停用普通用户、停用后登录态失效。
- 布局：下载历史、个人资料和用户管理使用紧凑标题区、Apple 蓝主操作、浅灰分隔与 Radix UI 工具控件；桌面表格在 390px 视口转换为单列记录，页面级无横向溢出。
- 部署配置：开发与生产 Compose 配置均可解析，验收过程未通过 Docker 启动服务。
