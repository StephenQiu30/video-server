# 微信视频号公开分享链接服务端解析调研

- 状态：Completed
- 日期：2026-08-29
- 对应设计：`docs/design/025-微信视频号公开分享链接下载设计.md`

## 1. 结论

微信视频号公开分享页可以匿名确认 `weixin.qq.com/sph/{id}` 的作品元数据，但抽样
响应不保证直接提供媒体 URL。当前没有确认到可供第三方 C 端服务代表任意用户授权、
并下载任意视频号分享作品的官方开放 API。

社区项目常见的元宝 Cookie、消费端私有解析接口、浏览器 Profile 或流量捕获方案虽然
可能在特定账号和设备上短期工作，但会把服务可用性绑定到个人电脑、共享账号和未承诺
稳定性的私有协议，不满足本项目的通用部署、隐私和长期可靠性要求，因此不进入运行时。

本项目只保留以下能力：

1. 接受公开 HTTPS `/sph/{id}` 单视频链接；
2. 只请求视频号第一方公开页面和匿名接口；
3. 仅当匿名响应直接提供批准腾讯媒体域上的 clear、非 DRM 媒体时返回格式；
4. 没有公开媒体、需要登录或存在保护材料时稳定失败，并引导用户上传自己拥有或已获
   授权的文件；
5. 不启动浏览器、不读取 Cookie、不调用元宝私有接口，也不依赖 Codex/AI Worker。

## 2. 第一方匿名边界

公开短链会进入：

```text
https://channels.weixin.qq.com/finder-preview/pages/sph?id={shortUri}
```

页面使用的匿名请求形态为：

```text
POST https://channels.weixin.qq.com/finder-preview/api/feed/get_feed_info
{"baseReq":{"generalToken":""},"shortUri":"{shortUri}"}
```

有效响应可能包含描述、作者、封面和公开作品标识。只有同一匿名响应直接包含允许的
`h264VideoInfo.videoUrl` 或 `h265VideoInfo.videoUrl`，且媒体 URL、路径和保护检查全部
通过时，服务才生成下载格式。匿名元数据成功本身不等于媒体可下载。

## 3. 被否决的方案

| 方案 | 否决原因 |
| --- | --- |
| 元宝 Cookie + 私有 `get_parse_result` | 依赖消费端账号和未承诺稳定性的私有协议，无法形成通用 C 端服务契约 |
| 读取 Chrome Profile / Keychain | 绑定特定用户和电脑，存在隐私风险，容器和生产环境不可移植 |
| 常驻或按需浏览器自动登录 | 平台挑战、会话撤销和 UI 变化都会破坏稳定性，并会干扰用户桌面 |
| 公共第三方解析站 | 内容、凭据、合规和供应链边界不可控 |
| MITM、根证书、流量捕获或解密 | 超出公开媒体下载边界，存在明确安全与合规风险 |

社区项目只用于理解协议形态，不作为生产能力或稳定性证明。

## 4. 官方能力边界

腾讯云点播提供媒资详情、媒体文件下载和拉取上传等 API，但它们面向客户自己上传或
存储在点播账户中的媒资，不是任意微信视频号分享链接的下载授权。若未来平台提供官方
OAuth、创作者资产或导出 API，应以独立 Connector 接入，并要求资产级下载/导出权限；
在此之前不以 Cookie 或浏览器自动化模拟官方授权。

## 5. 媒体与保护门禁

可下载结果必须同时满足：

- 来源是规范化的 `https://weixin.qq.com/sph/{id}`；
- 媒体 URL 使用 HTTPS、批准的腾讯媒体域和固定下载路径；
- 响应树内没有有效 `decodeKey`、DRM、encrypted/encryption 标记；
- 现有 FFprobe 流水线能够识别标准音视频轨道；
- Download Worker 在执行前重新匿名解析，不持久化过期 CDN URL。

任何条件不满足都返回稳定错误，不切换账号、不请求 Cookie、不调用第三方服务，也不
尝试解密。

## 6. 验证状态

自动化测试已覆盖匿名元数据、直接公开媒体、无媒体、失效链接、非批准媒体域与保护
材料拒绝。真实媒体 canary 只有在取得项目自有或明确授权、且匿名响应直接公开 clear
媒体的样本后才能完成；在此之前平台状态保持 `degraded`，不能显示为完整可用。
