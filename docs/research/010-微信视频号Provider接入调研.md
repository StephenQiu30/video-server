# 微信视频号 Provider 接入调研（已被取代）

- 原调研日期：2026-08-12
- 结论更新时间：2026-08-26
- 当前调研：`docs/research/014-微信视频号与腾讯视频授权媒体下载调研.md`
- 当前设计：`docs/design/024-微信视频号与腾讯视频授权媒体接入设计.md`

原调研提出的元宝 Cookie、未公开 finder/解析接口、公共 Worker、根证书代理、页面注入、`decodeKey`、ISAAC64 和受保护前缀转换不再是产品实现候选，也不得作为 Edge Agent 回退路径。

当前产品结论是：视频号分享 URL 只做来源识别并返回 `export_required`；用户可导入自己创作、拥有权利或经权利方授权且已合法取得的明文文件。只有微信书面许可、内容合作协议或正式媒体导出 API 通过独立评审后，才能新增 `official_connector`。

旧调研过程和历史源码证据通过 Git 追溯，不在当前事实文档中重复保留。
