# PLAN06 取消、重试与事件流

## 1. 背景

如果没有事件流、取消和重试能力，用户只能被动等待失败，系统也缺少可追踪过程。

## 2. 目标

1. 支持取消和重试。
2. 关键状态流转写入 `task_events`。

## 3. 非目标

- 不实现 SSE 推送。

## 4. 核心内容

1. 设计取消和重试接口规则。
2. 实现 `task_events` 表写入。
3. 定义哪些状态允许取消与重试。

## 6. 验收门禁

- 失败任务可重试。
- 可取消状态清晰可测。
- 关键事件可追踪。

## 7. 风险与边界

取消和重试如果没有状态约束，容易导致重复消费或数据污染。

## 8. 待确认问题

- 重试是复用原任务还是新建任务。
