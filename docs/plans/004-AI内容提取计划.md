# Plan 004 AI 内容提取计划

## 状态与输入

- 状态：Ready；尚未开始实现。
- Design：[004](../design/004-AI内容提取设计.md)。
- PRD：[004](../prd/004-AI内容提取需求.md)。
- 目标：完成视频语音转写、LangChain 结构化分析、AI 任务和结果 API 闭环。
- 依赖：Plan 001、002、003、005 的共享 API 基座完成。

## 1. 任务边界

只处理成功且未过期下载的视频语音。不实现字幕、画面理解、用户模型配置、Agent、RAG 或向量库。

## 2. 执行拆分

| 顺序 | Test-first 约束 | 最小实现 | 产出 |
| --- | --- | --- | --- |
| 1 | 下载状态与过期准入测试先失败 | AI Job 创建 Service | 创建边界 |
| 2 | 音频提取参数、清理和失败测试先失败 | FFmpeg Audio Adapter | 临时音频 |
| 3 | 带时间段转写 fixture 测试先失败 | faster-whisper Adapter | Timed transcript |
| 4 | Prompt 输入和 Pydantic schema 测试先失败 | LangChain Analysis Chain | 结构化结果 |
| 5 | 429/5xx、认证、模型和结构错误测试先失败 | Provider 错误映射 | 稳定失败契约 |
| 6 | AI Worker 状态、幂等和过期测试先失败 | ai queue task | 异步闭环 |
| 7 | 创建、查询、结果 API 契约测试先失败 | AI Router/VO | 对外 API |

## 3. 测试策略

- CI 使用短音频 fixture、Fake Transcriber 和 Fake Chat Model，不依赖模型下载或外部密钥。
- Adapter 集成测试可在显式环境中使用本地 faster-whisper 模型。
- Provider smoke 仅在提供测试密钥时运行，日志不得输出密钥、Prompt 或完整转写。

## 4. 验收映射

- S004-DAC-01：任务 1、6、7 的创建准入、去重和 API 证据。
- S004-DAC-02：任务 2、3 的真实 FFmpeg/faster-whisper 运行证据。
- S004-DAC-03、S004-DAC-04：任务 4 的真实 Provider、Pydantic、语言和时间范围证据。
- S004-DAC-05：任务 7 的 VO、日志、数据库和敏感输出扫描。
- S004-DAC-06、S004-DAC-07：任务 5、6 的故障、重试、崩溃清理和下载隔离证据。
- S004-DAC-08：下载产物到 AI 结果的真实端到端闭环。
- S004-AC-01：AI 创建准入参数化测试。
- S004-AC-02：带时间转写 Adapter 测试。
- S004-AC-03、S004-AC-04：固定 LangChain 链和 Pydantic 输出测试。
- S004-AC-05：默认中文结果 fixture 验证。
- S004-AC-06：错误分类与重试矩阵。
- S004-AC-07：依赖与输出中不存在字幕/画面能力的检查。

## 5. 验证命令

- `uv run ruff check .`、`uv run ruff format --check .`、`uv run mypy --strict src`。
- `uv run pytest --cov=video_server --cov-branch --cov-fail-under=90` 执行 AI Service、Adapter、Chain、Worker、API 全量测试。
- 使用本地 faster-whisper 模型和真实 OpenAI-compatible Provider 对受控短视频完成转写、章节和结果查询；该项不可用 Mock 替代。

## 6. 提交顺序

`test: AI 准入与音频约束 → impl: 音频/转写 → test: 结构化分析约束 → impl: LangChain chain → test: 任务/API 约束 → feat: AI 闭环`

## 7. 风险与非目标

- 模型资源和 Provider 能力差异可能导致 smoke 不可用，不能用 mock 结果替代明确的未验证说明。
- 不在本 Plan 引入多 Provider 路由或模型选择 UI。

## 8. 完成条件

S004-DAC-01 至 DAC-08 与 S004-AC-01 至 AC-07 必须全部 `passed`，真实模型闭环、临时音频清理和 AI/下载故障隔离均有证据后进入 Acceptance。
