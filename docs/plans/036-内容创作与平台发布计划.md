# 内容创作与平台发布实施 SOP

- 日期：2026-09-15；状态：调研与设计完成，以下实施步骤尚未执行。
- 输入：[023 调研](../research/023-内容创作与平台发布能力调研.md)、[036 Design](../design/036-内容创作与平台发布设计.md)、[PRD](../prd/036-内容创作与平台发布需求.md)；输出：[Acceptance](../acceptance/036-内容创作与平台发布验收.md)。

## 1. 每个切片统一执行流程

1. **确认基线。** 在 video-server/video-app 各自检查 Git 状态，仅修改相关仓库；读取 AGENTS、相邻模型/用例/测试和本切片验收项。记录当前 SHA、数据结构与部署版本，保留已有改动。
2. **先固定可验收行为。** 从 PRD 选择需求编号，写清输入、可见结果、错误恢复和不在范围的边界；必要时更新 Design/PRD，再实现。缺陷进入 code-quality，新功能缺口不伪装成既有事故。
3. **Red。** 先用回归测试暴露真实缺陷或验证新的业务失败边界：并发冲突、越权、响应丢失、文件缺失等。纯静态文案不添加镜像式测试。
4. **Green。** 最小业务实现落入现有分层；SQL 当前态、ORM、API 同步，生成唯一 OpenAPI 客户端。长任务使用现有 Outbox/lease 模式，不新建通用框架。
5. **Refactor。** 审核重复状态/配置、明文 Secret、任意路径、HTML/网页指令、副作用重试、资源引用和配额；只整理本切片需要的代码。
6. **验证。** 跑相应模块检查和该切片的故障注入/真实 UI/文件验收。明确夹具、候选环境和真实平台三种证据；失败不关闭验收项。
7. **交付。** 窄范围暂存，核对 staged diff，中文 Conventional Commit；按已有用户授权决定推送，记录本次远端 SHA与 CI。部署时使用同一版镜像，按范围重建业务服务，不另起基础设施。
8. **复查与回滚。** 检查业务结果、重启后恢复及观测；更新 Acceptance/CQ。失败关闭新增入口或 adapter 的准入，保留作品和核对记录，回退到已验证镜像/渲染版本，不删除数据。

## 3. 外部组件接入 SOP

对每个候选分别记录：

1. 上游固定 commit/tag、具体采用文件、许可证/NOTICE、直接依赖及运行时；未审查的子 Skill 不连带批准。
2. 用本项目输入跑一个最小离线样例，检查输出契约、中文、文件/网络访问和可取消性；依赖不得读取宿主 `.env`、日常浏览器或个人模型认证。
3. 明确采用方式：纯方法移植、固定库/CLI、受控平台 adapter 三选一；不把完整应用嵌入现有 Next.js。
4. 用本项目严格 schema/owner/预算校验包装；冻结模板和输出版本；上游日志清理 Secret 和全文。
5. 针对更新做样本差异和故障回归，通过后提交依赖锁与第三方声明；保留上一已验证版本以回滚。
6. 观察真实环境后才从“候选”变“可用”。浏览器发布不满足唯一回执或隔离时保持条件能力，用户仍可导出/官方分享。

## 4. 发布故障处理 SOP

| 现场现象 | 判定与动作 | 禁止误判 |
| --- | --- | --- |
| 页面显示连接状态过旧 | 后台有界查询，保留正文和应用登录 | 刷新整页或清除 FrameFetch 登录 |
| 凭据文件不可读/密钥解密失败 | 配置/权限故障，暂停该连接并报告操作 ID | 要求用户反复扫码解决磁盘问题 |
| 官方接口无权限 | 缺少特定动作 scope，保留导出/其他允许动作 | 已登录就宣称可发布 |
| 草稿/发布提交超时 | 检查提交标记与远端 ID，转未知并核对 | 自动重发写请求 |
| 图片上传部分成功 | 保留与账号/内容版本关联的远端素材映射；按有效期核验后只补失败部分 | 整稿重新生成或跨账号复用素材 ID |
| 平台审核失败 | 保存理由并允许修改为新内容版本，重新预览确认 | 无限退避重试同一份被拒内容 |
| 原机器重启/Worker 丢失 | 回收 lease；提交前可恢复准备，提交后先核对 | 只按 queued/running 重放外部动作 |
| 小红书分享 App 返回 | 记录交接结果，无法确认发布时保持交接状态 | 唤起成功等于已发帖 |

## 5. 检查命令与证据规范

后端变更从 `backend/` 执行 `uv run ruff check app tests`、`uv run ruff format --check app tests`、`uv run mypy app`、`uv run pytest`；前端变更按 frontend/AGENTS.md 执行 format/lint/test/build 并真实浏览器验证。SQL 用已有隔离测试库验证空库和当前态幂等应用，不另建本机基础服务。App 切片在独立仓库读规范、生成契约和跑真机分享/文件验收。

证据至少含：代码/镜像 SHA、时间、环境、样本 ID与使用权限、输入 revision、操作 ID、预期/实际结果、脱敏平台 ID/链接、文件 hash、残余问题。不能提交真实 Cookie、Token、日志正文、个人稿件和临时图片。

纯设计文档只做路径/引用/状态/术语一致性及 `git diff --check`；不因这轮文档运行全栈重启或把历史测试结果作为新功能通过证明。
