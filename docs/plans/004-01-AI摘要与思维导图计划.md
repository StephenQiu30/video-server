# AI 摘要与思维导图计划

## 1. 背景

AI 增强在下载成功后执行。它可以失败或跳过，但不能影响主视频任务成功。

## 2. 目标

- 未配置 key 时 `ai_status=skipped`。
- 配置可用时转录音频、生成摘要和 Mermaid 思维导图。
- 失败时记录 `ai_status=failed` 和错误原因。

## 3. TDD 步骤

1. `test:` 在 `apps/api/tests/test_ai_intelligence.py` 和 Worker 相关测试中增加 skipped、completed、failed 断言。
2. 运行红灯命令：

```bash
PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_ai_intelligence.py apps/api/tests/test_worker_jobs.py -q
```

3. `impl:` 调整 `apps/worker/worker/ai_pipeline.py` 和 AI 服务错误处理。
4. 运行绿灯命令并确认错误不泄露密钥。

## 4. 验收门禁

- AI pipeline 状态可见。
- AI 失败不改变主任务 `succeeded`。
- Mermaid 输出不包含代码围栏。
