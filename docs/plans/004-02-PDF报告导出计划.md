# PDF 报告导出计划

## 1. 背景

PDF 报告是 AI 摘要的可交付产物，必须校验任务归属和任务状态。

## 2. 目标

- 任务未完成时拒绝 PDF 导出。
- 任务完成且属于当前用户时返回 PDF 二进制。
- PDF 内容包含标题、摘要和生成时间等基础信息。

## 3. TDD 步骤

1. `test:` 在 `apps/api/tests/test_finalize_features.py` 增加权限、状态和 PDF header 断言。
2. 运行红灯命令：

```bash
PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_finalize_features.py -q
```

3. `impl:` 调整 `apps/api/app/services/pdf.py` 和 `apps/api/app/routers/tasks.py`。
4. 运行绿灯命令并确认 OpenAPI 非 JSON 响应仍正确。

## 4. 验收门禁

- 未完成任务返回 409。
- 非任务拥有者不能导出。
- 成功响应 `content-type=application/pdf`。
