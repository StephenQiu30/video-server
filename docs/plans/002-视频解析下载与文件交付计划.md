## 1. 任务边界

实现 URL 安全、yt-dlp inspect、格式标准化、下载、FFmpeg 合并/ffprobe、MinIO 上传和预签名交付。不新增下载引擎、转码能力、存储适配层或业务重试框架。

## 3. 预期文件边界

- `src/media/{models,schemas,service,formats,yt_dlp,url_policy}.py`，持久化统一复用 `src/downloads/repository.py`。
- `src/downloads/application.py` 负责 HTTP 下载编排，`src/worker.py` 负责 Worker 下载执行；两者复用 Plan 003 的状态与仓储。
- `src/minio_client.py` 增加直接 MinIO SDK 操作，不增加 interface/factory。
- `tests/unit/media/`、`tests/integration/{yt_dlp,ffmpeg,minio}/`、受控样例清单。
