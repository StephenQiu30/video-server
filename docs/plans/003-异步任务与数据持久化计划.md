# Plan 003 异步任务与数据持久化计划

## 状态与输入

- 状态：Ready；尚未开始实现。
- Design：[003](../design/003-异步任务与数据存储设计.md)。
- PRD：[003](../prd/003-异步任务与数据持久化需求.md)。
- 目标：建立六张表、两条队列、状态机、幂等重试、过期和清理基座。
- 依赖：Plan 001 与 Plan 005 的共享 API 错误基座。

## 1. 任务边界

包含数据模型、迁移、Repository/Unit of Work、Celery 路由、状态转换、幂等锁和清理任务。不实现 yt-dlp、FFmpeg 或 LangChain 业务。

## 2. 执行拆分

| 顺序 | Test-first 约束 | 最小实现 | 产出 |
| --- | --- | --- | --- |
| 1 | 表、外键、CHECK、唯一约束测试先失败 | SQLAlchemy Entities + Alembic | 六张表 |
| 2 | 合法/非法状态转换测试先失败 | Job 状态服务 | 状态机 |
| 3 | 消息仅含 job ID 与路由测试先失败 | Celery task envelope/routes | 两条队列 |
| 4 | 重复执行和终态短路测试先失败 | 幂等任务基类/锁 | 重复投递安全 |
| 5 | 瞬时/业务错误重试测试先失败 | 重试策略 | 有限退避 |
| 6 | 24 小时过期和 7 天删除测试先失败 | Scheduler 清理任务 | 生命周期 |
| 7 | 重启、重复消息和依赖恢复集成测试 | Repository/Worker 串联 | 持久恢复 |
| 8 | 备份恢复与依赖重启持久性检查先失败 | PostgreSQL 恢复演练和持久卷核验 | 可恢复性证据 |

## 3. 数据与迁移要求

- 第一份 Alembic migration 从空 PostgreSQL 创建全部表和索引。
- 测试显式验证 Artifact/AI Result 唯一归属和状态 CHECK。
- 进度写入封装节流，不允许各 Worker 自行无限更新。
- 业务时间统一使用 UTC timestamptz。

## 4. 验收映射

- S003-DAC-01、S003-DAC-02：任务 1、2 的空库迁移、schema、状态矩阵和并发约束。
- S003-DAC-03：任务 3 的消息负载、路由和发布失败证据。
- S003-DAC-04、S003-DAC-05：任务 4、5、7 的重复投递、崩溃和真实重启恢复证据。
- S003-DAC-06、S003-DAC-07：任务 5、6 的时间推进、清理和重试分类矩阵。
- S003-DAC-08：任务 8 的 PostgreSQL 恢复及 RabbitMQ/MinIO 重启持久性演练。
- S003-AC-01、S003-AC-07：schema、迁移和索引检查。
- S003-AC-02：消息负载和 route 单元测试。
- S003-AC-03：进程重启后的数据库集成测试。
- S003-AC-04、S003-AC-05：重复投递、幂等、重试矩阵。
- S003-AC-06：时间推进后的 expired、墓碑和删除测试。

## 5. 验证命令

- `alembic upgrade head` 对空库执行并检查当前 revision。
- `uv run ruff check .`、`uv run ruff format --check .`、`uv run mypy --strict src`。
- `uv run pytest --cov=video_server --cov-branch --cov-fail-under=90` 执行模型、状态、队列、幂等、清理和集成测试。
- RabbitMQ 管理状态或 Celery inspect 验证只有 download/ai 队列。

## 6. 提交顺序

`test: schema 与状态约束 → impl: entities/migration → test: 队列幂等约束 → impl: task 基座 → test: 生命周期约束 → impl: scheduler 清理`

## 7. 风险与非目标

- SQLite 不能替代 PostgreSQL 集成证据。
- 不加入任务取消、优先级、列表、事件溯源或 Redis 锁。

## 8. 完成条件

S003-DAC-01 至 DAC-08 与 S003-AC-01 至 AC-07 必须全部 `passed`，空库迁移、重复任务、重启和备份恢复均有真实证据后进入 Acceptance。
