# PLAN02 错误语义与日志脱敏

## 1. 背景

入口安全不是只拒绝危险输入，还要把拒绝理由表达清楚，并避免日志泄露敏感参数。

## 2. 目标

1. 为入口校验建立稳定错误码。
2. 对日志中 URL 查询参数做脱敏或裁剪。

## 3. 非目标

- 不做下载执行失败分类。

## 4. 核心内容

1. 定义 `INVALID_URL`、`UNSAFE_URL` 等入口错误码。
2. 更新错误响应结构和测试。
3. 验证日志中不输出完整敏感参数。

## 6. 验收门禁

- 入口错误码稳定。
- 日志脱敏可通过测试或样例验证。

## 7. 风险与边界

脱敏过度会影响排障，脱敏不足会泄露敏感信息。

## 8. 待确认问题

- 是否保留域名和 path 但清空 query。
