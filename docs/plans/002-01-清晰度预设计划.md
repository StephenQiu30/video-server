# 清晰度预设计划

## 1. 背景

普通用户需要通过推荐、最高 1080p、720p、480p、360p 等预设完成下载选择，而不是理解复杂 format selector。

## 2. 目标

- 解析响应稳定返回推荐和常见清晰度预设。
- 平台缺少目标清晰度时提示不可用或自动降级。
- 不通过后端转码生成平台未提供的清晰度。

## 3. TDD 步骤

1. `test:` 在 `apps/api/tests/test_download_adapter.py` 增加可用、降级、不可用三类清晰度断言。
2. 运行红灯命令：

```bash
PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_download_adapter.py -q
```

3. `impl:` 调整 `apps/api/app/services/download_adapter.py` 的格式构建逻辑。
4. 运行绿灯命令并确认 OpenAPI schema 未破坏。

## 4. 验收门禁

- `recommended` 总是排在普通预设前。
- 每个预设有 `quality_label`、`available` 和 `note`。
- 格式 selector 长度仍满足 schema 限制。
