# 子计划 2：字幕封面元数据归档

## 1. 背景

下载主链路（子计划 1）保证主视频文件的可靠下载和归档。本子计划覆盖增强产物——字幕、封面、元数据和 AI 摘要——的收集、存储和失败处理策略。

**核心原则**：增强产物是任务的"锦上添花"，不可用时记录原因即可，绝不回退主任务状态。

关联 PRD：`docs/prd/003-下载任务与产物归档.md`
关联子计划：`docs/plans/003-01-下载主链路计划.md`

## 2. 目标

```gherkin
Given 主视频下载成功（state=succeeded）
When AI 流水线执行转录和摘要生成
Then ai_status 从 PROCESSING → COMPLETED，ai_summary 和 ai_mindmap 字段填充
And 如 AI 流水线任一步骤失败，ai_status=FAILED，ai_error 记录原因
And 任务 state 仍为 succeeded，不回退
```

## 3. 非目标

- 不实现字幕文件的独立下载或管理（字幕由 yt-dlp 内嵌处理）。
- 不实现封面图片的本地存储（仅存储远程 URL）。
- 不定义 AI 摘要的详细产品逻辑（由 AI Intelligence Suite 独立覆盖）。

## 4. 核心计划

### 4.1 增强产物分类

| 产物 | 来源 | 存储位置 | 生命周期 |
|------|------|----------|----------|
| 字幕 | yt-dlp 提取（内嵌或独立文件） | 视频文件内嵌 | 随主视频文件过期 |
| 封面 | 解析阶段获取的远程 URL | `DownloadTask.cover_url` 字段 | 持久（远程 URL，不存储本地副本） |
| 元数据 | 解析阶段获取 | `title`、`duration_seconds`、`format_label` 字段 | 持久（数据库字段） |
| AI 摘要 | AI 流水线生成 | `ai_summary`、`ai_mindmap` 字段 | 持久（数据库字段） |
| AI 状态 | AI 流水线状态机 | `ai_status`、`ai_error` 字段 | 持久（数据库字段） |

### 4.2 AI 流水线

**实现文件**：`apps/worker/worker/ai_pipeline.py`

`process_ai_pipeline(db, task, artifact)` 在主任务成功后异步执行：

```
1. 检查配置  — llm_api_key 和 transcription_api_key 是否存在
   ├─ 缺失 → ai_status=SKIPPED，退出
   └─ 存在 → 继续
2. ai_status=PROCESSING
3. 音频提取  — ffmpeg -y -i {video} -vn -ar 16000 -ac 1 -b:a 64k {audio.mp3}
4. 语音转录  — TranscriptionService (Groq Whisper API)
5. 摘要生成  — AIService (DeepSeek LLM)
6. 思维导图  — AIService (DeepSeek LLM)
7. 写入结果  — ai_summary, ai_mindmap, ai_status=COMPLETED
8. 清理临时文件 — 删除 .mp3
9. 异常处理  — ai_status=FAILED, ai_error=错误消息
```

**关键约束**：
- AI 流水线在主任务 `succeeded` 之后执行，其成功/失败不影响 `task.state`。
- AI 流水线的任何异常被捕获并记录到 `ai_error`，不会向上传播。
- 临时音频文件（`.mp3`）在流水线结束后无论成功失败都清理。

### 4.3 AI 状态机

**实现位置**：`apps/api/app/models.py` 中的 `AIProcessStatus` 枚举

| 状态 | 值 | 含义 |
|------|----|------|
| SKIPPED | `skipped` | API key 未配置，跳过 |
| PROCESSING | `processing` | 正在执行 |
| COMPLETED | `completed` | 全部完成 |
| FAILED | `failed` | 任一步骤失败 |

### 4.4 数据模型

**DownloadTask 增强产物字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `cover_url` | String (nullable) | 封面远程 URL |
| `title` | String | 视频标题 |
| `duration_seconds` | Integer (nullable) | 视频时长 |
| `format_id` | String | 用户选择的格式 ID |
| `format_label` | String (nullable) | 格式显示标签 |
| `ai_summary` | Text (nullable) | AI 生成的摘要 |
| `ai_mindmap` | Text (nullable) | AI 生成的思维导图（Markdown） |
| `ai_status` | String (nullable) | AI 流水线状态 |
| `ai_error` | String (nullable) | AI 流水线错误消息 |

**TaskRead Schema**：包含所有上述字段，确保 API 响应中增强产物信息完整。

### 4.5 失败边界

| 场景 | 处理方式 | 对主任务的影响 |
|------|----------|----------------|
| AI key 未配置 | `ai_status=SKIPPED` | 无影响 |
| 音频提取失败 | `ai_status=FAILED` + `ai_error` | 无影响 |
| 转录 API 失败 | `ai_status=FAILED` + `ai_error` | 无影响 |
| 摘要生成失败 | `ai_status=FAILED` + `ai_error` | 无影响 |
| 思维导图生成失败 | `ai_status=FAILED` + `ai_error` | 无影响 |
| 封面 URL 不可用 | `cover_url` 为空 | 无影响 |
| 元数据解析失败 | 使用默认值 | 无影响 |

**核心原则**：增强产物的任何异常都被 `try/except` 捕获，记录到 `ai_error`，绝不向上传播导致主任务状态变更。

## 7. 验收标准

- [ ] 字幕、封面、元数据可用时随任务归档并可在任务详情中展示。
- [ ] 增强产物失败或不可用只记录事件或增强状态，不把主视频任务回退为失败。
- [ ] 增强产物归属、过期和权限与主视频一致。
- [ ] 先提交失败测试，再提交最小实现，验证命令通过。
- [ ] AI 流水线异常不向上传播，`ai_error` 记录完整错误信息。

## 8. 风险与边界

1. **外部 API 依赖**：Groq 和 DeepSeek API 的可用性影响 AI 摘要功能，但不影响主任务。
2. **音频提取性能**：大视频文件的音频提取可能耗时较长，需要合理设置超时。
3. **LLM 输出质量**：摘要和思维导图的质量取决于 LLM 能力，可能需要后续优化 prompt。
