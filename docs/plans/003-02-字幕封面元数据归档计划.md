# 字幕封面元数据归档计划

## 1. 背景

字幕、封面和元数据能提升内容整理价值，但它们不是主视频下载成功的必要条件。

## 2. 目标

- 可用时保存字幕、封面和元数据。
- 不可用时记录事件或状态，不让主任务失败。
- 产物归属、过期和权限与主视频一致。

## 3. TDD 步骤

1. `test:` 增加 Worker 增强产物成功、部分失败和不可用场景。
2. 运行红灯命令：

```bash
PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_worker_jobs.py apps/api/tests/test_task_endpoints.py -q
```

3. `impl:` 增加增强产物收集、存储和任务响应字段。
4. 运行绿灯命令，确认主视频成功不受增强失败影响。

## 4. 验收门禁

- 主文件成功是任务成功条件。
- 增强产物失败只影响增强状态或事件。
- 任务详情能展示可用增强产物信息。
