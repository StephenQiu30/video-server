# 子计划 003-02：字幕封面元数据归档

更新时间：2026-06-02
关联 Issue：STE-59
父 PRD：`docs/prd/003-下载任务与产物归档.md`

## 1. 目标

在主视频下载成功后，收集并归档增强产物（字幕、封面、元数据），确保增强产物失败不影响主任务状态。

## 2. 增强产物定义

| 产物 | 来源 | 存储方式 | 任务字段 |
|---|---|---|---|
| 字幕 | yt-dlp `--write-subs` / 内嵌提取 | 对象存储 | `subtitle_key` |
| 封面 | yt-dlp `--write-thumbnail` | 对象存储 | `thumbnail_key` |
| 元数据 | yt-dlp `--write-info-json` | 数据库 JSON | `metadata_json` |

## 3. 收集策略

### 3.1 收集时机

- 主视频下载成功（`state=succeeded`）后开始收集增强产物
- 增强产物收集在 `process_download_task()` 主流程之后执行
- 通过 `process_enhanced_artifacts()` 独立函数处理

### 3.2 yt-dlp 选项

在主下载任务的 yt-dlp 选项中增加：
```python
{
    "writesubtitles": True,
    "writeautomaticsub": True,
    "writethumbnail": True,
    "writeinfojson": True,
    "subtitleslangs": ["zh", "zh-Hans", "zh-Hant", "en", "ja"],
}
```

### 3.3 收集流程

```
1. 设置 enhanced_status = "processing"
2. 尝试收集字幕文件
   - 成功：上传到对象存储，记录 subtitle_key
   - 失败：记录事件，继续
3. 尝试收集封面文件
   - 成功：上传到对象存储，记录 thumbnail_key
   - 失败：记录事件，继续
4. 尝试收集元数据
   - 成功：解析并存储到 metadata_json
   - 失败：记录事件，继续
5. 汇总状态：全部成功=completed，部分成功=partial，全部失败=failed
6. 设置 enhanced_status 和 enhanced_error
```

## 4. 存储规范

### 4.1 对象存储

- 字幕 key 格式：`users/{user_id}/tasks/{task_id}/subs/{lang}.vtt`
- 封面 key 格式：`users/{user_id}/tasks/{task_id}/thumb.{ext}`
- 保留期限与主视频一致（`file_retention_hours`）
- 过期时随主视频一起清理

### 4.2 数据库存储

元数据存储为 JSON 字段，包含：
```json
{
  "title": "视频标题",
  "description": "视频描述",
  "uploader": "上传者",
  "upload_date": "2026-01-01",
  "view_count": 1000000,
  "like_count": 50000,
  "tags": ["tag1", "tag2"],
  "duration": 300,
  "extractor": "youtube"
}
```

## 5. 失败边界

### 5.1 核心原则

- **增强产物失败不回退主任务状态**
- 每种增强产物独立尝试，一种失败不影响其他
- 失败原因记录在任务事件中

### 5.2 失败处理

| 失败场景 | 处理方式 |
|---|---|
| 字幕不可用 | 记录事件 "字幕不可用：平台未提供"，继续 |
| 字幕下载失败 | 记录事件 "字幕下载失败：{reason}"，继续 |
| 封面不可用 | 记录事件 "封面不可用"，继续 |
| 封面上传失败 | 记录事件 "封面上传失败：{reason}"，继续 |
| 元数据解析失败 | 记录事件 "元数据解析失败：{reason}"，继续 |
| 全部增强失败 | enhanced_status="failed", enhanced_error=汇总原因 |

### 5.3 增强状态字段

```python
# DownloadTask 新增字段
enhanced_status: str | None  # pending/processing/completed/partial/failed
enhanced_error: str | None   # 汇总失败原因
subtitle_key: str | None     # 字幕对象 key
thumbnail_key: str | None    # 封面对象 key
metadata_json: str | None    # 元数据 JSON
```

## 6. TDD 要求

### 6.1 测试先行

每个增强产物的收集、存储和失败处理都必须先写测试。

### 6.2 测试场景

| 场景 | 预期结果 |
|---|---|
| 字幕可用 + 封面可用 + 元数据可用 | enhanced_status="completed"，所有字段有值 |
| 字幕不可用 + 封面可用 | enhanced_status="partial"，subtitle_key=None |
| 全部不可用 | enhanced_status="failed"，enhanced_error 有值 |
| 主视频成功 + 增强全部失败 | 主任务 state="succeeded"，不回退 |
| 增强产物过期 | 随主视频一起清理 |

## 7. API 变更

### 7.1 TaskRead 响应

新增字段：
```python
enhanced_status: str | None = None
enhanced_error: str | None = None
subtitle_key: str | None = None
thumbnail_key: str | None = None
metadata_json: str | None = None
```

### 7.2 增强产物下载链接

- `GET /api/tasks/{task_id}/subtitle-link`：返回字幕下载链接
- `GET /api/tasks/{task_id}/thumbnail-link`：返回封面下载链接

## 8. 验收标准

- [ ] 字幕、封面、元数据可用时随任务归档并可在任务详情中展示

- [ ] 增强产物归属、过期和权限与主视频一致
- [ ] 先提交失败测试，再提交最小实现，验证命令通过
