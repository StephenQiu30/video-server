# PLAN09 本机开发与依赖复用

## 1. 背景

研发阶段更需要快速调试，而不是每次都拉起整套容器。

## 2. 目标

1. 复用已有 Redis、Postgres、MinIO。
2. 支持本机启动 API 与 Worker。

## 3. 非目标

- 不在本计划中完善 Docker Compose。

## 4. 核心内容

1. 定义本机开发所需环境变量。
2. 提供依赖探测和缺失提示。
3. 给出最小启动与验证命令。

## 6. 验收门禁

- 本机开发路径可复用已有依赖成功启动。
- 缺失依赖时有明确提示。

## 7. 风险与边界

如果本机路径和 Docker 路径配置不一致，后续排障成本会很高。

## 8. 待确认问题

- 是否需要脚本自动探测端口和服务可用性。
