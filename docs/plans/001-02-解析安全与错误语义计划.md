# 解析安全与错误语义计划

## 1. 背景

解析入口必须拒绝无效、本机、内网和保留地址，并用清晰错误码表达平台限制、限流、暂不支持和解析失败。

## 2. 目标

- 解析前完成 URL 规范化和安全校验。
- 错误码可用于前端展示可行动提示。
- 不为受限内容继续尝试规避。

## 3. TDD 步骤

1. `test:` 在 `apps/api/tests/test_parse_error_classification.py` 和 `apps/api/tests/test_url_normalization.py` 增加红灯测试。
2. 运行红灯命令：

```bash
PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_parse_error_classification.py apps/api/tests/test_url_normalization.py -q
```

3. `impl:` 调整 `apps/api/app/services/platforms.py`、`apps/api/app/services/download_adapter.py` 或 URL 工具。
4. 运行绿灯命令并确认错误语义稳定。

## 4. 验收门禁

- 内网、本机、保留地址被拒绝。
- 登录、会员、验证码、限流类错误映射到不同业务错误码。
- 错误响应不泄露完整敏感链接参数。
