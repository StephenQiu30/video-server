# Plan 004：PDF 导出与生命周期

## 1. 前置门禁

Plan 000–003 完成；邮箱 UUID owner、结构化 Insight Schema、证据引用、思维导图 JSON 与 MinIO 资产 Saga 稳定。

## 2. 范围

- 版本化保存用户编辑后的结构化知识文档。
- Jinja2 受控模板、Graphviz SVG 和 WeasyPrint PDF。
- 中文字体、目录、分页、可选择文本、链接和文字大纲。
- PDF 资产按 `PENDING → UPLOADING → READY` 写入 MinIO，HEAD/SHA-256 校验后才签发短期地址；失败可重试但不能生成重复 READY 版本。
- 用户立即删除使用 `DELETING → DELETED`，覆盖 MinIO 当前/历史 object version、PostgreSQL 元数据、Redis 缓存失效和备份滚动策略。
- 清理审计、孤儿资产扫描和隐私验收。

## 3. 非目标

公开分享、协同编辑、模板市场、永久归档和从不受信 HTML/CSS 生成 PDF。

## 4. 核心验收

- 基准集 PDF 生成成功率 100%，无乱码、裁切、重叠和字体缺失。
- PDF 结构与用户最后保存的内容一致，导出不重新生成 AI 结果。
- 禁止 `file://`、外部网络资源和恶意 SVG/HTML。
- 删除与过期满足 PRD 的 15 分钟、24 小时、7 天和备份期限。
- 显式保存输出在用户删除前保持私有可用；删除后在线对象不可读且所有加密备份版本在 30 天内滚动淘汰。
- 跨 UUID owner 无法读取/删除/重签；对象缺失、孤儿对象、备份残留和 PG/MinIO 状态错配均有对账与删除审计。
