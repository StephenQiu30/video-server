## 适合放入

1. 阶段计划与任务拆解。
2. change 的执行路线。
3. 里程碑、排期和交付顺序。
4. 风险、依赖和后续事项。

## 不适合放入

1. 产品需求原文。
2. 详细技术设计。
3. 验收报告或测试记录。
4. 仅服务当前执行的 todo 列表、临时进展记录或过程流水账。

## 命名建议

使用 `顺序编号-语义化标题.md`，例如 `01-URL协议与地址安全计划.md`。
