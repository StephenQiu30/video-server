# 限流配额与合规负向计划

## 1. 背景

公网部署必须启用鉴权、限流、任务额度、并发、文件大小和日志脱敏，防止后端成为滥用工具。

## 2. 目标

- 解析和创建任务有独立限流。
- 用户有日额度、并发、存储、文件大小和保留时间限制。
- 生产模板保留强制替换占位符和负向校验。
- 合规 smoke 覆盖明显违规输入。

## 3. TDD 步骤

1. `test:` 在 `apps/api/tests/test_production_config.py`、`test_rate_limit.py`、`test_task_endpoints.py` 增加负向断言。
2. 运行红灯命令：

```bash
PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_production_config.py apps/api/tests/test_rate_limit.py apps/api/tests/test_task_endpoints.py -q
```

3. `impl:` 调整配置校验、限流、任务额度或 smoke 脚本。
4. 运行绿灯命令和合规 smoke：

```bash
bash scripts/smoke_compliance_negative.sh
```

## 4. 验收门禁

- 未登录不能创建解析或下载任务。
- 额度、并发和大小限制有明确错误。
- 敏感参数不进入日志或错误响应。
- 生产配置模板不能被误用为真实配置。
