# 高级格式与水印提示计划

## 1. 背景

高级用户需要查看平台原始格式。产品同时要求优先无水印，但不得实现主动去水印或绕过平台限制。

## 2. 目标

- 原始格式保留 format_id、分辨率、扩展名、大小、音视频类型。
- 解析响应表达水印状态或不可确认提示。
- 文案统一为“优先无水印源，不主动去水印”。

## 3. TDD 步骤

1. `test:` 在 `apps/api/tests/test_download_adapter.py` 增加 raw format 和水印提示断言。
2. `test:` 在 `apps/api/tests/test_openapi_contract.py` 增加响应 schema 断言。
3. 运行红灯命令：

```bash
PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_download_adapter.py apps/api/tests/test_openapi_contract.py -q
```

4. `impl:` 扩展 schema 和格式映射，保持向后兼容。
5. 运行绿灯命令并检查文案不包含主动去水印承诺。

## 4. 验收门禁

- 高级格式与预设格式可区分。
- 水印提示不承诺移除视频画面水印。
- OpenAPI 文档包含新增字段。
