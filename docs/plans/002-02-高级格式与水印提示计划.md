# PRD002-02 高级格式与水印提示计划

## 1. 背景

PRD002 要求解析结果标识原始格式（raw）、推荐格式（recommended）和清晰度预设格式（video），并对可能包含水印的来源进行提示。产品表述限定为优先可公开获取的无水印或原始源，不包含主动去水印能力。

## 2. 目标

```gherkin
Given 解析结果中存在多种格式
When 用户查看格式列表
Then raw 格式应包含平台原始 format_id、分辨率、文件大小等元数据
And recommended 格式应标注为"推荐下载"
And video 格式应标注清晰度预设

Given 来源为已知带水印平台（如抖音、快手）
When 调用解析接口
Then 格式的 note 字段应提示"该来源可能包含平台水印"
And 不执行去水印操作
```

## 3. 非目标

- 不做主动去水印、裁剪或 AI 修复。
- 不修改 yt-dlp 格式选择逻辑。
- 不新增 DRM 规避能力。

  - 验证已知带水印平台的 note 提示。

- [ ] 运行验证命令确认测试失败。

### 4.2 实现：扩展 schema 和格式映射

- [ ] 在 `_to_parse_response()` 中，根据平台 profile 在 `note` 中追加水印提示。
- [ ] 确保 `kind` 字段正确区分 "recommended"、"video"、"raw"。
- [ ] 更新 OpenAPI schema 文档。

### 4.3 验证：测试通过

## 6. 验收标准

- raw 格式包含平台原始 format_id、分辨率、文件大小。
- recommended 格式正确标识为"推荐下载"。
- 已知带水印平台的格式在 note 中提示水印状态。
- 不包含主动去水印能力。
- 验证命令通过。

## 7. 风险与依赖

- 水印状态判断依赖平台已知特征，无法覆盖所有来源。
- 部分平台的水印策略可能随时间变化。
