# 万能视频下载器 MVP 执行计划

## 1. 背景

本计划把 PRD 001-005 拆为可测试、可提交、可同步 Linear 的阶段任务。所有功能类任务遵循 test-first：先提交 `test:` 定义验收，再提交 `impl:` 最小实现，必要时补 `refactor:`。

## 2. 目标

1. 以混合最小样例验证主流平台公开视频下载闭环。
2. 支持无水印优先提示、预设清晰度和高级原始格式选择。
3. 完成主视频、字幕、封面、元数据、AI 摘要和 PDF 报告的分层产物闭环。
4. 保持自部署 Cookie 和公网 SaaS 合规边界分离。

## 3. 非目标

- 不实现主动去水印。
- 不实现 Cookie 上传或账号托管。
- 不实现批量下载、频道同步或播放列表同步。
- 不承诺所有平台、所有清晰度、所有字幕长期可用。

## 4. 阶段拆解

| 阶段 | 对应 PRD | TDD 入口 | 交付物 |
| --- | --- | --- | --- |
| P0 文档与契约校准 | PRD 001-005 | 文档结构检查、OpenAPI 契约测试 | PRD、计划、测试计划、Linear issue |
| P1 解析与平台画像 | PRD 001 | `test_platform_profiles.py`、`test_parse_error_classification.py` | 平台识别、错误语义、合规提示 |
| P2 格式与水印提示 | PRD 002 | `test_download_adapter.py`、OpenAPI schema 测试 | 预设档位、高级格式、水印能力提示 |
| P3 下载产物归档 | PRD 003 | `test_worker_jobs.py`、`test_task_endpoints.py` | 主文件、字幕、封面、元数据、对象存储 |
| P4 AI 与 PDF 增强 | PRD 004 | `test_ai_intelligence.py`、`test_finalize_features.py` | 摘要、思维导图、PDF 导出 |
| P5 自部署与合规治理 | PRD 005 | `test_production_config.py`、smoke 脚本 | Cookie 配置、限流、配额、合规负向验证 |

## 5. 任务拆分

### 5.1 解析与平台画像

- 先写失败测试：公开样例 URL 应返回平台画像、合规提示和格式入口。
- 最小实现：补齐平台 profile、错误分类和解析响应字段。
- 验证：运行 `PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_platform_profiles.py apps/api/tests/test_parse_error_classification.py`。
- 提交：`test: 定义平台解析验收` -> `impl: 完成平台解析边界`。

### 5.2 分辨率与无水印优先

- 先写失败测试：解析结果应包含推荐档位、常见清晰度、高级原始格式和水印提示。
- 最小实现：扩展 `VideoFormat` 或解析响应字段，避免主动去水印表达。
- 验证：运行 `PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_download_adapter.py apps/api/tests/test_openapi_contract.py`。
- 提交：`test: 定义格式选择验收` -> `impl: 完成格式与水印提示`。

### 5.3 下载任务与产物归档

- 先写失败测试：主视频成功时任务成功，字幕/封面/元数据失败时记录事件但不回退主任务。
- 最小实现：扩展 Worker 产物处理和任务响应字段。
- 验证：运行 `PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_worker_jobs.py apps/api/tests/test_task_endpoints.py`。
- 提交：`test: 定义下载产物归档验收` -> `impl: 完成下载产物归档`。

### 5.4 AI 摘要与 PDF 报告

- 先写失败测试：无 AI key 时跳过，AI 成功时保存摘要和思维导图，PDF 仅允许成功任务导出。
- 最小实现：保持 AI pipeline 异步增强，不影响主视频成功。
- 验证：运行 `PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_ai_intelligence.py apps/api/tests/test_finalize_features.py`。
- 提交：`test: 定义AI与PDF验收` -> `impl: 完成AI与PDF增强`。

### 5.5 自部署 Cookie 与合规治理

- 先写失败测试：支持浏览器名生效，无效配置失败，生产模板不允许默认弱配置。
- 最小实现：收紧配置校验、错误提示和 smoke 负向脚本。
- 验证：运行 `PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_production_config.py apps/api/tests/test_worker_reliability_modules.py` 和 `bash scripts/smoke_compliance_negative.sh`。
- 提交：`test: 定义自部署合规验收` -> `impl: 完成自部署合规治理`。

## 7. 验收门禁

- 每个功能 issue 都有对应 PRD、测试计划和执行命令。
- 每个功能 PR 的首个功能提交必须是 `test:`。
- `npm test` 作为整体验收入口必须通过。
- 无法自动化验证的平台样例必须写入验收记录或 smoke 样例文件。
