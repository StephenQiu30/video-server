# PLAN03 平台画像注册与识别

## 1. 背景

首版需要把“支持哪些平台”变成稳定可测的系统能力，而不是只在 README 里写一句话。

## 2. 目标

1. 固化 5 个正式支持平台画像。
2. API 和任务详情使用统一 `platform_id`。

## 3. 非目标

- 不承诺所有已识别平台都能成功下载。

## 4. 核心内容

1. 建立平台画像注册表。
2. 为 YouTube、Bilibili、TikTok、X、Instagram 编写识别测试。
3. 输出统一展示字段和合规提示。

## 6. 验收门禁

- 5 个正式支持平台均可被识别。
- 平台画像字段和合规提示稳定。

## 7. 风险与边界

平台域名和跳转链接形式可能变动，测试样例应覆盖常见 URL 形态。
