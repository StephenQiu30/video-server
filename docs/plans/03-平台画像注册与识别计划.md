# PLAN03 平台画像注册与识别

## 1. 背景

PRD02 定义了首版 5 个正式支持平台（YouTube、Bilibili、TikTok、X、Instagram），本计划以此为准进行实现规划。

当前代码已实现 10 个平台画像注册（`PLATFORM_PROFILES`）和平台识别（`find_platform_profile`），其中包含 YouTube、Bilibili、TikTok，缺少 X 和 Instagram。

## 2. 目标

1. 固化 5 个正式支持平台画像，与 PRD02 一致。
2. API 在任务创建和任务详情接口中返回统一的平台字段（`platform_id`、`platform_display_name`、`platform_category`、`platform_compliance_note`）。
3. 合规提示不承诺绕过登录、验证码、会员或私密访问限制。

## 3. 非目标

- 不承诺所有已识别平台都能成功下载。
- 不在本计划中定义任务执行或对象存储逻辑。

## 4. 核心内容

### 4.1 正式支持平台画像

以 PRD02 §4.1 为准：

| platform_id | display_name | category | compliance_note |
| --- | --- | --- | --- |
| `youtube` | YouTube | overseas-video | 仅支持公开可访问内容，不承诺绕过登录、年龄验证或会员限制 |
| `bilibili` | Bilibili | cn-video | 仅支持公开可访问内容，不承诺绕过登录、大会员或区域限制 |
| `tiktok` | TikTok | overseas-short-video | 仅支持公开可访问内容，不承诺绕过登录或私密账号限制 |
| `x` | X | social-platform | 仅支持公开可访问内容，不承诺绕过登录或私密账号限制 |
| `instagram` | Instagram | social-platform | 仅支持公开可访问内容，不承诺绕过登录、私密账号或限时动态限制 |

### 4.2 实现差距

当前 `apps/api/app/services/platforms.py` 的差距：

| 差距项 | 说明 |
| --- | --- |
| 缺少 X 平台画像 | 需注册 `x` 平台，hosts: `x.com`, `twitter.com` |
| 缺少 Instagram 平台画像 | 需注册 `instagram` 平台，hosts: `instagram.com` |
| category 命名不一致 | 当前用 `long_video`/`domestic_short_video`，PRD02 用 `overseas-video`/`cn-video` 等 |
| ParseResponse 缺少 `platform_display_name` | schemas.py 未定义该字段 |
| TaskRead 无平台字段 | schemas.py TaskRead 未包含平台字段 |

### 4.3 平台识别逻辑

1. `find_platform_profile(url)` 根据 URL hostname 匹配平台画像。
2. `validate_supported_download_url(url)` 在匹配失败时检查是否为 blocked host。
3. 未匹配的公开 host 允许 yt-dlp best-effort 处理。

### 4.4 API 平台字段契约

#### ParseResponse

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `platform_id` | string \| null | 平台唯一标识 |
| `platform_display_name` | string \| null | 平台展示名称 |
| `platform_category` | string \| null | 平台分类 |
| `compliance_note` | string \| null | 合规提示 |

#### TaskRead

任务详情接口返回与 ParseResponse 一致的平台字段。

## 6. 验收门禁

- 5 个正式支持平台均可被识别（含 X 和 Instagram）。
- 平台画像字段（platform_id、display_name、category、compliance_note）与 PRD02 一致。
- API 返回统一平台字段。
- 合规提示不承诺绕过登录、验证码、会员或私密访问限制。

## 7. 风险与边界

1. 平台域名和跳转链接形式可能变动，测试样例应覆盖常见 URL 形态。
2. X 平台域名从 `twitter.com` 迁移到 `x.com`，需同时匹配两个域名。
3. Instagram 的限时动态和私密内容无法保证可访问性。

## 8. 待确认问题

- 是否在首版中额外支持 X 和 Instagram 的 yt-dlp 适配器（或使用通用 YtDlpAdapter fallback）。
