# PLAN04 创建任务与状态查询

## 1. 背景

异步下载主链路的第一步是把“接单”和“查单”稳定下来，让 API 与 Worker 解耦。

## 2. 目标

1. 支持创建任务、列表和详情查询。
2. 入队前写入 `download_tasks` 初始记录。

## 3. 非目标

- 不在本计划中实现下载执行。

## 4. 核心内容

1. 设计任务创建请求与响应 schema。
2. 建立 `download_tasks` 基本读写。
3. 实现列表与详情查询接口。

## 6. 验收门禁

- 创建任务返回任务 ID 和 `queued` 状态。
- 列表与详情能读出任务基础信息。

## 7. 风险与边界

如果接口先于状态模型定型，后续会频繁调整响应结构。

## 8. 待确认问题
