# Plan 003：AI 转录总结与思维导图

## 1. 前置门禁

Plan 002 完成；资产访问、保留期限和删除语义稳定；用户已独立同意 AI 数据处理。

## 2. 范围

- 本地文件上传和已下载资产作为分析输入。
- FFmpeg 提取单声道压缩音频并按限制切片，保存时间范围。
- OpenAI Audio Adapter 与可替换 Provider Port。
- 章节级 map summary 与整体 reduce summary。
- Strict JSON Schema 生成摘要、章节、术语、行动项和思维导图。
- 每个事实、章节和非根节点关联 transcript evidence。
- Graphviz 只渲染应用生成并转义的层级 JSON。
- AI 失败支持分步骤重试和 `PARTIAL_SUCCESS`。

## 3. 非目标

画面关键帧、多模态视觉理解、身份/情绪推断、模型训练、AI 对话和 PDF。

## 4. 核心验收

- 中文/英文基准转写达到 PRD 阈值。
- 结构 Schema 通过率 100%，严重事实幻觉为 0。
- 关键事实证据覆盖率至少 95%，非根节点至少 90%。
- 无音轨或低置信度时不编造总结。
- 用户可独立重试失败阶段，不覆盖已成功结果。
