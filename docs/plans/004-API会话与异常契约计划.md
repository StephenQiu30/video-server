## 1. 任务边界

实现六个 operation、Pydantic schema、匿名会话、Origin/CORS、Problem Details、幂等 HTTP 行为、健康检查和 OpenAPI 契约；最后运行服务端完整 MVP 回归。不增加兼容 envelope、账号、任务列表或实时推送。

## 5. 验证命令与交付门禁

- `uv run pytest tests/contract tests/integration/api -q`。
- `uv run pytest tests/e2e -q`，使用真实 PostgreSQL、RabbitMQ、MinIO、yt-dlp、FFmpeg 和受控视频。
- `uv run pytest --cov=src --cov-branch --cov-fail-under=90`、Ruff、格式、mypy、Alembic 空库迁移。
- 访问 `/docs` 验证 Swagger UI 可人工审阅并试调；直接读取 `/openapi.json` 验证机器契约、Content-Type 和 operation ID。
- 导出两次 `/openapi.json` 并比较零差异；在 video-web 将 `OPENAPI_SCHEMA_URL` 指向该 JSON，连续执行两次 `npm run openapi`，验证只更新 `src/services/video/` 且零 diff，再运行 TypeScript 构建。
- 逐项停止 PostgreSQL/RabbitMQ/MinIO，记录请求、状态、日志和恢复。
