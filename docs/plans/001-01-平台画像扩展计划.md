# 平台画像扩展计划

## 1. 背景

PRD 001 要求系统识别国内短视频、长视频和海外公开视频平台，并返回平台名称、类别和合规提示。

## 2. 目标

- 覆盖抖音、快手、小红书、西瓜、微博、B 站、YouTube、TikTok、Vimeo、Dailymotion 的平台画像。
- 保持未知公开站点走 yt-dlp best-effort。
- 不把平台画像解释为所有内容都可下载。

## 3. TDD 步骤

1. `test:` 在 `apps/api/tests/test_platform_profiles.py` 增加平台 host、短链和合规提示断言。
2. 运行红灯命令：

```bash
PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_platform_profiles.py -q
```

3. `impl:` 在 `apps/api/app/services/platforms.py` 补齐或调整平台画像。
4. 运行绿灯命令：

```bash
PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_platform_profiles.py -q
```

## 4. 验收门禁

- 每个平台返回稳定 `id`、`display_name`、`category`。
- 每个高风险平台有明确 `compliance_note`。
- 未知公共 host 不被平台画像误拒绝。
