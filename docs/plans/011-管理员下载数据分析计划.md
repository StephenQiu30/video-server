# 011 管理员下载数据分析计划

- 状态：Ready
- 日期：2026-08-10
- 关联 Design：`docs/design/011-管理员下载数据分析设计.md`
- 关联 PRD：`docs/prd/011-管理员下载数据分析需求.md`

## 1. 实施顺序

1. 先冻结 `days=7..365`、UTC 日边界、状态分类、成功率 0–100 和响应字段白名单，增加 OpenAPI 契约测试。
2. 在应用层增加管理员下载分析用例、只读 repository 端口和纯应用模型，用例内二次校验 actor 角色。
3. 使用现有 `download_jobs.inspection_id -> media_inspections.id` 关联实现摘要、UTC 日趋势和 `extractor_key` 来源聚合；不解密 URL，不增加来源冗余列或分析事实表。
4. 按查询计划在 `backend/sql/schema.sql` 和 SQLAlchemy ORM 同步必要的时间范围索引，用新数据库验证当前态 schema。
5. 增加 `GET /api/admin/downloads/analytics` 路由与严格响应 schema，复用 `admin` tag 和 `get_current_admin`，稳定 `operationId` 为 `getDownloadAnalytics`。
6. 运行 OpenAPI 生成，在手写薄 facade 中复用生成请求/类型，不修改 `frontend/src/services/video/` 生成文件。
7. 增加 `/admin/analytics` 静态页面、管理员守卫、桌面账户菜单/移动 Sheet 入口以及返回 `/account` 的稳定 fallback。
8. 实现窗口选择、刷新、摘要、日趋势、来源分布和等价语义列表，覆盖加载/空/错误/过期响应状态。
9. 完成后端契约、应用、repository 和路由集成测试，以及前端服务、页面、导航、权限、响应式和可访问性测试；真实 PostgreSQL 口径与浏览器无障碍证据在 Acceptance 中保持待验收。
10. 运行全量工程门禁，并在同一变更中回填 011 Acceptance 与 `design-qa.md` 的浏览器证据。

## 3. 后端测试覆盖

- OpenAPI：新路径、`getDownloadAnalytics`、单一 `admin` tag、`days` 默认/边界、200 响应 `$ref`；同步更新全局精确 operationId 集合。
- 路由集成：未登录 401、普通用户 403、管理员 200，默认 30 与合法值透传，6/366 返回 422，服务未装配时返回 503。
- 应用用例：普通 actor 直接调用仍被拒绝；时间边界、repository 结果映射、空结果和非法成功率不能绕过验证。
- Repository：至少准备多来源、六种状态、多日、UTC 边界、空白日、过期 inspection、幂等重放和其他来源数据；断言计数、排序和 0–100 成功率。
- 安全白名单：完整 JSON 中不得出现 URL/密文包、`owner_hash`、`provider_media_id`、`provider_hints`、`error_message`、对象 key 或用户字段。
- 数据库：单元测试验证第一日 UTC 00:00 到当前时刻的包含边界、日分桶和新索引；PostgreSQL 实际行为留待 Acceptance 取证。

## 4. 前端测试覆盖

- API facade：验证生成客户端发送 `GET /api/admin/downloads/analytics` 并正确传递 `days`。
- 页面数据：默认 30 天，只在 7/30/90 天快捷值之间切换，刷新复用当前值，快速切换时忽略旧响应。
- 呈现：摘要的任务/状态、去重用户、制品字节、平均时长和成功率，每日趋势，来源排名/用户/字节/成功率均正确显示；不再将后端 0–100 百分比乘以 100。
- 状态：认证恢复骨架、首次加载、空数据、请求失败与重试、刷新时保留旧数据。
- 权限与导航：管理员桌面菜单/移动 Sheet 有入口和当前页语义；普通用户无入口且 `ProtectedRoute requireAdmin` 不渲染内容。
- 可访问性：唯一 `h1`、真实 label/button/figure/table 或 list，图表可读名称，精确数值不只存在于 Tooltip，状态不只靠颜色。
- 浏览器：1280px 和 390×844 无横向溢出，键盘可切换窗口/刷新，200% 缩放、明暗主题和 reduced motion 下数据仍可读。

## 5. 不做项

不增加 migration 目录；按仓库规范同步当前态 SQL 和 ORM。不增加来源冗余列、分析事实表、原始 URL 导出、用户明细、自动轮询或独立前端运行时。
