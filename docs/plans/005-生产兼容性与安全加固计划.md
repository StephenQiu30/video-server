# Plan 005：生产兼容性与安全加固

## 1. 范围

- 来源兼容 canary、版本快速升级/回滚和政策定期复核。
- 容量、背压、队列隔离、配额、成本预算与灾难恢复。
- DNS rebinding、重定向、资源耗尽、worker 逃逸和跨用户访问测试。
- OpenTelemetry、SLO、告警、运行手册和数据清理演练。
- PostgreSQL WAL/PITR 恢复、Redis 全失重建、MinIO 独立故障域备份/复制和 PG↔MinIO 对账的周期演练，验证系统默认 RPO≤5 分钟、RTO≤2 小时。
- MinIO Community 上游归档风险复核：生产必须记录维护发行版或明确风险接受、安全补丁责任与固定 digest；不满足则生产发布保持 blocked。
- SMTP 延迟/拒收、邮件 outbox 重放、认证限流和会话全量撤销的故障演练。
- 基于关键帧的多模态视觉总结独立评估，不默认进入 MVP。

## 2. 非目标

DRM 或平台限制绕过、无限来源承诺、无限容量和未评审的新供应商。

## 3. 解锁条件

Plan 000 至 004 的 Acceptance 已完成且无未解决的身份、持久化、安全或隐私 blocker。
