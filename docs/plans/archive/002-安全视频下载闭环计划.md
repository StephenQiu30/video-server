# 002 安全视频下载闭环计划

- 状态：Completed

## 实施顺序

1. 先实现 Domain：语义格式、DownloadJob 状态机、lease、错误分类与纯单测。
2. 建立 PostgreSQL 当前态 SQL、repository 与 transactional outbox。
3. 建立无凭据 Media Runner、HMAC、受控子进程组、工作目录与资源限制。
4. 配置 egress proxy，并用私网/重定向/DNS 用例验证。
5. 实现 inspect、格式规范化和 re-inspect 语义重匹配。
6. 实现 Worker 领取、心跳、进度、取消、硬超时、remux、ffprobe、SHA 和 MinIO 上传。
7. 实现 API/session/idempotency/problem details 与前端完整下载流程。
8. 使用真实 PostgreSQL/RabbitMQ/MinIO/yt-dlp/FFmpeg 完成受控直链 MP4 核心 E2E。
9. 为 failed/cancelled 终态任务增加幂等的人工重试 API 与页面入口，以新任务保留原历史，并覆盖 inspection 过期与所有权边界。

## 提交切片

每个步骤按 `test → implementation → docs/evidence` 分离，禁止用 Mock-only 测试宣称下载闭环完成。
