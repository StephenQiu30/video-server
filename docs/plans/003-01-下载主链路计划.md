# 子计划 003-01：下载主链路

更新时间：2026-06-02
关联 Issue：STE-58
父 PRD：`docs/prd/003-下载任务与产物归档.md`

## 1. 目标

确保下载主链路（主视频文件）的任务状态机、Worker 流程、失败分类和对象存储交付稳定可验证。

## 2. 任务状态机

### 2.1 状态定义

参见 PRD 第 3.1 节。实现代码位于 `packages/shared/video_downloader_shared/states.py`。

### 2.2 状态流转规则

| 当前状态 | 允许的目标状态 | 触发条件 |
|---|---|---|
| QUEUED | RUNNING | Worker 开始处理 |
| QUEUED | CANCELED | 用户取消 |
| QUEUED | FAILED | 队列不可用、超时 |
| RUNNING | SUCCEEDED | 主视频上传完成 |
| RUNNING | FAILED | 下载/校验/上传失败 |
| RUNNING | CANCELED | 用户取消 |

### 2.3 事件流

每次状态变更记录 `TaskEvent`：
1. `QUEUED` → "任务已创建，等待下载"
2. `RUNNING` → "Worker 已开始下载"
3. `RUNNING` → "开始下载源文件"
4. `RUNNING` → "源文件下载完成"
5. `RUNNING` → "开始校验媒体文件"
6. `RUNNING` → "开始上传到私有对象存储"
7. `SUCCEEDED` → "文件已保存到私有对象存储"

## 3. Worker 下载流程

### 3.1 流程步骤

```
1. 断言媒体工具可用（ffmpeg, ffprobe）
2. 创建任务工作目录
3. 标记任务为 RUNNING
4. 调用 yt-dlp 下载源文件
5. 校验文件大小限制
6. ffprobe 校验媒体文件有效性
7. 上传到私有对象存储
8. 设置任务为 SUCCEEDED
9. 清理工作目录
```

### 3.2 关键实现

- **下载入口**：`apps/worker/worker/download_runner.py` → `download_task_artifact()`
- **媒体校验**：`apps/worker/worker/media_probe.py` → `probe_with_ffprobe()`
- **存储上传**：`apps/worker/worker/artifact_storage.py` → `upload_artifact()`
- **任务编排**：`apps/worker/worker/jobs.py` → `process_download_task()`

### 3.3 取消检测

- 每个关键步骤前检查任务是否已取消
- 取消时清理已上传的对象文件
- 取消通过 `JobFailure(TASK_CANCELED)` 抛出

## 4. 失败分类与错误码

### 4.1 错误码定义

| 错误码 | 含义 | 可重试 |
|---|---|---|
| `download_failed` | 通用下载失败 | 是 |
| `format_unavailable` | 所选格式不可用 | 否 |
| `file_too_large` | 文件超过大小限制 | 否 |
| `media_tools_missing` | FFmpeg/ffprobe 不可用 | 否 |
| `ffprobe_failed` | 媒体校验失败 | 否 |
| `storage_failed` | 对象存储上传失败 | 是 |
| `task_timeout` | 任务超时 | 是 |
| `task_canceled` | 用户取消 | 否 |
| `platform_restricted` | 平台限制 | 否 |
| `platform_rate_limited` | 平台限流 | 是 |
| `unsupported_platform` | 不支持的平台 | 否 |
| `browser_cookies_unavailable` | 浏览器登录态不可用 | 否 |
| `retention_expired` | 文件已过期 | 否（需重试） |

### 4.2 错误分类逻辑

实现位于 `apps/worker/worker/failures.py`：
- `failure_code(exc)`：根据异常类型和消息分类错误码
- `format_failure_reason(exc)`：生成用户友好的中文错误描述
- `failure_info_from_exception(exc, stage)`：生成完整的失败信息

### 4.3 URL 脱敏

错误消息中的 URL 参数必须脱敏，不暴露 token、签名等敏感信息。
