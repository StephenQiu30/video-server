# 下载主链路计划

## 1. 背景

主视频文件是任务成功的必要产物。Worker 必须完成下载、音视频合并、媒体校验、对象存储上传和下载链接生成。

## 2. 目标

- 任务状态从 queued 到 running 到 succeeded 或 failed 可追踪。
- 主文件成功上传后提供短期预签名下载链接。
- FFmpeg、大小限制、上传失败等错误有可读原因。

## 3. TDD 步骤

1. `test:` 在 `apps/api/tests/test_worker_jobs.py` 和 `apps/api/tests/test_task_endpoints.py` 增加主链路状态、事件和下载链接断言。
2. 运行红灯命令：

```bash
PYTHONPATH=apps/api:apps/worker:packages/shared pytest apps/api/tests/test_worker_jobs.py apps/api/tests/test_task_endpoints.py -q
```

3. `impl:` 调整 Worker 下载、媒体校验、对象存储和任务响应。
4. 运行绿灯命令并补充必要 smoke。

## 4. 验收门禁

- 主视频成功后 `state=succeeded`、`progress=100`。
- 下载链接只对任务拥有者可用。
- 失败任务包含 `failure_code` 和 `failure_reason`。
