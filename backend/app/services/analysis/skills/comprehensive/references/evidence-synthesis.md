# 综合分析证据规范

## 一、三层证据链

1. **观察层**：分析分镜区间、边界类型、代表帧、可见主体、动作、构图、画面文字和状态变化。边界区分物理编辑、确认连续节拍与证据不足的未知类型。
2. **解释层**：镜头功能、段落转折、节奏、视觉模式和可能的表达效果。措辞应说明依据，不把推断写成创作者明确意图。
3. **建议层**：复刻、剪辑、生成或资产整理建议。必须引用观察层对象并带可执行动作。

若解释与观察冲突，以观察为准；若证据不足，把结论降级为保守描述，不用常识填补。

## 二、段落归纳

内容段落可由以下一种或多种变化触发：空间/主体切换、视觉目标改变、信息密度变化、镜头时长簇变化、静动转换、色调重置或明确转场卡。段落边界不等于每个 Cut，也不能只靠固定时长。

`summary.text` 应包含：

- 视频的可见主题或任务；
- 主要段落如何推进；
- 最关键的视觉转折；
- 全片主要节奏或形式特征；
- 证据不足时的限制。

`summary.evidence_shot_ids` 至少覆盖开端、中段关键转折和结尾，不得只引用单一高光。

## 三、覆盖矩阵

完成前逐项检查：

| 维度 | 最低要求 |
|---|---|
| 时间线 | 从 0 连续到权威时长；物理编辑与连续节拍不混淆 |
| 结构 | 每个主要视觉段落有代表镜头 |
| 转折 | 关键变化有前后镜头证据 |
| 高光 | 候选理由可由画面证明，且不是全部镜头 |
| 资产 | 核心身份合并，关键状态有证据 |
| 建议 | 每项包含对象、动作和验收条件 |

连续长镜头若先后完成不同主体任务、空间阶段或信息状态，应按可复核节拍拆成多项，并使用 `transition_in=continuous`。禁止固定时长切片；超过 10 秒仍保持单项时，必须确认全片没有值得独立复核的视觉阶段并标记 `segmentation:single-unit-verified`。

## 四、制作建议优先级

优先级依次考虑：

1. 是否承载核心叙事转折；
2. 是否建立风格或空间规则；
3. 是否可作为角色/场景/道具连续性的基准；
4. 是否存在复杂动作、遮挡、文字或状态变化风险；
5. 是否能在不依赖未知音频的情况下被可靠复刻。

不要编造成本、排期、平台效果、供应商能力或已经完成的生产状态。
