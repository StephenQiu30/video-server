# 剧本审稿的专项判断

## 结构：承诺、推进与回报

- 从原文识别主角追求、阻力机制和可见代价。检查中段是否改变权力、知识、关系、资源、暴露或时间压力；同一羞辱、误会或救援反复出现，只有后一次产生新选择或新代价时才算升级。
- 关键转折应改变后续可行选项，不能仅因场面更响或地点改变就称为转折。铺垫与回报要看前因是否进入后续行动；类型惯例和有意留白不自动构成缺陷。
- 长篇或分集剧本检查每个局部单元是否在下一次悬念前产生可辨认的结果，后续是否继承这个结果。不要按固定页码、集数或幕数给质量评分。

## 人物：目标、策略、压力和选择

- 分开写人物声称的价值与压力下实际采取的行动。弧线可以是成长、退缩、停滞或拒绝改变；只在文本展示了压力测试、选择、局部结果与代价时声称发生变化。
- 检查人物惯常策略是否在新的阻力面前调整。对手可以是人物、制度、环境或内在信念；不要为了符合模板强加一个“更强反派”。
- 如果某项证物或对白只证明了时间、地点或状态，不把它升级为动机、身份或完整机制。区分世界事实、角色相信和观众知道。

## 场景与节奏：行动—反应—下一步

- `purpose` 说明这场为何存在；`conflict` 说明谁想改变什么以及阻力；`turn` 说明场末目标、信息、关系、资源或代价怎样变化；`pacing` 指出造成停滞或推进的具体节拍。
- 检查结果之后是否给人物处理、犹豫或决定的空间，以及该决定是否形成下一场的追求。情绪消化可以很短，不能因为没有外部动作便一律判为拖沓。
- 对重复场景比较策略和代价，至少说明两个位置与各自功能；有意的仪式、喜剧重复或创伤反应可能恰恰改变意义，不能仅凭表面相似判为模板。

## 对白：作为行动而非信息容器

- 问说话者此刻想让对方做什么、用什么言语策略、对方如何回应。潜台词要由行动与反应支持，不能只凭措辞猜心理。
- 分辨人物声音、信息倾倒、已知事实的重复说明和对白对关系的实际改变。若两人反复质问与否认而筹码不变，指出需要改变的行动或信息，而不是只要求“更自然”。
- 沉默、动作和道具可以承担对白功能；建议可以指出可演的替代方向，但不直接补写未经请求的新台词。

## 制作边界

文本中的人物、地点、物件和可见动作可作为后续生产的待确认线索；当前结果不创建镜头、资产、拍摄计划或人工决定。源场景也不等于未来 Cut 或固定时长单元。
