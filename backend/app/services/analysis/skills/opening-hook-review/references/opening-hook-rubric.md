# 开场钩子审查量表

## 1. 观察窗口

- `0–3s`：首个可见注意力锚点。记录主体、动作、状态变化或真实可辨认文字，以及它们是否形成清晰视觉优先级。
- `0–5s`：可见内容承诺。判断画面是否已让观众知道应继续关注什么，不用未获取的语音补齐含义。
- `0–15s`：视觉进展。检查主体、信息、关系或状态是否发生可理解的推进，以及开场是否平稳进入正文。

视频比窗口更短时，使用实际时长而不推断缺失内容。即使前 15 秒已经形成结论，仍须观察全片，因为承诺兑现、迟到信息和重复段落可能只在后续画面中出现。

## 2. 评估维度

### A. 注意力锚点

检查是否有一个明确的主体、动作或状态变化先于其他信息被看见。多个元素同时移动、多行文字竞争、主体太小或无任务的过场都要记录具体影响。不把更大、更亮或更快自动视为更有效。

### B. 内容承诺

承诺是开场画面对后续内容的可见预期：一个问题、结果、冲突、变化或明确对象。只能从画面和真实可辨认文字归纳，不把片名、文件名、假定台词或创作者意图当作已发生事实。

### C. 有意义的视觉进展

区分四种情况：

- 受控进展：每次 Cut、运镜或画面内变化都提供新状态或新关系。
- 停滞：长时间无可见信息、动作或状态变化，且没有明确的视觉目的。
- 碎片化：变化频繁但主体、空间或动作无法延续，相邻镜头不形成可理解关系。
- 过载：单镜或短窗口中同时要求读取过多文字、主体或动作，且没有足够停留。

镜头数量和变化频率本身都不是质量指标。

当进展发生在连续长镜头内部时，只有新的注意力锚点、承诺、发展、兑现或正文交接已经形成独立进入/退出状态，才建立 `transition_in=continuous` 分镜。3/5/15 秒仅是审查窗口，不能直接成为分镜边界。

### D. 文字可读性与认知负担

只评价当前证据中实际可见的文字。记录字号、对比、背景干扰、透视压缩、出现时长和与主体动作的竞争。无法确认文字时使用 `text:uncertain`，不猜测文案内容。

### E. 承诺兑现

在后续分镜中寻找与开场问题、结果、主体或变化相关的可见状态。延迟兑现、完全不兑现、只在文字中声称或画面证据不足必须分开记录。

### F. 正文衔接与可剪性

检查开场动作或状态是否完整落定，是否从动作中间无目的切断，以及进入正文时空间、主体、运动方向或信息目标是否可以继承。

## 3. 证据写法

每个重要诊断都包含：

1. 位置：真实 `shot.id` 或连续分镜范围。
2. 观察：画面中真实可见的主体、动作、构图、文字或状态变化。
3. 影响：该观察如何影响视觉优先级、内容理解、进展或衔接。
4. 修订结果：应保留的不变量与需要达到的效果，而不是未经请求的全片代写或自动剪辑。

“不够吸引人”、“节奏不好”、“很有 AI 感”或“预计留存会提升”都不是有效证据陈述。

## 4. 受控标签

开场分镜优先使用以下 `visual_tags` 前缀，每个标签只表达一个当前画面可支持的状态：

- `hook-role:anchor|promise|development|payoff|handoff`
- `attention:clear|competing|weak|uncertain`
- `text:readable|crowded|too-small|uncertain`
- `pacing:controlled|static|fragmented|overloaded`
- `payoff:aligned|delayed|missing|uncertain`

后续分镜不需为了表面一致而填充无意义的钩子标签。

## 5. 字段交付

- `summary.text`：写开场判断、证据最强的优势、优先风险和后续兑现状态。
- `summary.evidence_shot_ids`：至少覆盖开场锚点；评价兑现时同时引用相关后续镜头。
- `highlights`：表达能独立成立的开场优势或关键兑现候选；分数仅用于本结果内排序。
- `scenes[].continuity_risks`：记录开场与正文之间的具体断裂、重复、方向或状态不连续。
- `production_advice`：按影响与可执行性排序，引用优先分镜，并在 `recommended_extensions` 写需要的人工复核、文字清晰度检查、更密观察或后续剪辑建议。

## 6. 交付自检

- 全片 `shots` 从 0 连续覆盖到权威时长，`scenes` 覆盖每个分镜一次。
- 真实编辑与连续节拍已分开标记；没有因开场无 Cut 而折叠可见进展，也没有按 3/5/15 秒机械拆镜。
- 3/5/15 秒窗口均已检查，短片段使用实际时长。
- 每个结论都能回到可见画面和真实分镜，没有音频、平台表现或创作者意图猜测。
- 建议说明保留内容和目标结果，没有声称已剪辑、已生成、已发布或已提升业务指标。
