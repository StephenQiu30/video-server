# 高光候选量表

## 一、五维评分

每项 0–4 分，只依据可见画面：

1. **视觉显著性**：构图、动作、尺度、色彩或状态变化是否形成清晰焦点。
2. **信息/情绪转折**：是否出现可见的新信息、选择、结果、反应或关系变化。
3. **上下文独立性**：脱离长前文后，核心画面是否仍可理解；需要多少前置镜头。
4. **可剪辑性**：是否有完整进入点、动作/节拍和退出点；是否适合单独回看或编入预告。
5. **复用与连续性**：是否具有代表性，且不存在严重遮挡、文字残缺、动作中断或状态冲突。

先计算内部总分 0–20，再映射到输出 `score` 0–100：`总分 × 5`。`shot.highlight_score` 映射为：0–4→1，5–8→2，9–12→3，13–16→4，17–20→5。

评分只用于同一视频内排序。禁止写成算法预测、平台表现或用户偏好事实。

## 二、候选边界

- **进入点**：主体、空间或问题已经可理解，避免从动作半途开始。
- **核心点**：包含最关键的可见变化或构图。
- **退出点**：动作结果、反应或视觉停顿已完成，避免过早切断。
- 若转折依赖两个相邻镜头，合为一个高光并引用全部证据镜头；若中间有无关段落则拆分。

## 三、去重与多样性

两个候选若主体、动作、构图、信息任务和节奏作用大体相同，只保留总分更高者。最终候选尽量覆盖不同用途，例如：建立世界、人物反应、动作峰值、信息揭示、视觉转场或收束画面；不要为追求类别齐全而保留弱候选。

## 四、理由模板

`reason` 使用：`主要优势；完整性证据；相对其他候选的区别；使用前需验证的风险`。

避免“有传播力”“很震撼”“情绪拉满”等循环论证。若没有可访问音频，不得以对白金句、节拍或音效冲击作为评分依据。
