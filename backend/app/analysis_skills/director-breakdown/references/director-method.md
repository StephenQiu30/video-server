# 导演拉片方法

## 一、六层判读

对每个镜头按以下顺序分析，后一层不得覆盖前一层的不确定性。

1. **Cut 与状态**：边界前后是否发生硬切、渐变、遮挡切、空间变化或连续动作语义变化；分别观察起始、代表和结束状态。
2. **画面调度**：主体从哪里开始、发生什么可见动作、在哪里结束；多主体时记录距离、朝向、遮挡、前后景关系和权力位置变化。
3. **摄影与美术**：景别、可见角度、构图重心、层次、负空间、光源方向、明暗关系、主色和关键道具。焦段、灯具型号、曝光数值不可仅凭画面断言。
4. **剪辑关系**：本镜如何承接上一镜并交给下一镜；检查动作匹配、视线匹配、运动方向、图形/色彩匹配、反应镜头、插入镜头和有意跳切。
5. **叙事节拍**：本镜头只承担一个首要任务，例如建立空间、交代信息、隐藏信息、触发选择、展示反应、升级冲突、释放压力或收束段落。
6. **制作转译**：说明最值得保留的画面约束、连续性锚点、适合复刻的原因和容易失败的地方；不要声称已经生成或选定镜头。

## 二、字段编码

- `description`：`主体/位置与动作；空间/构图；光线/色彩；起始状态 → 结束状态`。只写画面可证实内容。
- `shot_size`、`camera_motion`、`transition_in`：使用 Schema 枚举。无法确认时选 `unknown`，混合且不可归为单一类型时选 `mixed`。
- `narrative_function`：`节拍：……；承接/转折：……；依据：……`。
- `visual_tags`：优先使用 `angle:`、`composition:`、`lighting:`、`palette:`、`continuity:`、`rhythm:` 前缀；每项应短、具体、可比较。
- `highlight_score`：1=仅维持连续，2=有辅助信息，3=完成明确节拍，4=关键转折或强表达，5=不可替代的核心画面。不要预测播放量或转化率。

## 三、序列级检查

1. 第一镜是否建立了足够空间；若故意延迟建立，说明其叙事作用。
2. 相邻镜头是否保持人物朝向、运动方向、道具位置、服装状态和光线方向；变化若有画面依据，描述为状态变化。
3. 同轴剪辑若仅有轻微景别变化，检查是否造成视觉跳动；不要把经验法则写成绝对错误。
4. 动作开始于上一镜、完成于下一镜时，分别记录两镜承担的动作阶段。
5. 找出节奏改变的证据：镜头时长簇变化、静止转运动、大全景转特写、色彩/亮度突变或视觉信息密度变化。
6. 摘要必须能被具体镜头支持；制作建议的优先镜头必须来自同一分析结果。

## 四、复刻建议模板

`production_advice.summary` 回答：应保留哪条视觉规则、核心节拍怎样组织、最大连续性风险是什么。

`recommended_extensions` 每项使用：`适用镜头/段落；保留约束；可执行动作；验收条件`。

例如：“Shot 004–006；保持人物始终面向画面右侧和桌上红色道具位置；先生成固定机位建立镜头，再生成反应特写；检查切换后视线与道具状态一致。”

## 五、完成条件

- 时间线连续覆盖且边界经过画面复核。
- 每镜的描述、叙事功能和标签互相补充，不重复同一句话。
- 至少检查空间、调度、镜头动机、剪辑关系、节奏和连续性六层。
- 所有高光、资产、摘要和建议引用存在的镜头；没有音频证据的结论保持为限制。
