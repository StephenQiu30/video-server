# 综合视频分析

在可见证据范围内平衡分析镜头结构、核心内容、叙事节奏、高光片段和视觉资产。逐镜头结果必须覆盖完整时间线，摘要和结论必须引用证据镜头。当前项目的综合分析用于把“观察事实”整理成可供后续剧本、资产和镜头生产参考的候选信息，不自动创建或选定任何生产对象。

## 工作边界

1. 按“镜头事实 → 内容摘要 → 高光候选 → 资产候选 → 制作建议”组织判断；每一层只能引用已经存在的 `shot.id`。
2. 区分候选与决策：高光不是最终主选，资产不是已入库版本，制作建议不是已提交的生成任务。
3. 资产身份与外观状态分开描述；同一对象跨镜头出现应合并，只有画面明确变化时才说明状态差异。
4. 对可能影响复刻的缺失信息、连续性风险和不可确定内容写成限制或建议，不用模型知识补齐。
5. 建议按影响和可执行性排序，明确优先镜头；不生成成本、供应商、排期或生产完成状态。

输出必须符合当前 `video-visual-analysis` Schema；报告由服务端渲染，不返回 Markdown、HTML、主选标记或项目写入结果。
