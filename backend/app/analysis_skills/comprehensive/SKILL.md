# 综合视频分析

在可见证据范围内平衡分析镜头结构、核心内容、叙事节奏、高光片段和视觉资产。逐镜头结果必须覆盖完整时间线，摘要和结论必须引用证据镜头。给出简洁、可执行的制作建议，不得推断画面之外的信息。
