# 场景边界与提炼规范

## 一、场景定义

一个场景段落同时满足大部分条件：

- 相邻镜头处于可理解的连续时间范围；
- 空间关系稳定，或交叉剪辑仍在完成同一连续事件；
- 主体和主要事件目标没有重置；
- 构图、光色、镜头运动或画面材质遵循一组相对稳定的视觉规则；
- 这些镜头共同完成一个主要叙事任务。

单个镜头可以独立成场景，但不能因为镜头数量少而与相邻段落强行合并。

## 二、边界证据

按强到弱检查：

1. **空间重置**：地点、室内外、舞台/界面层级或空间布局发生明确变化。
2. **时间重置**：昼夜、天气、服装/道具状态、进度画面或明确时间卡发生变化。
3. **事件重置**：上一任务已经完成/中断，新主体或新行动目标开始。
4. **视觉重置**：画幅、色调、媒介形态、镜头运动规则或信息密度形成新的稳定簇。
5. **段落标记**：标题卡、黑场、建立镜头、进出场、蒙太奇起止或明显节奏停顿。

只有单个 Cut、轻微景别变化或同一动作的反打通常不足以建立新场景。

## 三、字段规范

- `id`：稳定标识，如 `scene-001`；`index` 从 1 连续递增。
- `title`：使用“主体/事件 + 场景任务”的短标题，不使用“场景一”或空泛情绪词。
- `location`：可见空间，例如“白墙会议室”“夜间街道”“深色产品演示台”；未知时写“空间无法确认”，不猜地名。
- `description`：`开始状态；主体与事件推进；关键可见变化；结束状态`。
- `narrative_function`：`本场景任务；承接上一场的依据；进入下一场的触发`。
- `visual_rules`：2–6 条稳定且可执行的规则，覆盖构图/机位、光色、运动、空间或关键资产中的实际相关项。
- `continuity_risks`：具体到人物朝向、道具状态、屏幕文字、空间位置、服装、光线或动作衔接；不写“注意保持一致”。
- `evidence_shot_ids`：按时间顺序列出本场景全部镜头，不可只选代表镜头。

## 四、归并算法

1. 从 Shot 001 开始建立当前场景。
2. 对每个相邻镜头比较空间、时间、事件目标和视觉规则。
3. 若变化只是覆盖角度、反应镜头、插入特写或同一连续动作，继续归并。
4. 若至少一个强边界成立，或多个弱边界共同表明任务已重置，结束当前场景并建立下一场。
5. 完成后反向检查：相邻两场能否用一句明确的“为什么这里换场”区分；不能则合并。

## 五、验收

- 所有场景 `evidence_shot_ids` 首尾相接，合计恰好覆盖全部镜头一次。
- 场景时间由证据镜头派生，不自行返回或估算。
- 每场只有一个主要叙事任务，标题、描述和功能不互相重复。
- 同地点回返、蒙太奇和交叉剪辑按连续时间段处理，并说明呼应而非跨段合并。
- 视觉规则足以指导场景复刻，连续性风险足以被人工验收。
