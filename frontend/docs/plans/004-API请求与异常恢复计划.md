## 1. 任务边界

建立唯一 Umi Request、React Query、OpenAPI 生成 Service、Problem Details 转换、Cookie/隐私过滤、mutation/GET 策略和依赖故障行为。不实现页面业务状态，不增加 Axios/fetch client、兼容 DTO 或 Mock fallback。

## 3. 预期文件边界

- `config/config.ts` 启用 `@umijs/max-plugin-openapi`，唯一 `openAPI` 项配置环境 `schemaPath`、`projectName: 'video'`、`@umijs/max` Request 与 `mock: false`；`config/proxy.ts` 读取 API/代理环境；复用 Plan 001 的 `.env.example`。
- `package.json` 固定提供 `"openapi": "max openapi"`；不得增加第二个生成器或抓取 Swagger UI HTML 的脚本。
- `src/app.tsx`、`src/requestErrorConfig.ts`。
- 生成目录 `src/services/video/{typings.d.ts,*.ts}`，提交版本库且禁止手改；不在目录外手写 API 文件或复制 DTO。
- 请求/错误/生成测试与 schema 来源记录；不提交临时下载的 OpenAPI。

## 5. 验证命令

- 启动真实 video-server，确认 `/docs` 可人工浏览、`/openapi.json` 可机器读取；`OPENAPI_SCHEMA_URL` 只指向后者。
- 执行 `npm run openapi`，确认调用 `max openapi` 且只生成 `src/services/video/`；再次执行并运行 `git diff --exit-code -- src/services/video`。
- 检查生成结果包含且只暴露约定的四个 operation，随后执行 TypeScript 构建；schema 缺失、operation ID 缺失/重复时必须失败。
- `npm run test -- request`、`npm run test:coverage`。
- `npm run lint`、`npm run format:check`、`npm run typecheck`、`npm run build`。
- AST/源码扫描 Axios、裸 fetch、裸 URL、重复 DTO、`any`、Mock fallback。
- 连接真实 Server，逐项停止 Server 与 MinIO 验证错误和恢复。
