实现单任务状态、轮询、刷新恢复、错误保持、点击签发 URL 和真实 MinIO 下载；最后执行 Web 全量 DAC/AC 与完整“链接→文件”回归。不增加任务列表、取消、暂停或浏览器 Blob 下载。
