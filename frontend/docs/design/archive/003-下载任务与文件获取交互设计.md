## 1. 页面职责

`/downloads/:jobId` 只展示一个任务的状态和最终文件，不展示任务列表、不修改格式、不创建第二个任务。

状态视图：`loading → queued → running → succeeded | failed | expired`。

- queued：等待处理，无伪进度。
- running：显示 stage；有 progress 时显示百分比，null 时显示不确定进度。
- succeeded：文件名、类型、大小、SHA-256、过期时间和“下载文件”。
- failed：安全错误信息与“返回重新提交”。
- expired：明确文件已过期，禁用下载。
- 未知状态：进入安全错误页，绝不按成功渲染。

## 2. 轮询和刷新恢复

- 使用 React Query；queued/running 每 2 秒查询，终态停止。
- 页面隐藏、浏览器离线或组件卸载时暂停；恢复后立即查询一次。
- GET 临时失败保留最后一次真实状态并显示连接提示，不把任务改成 failed。
- 刷新、前进和后退只依赖 route job ID 与 HttpOnly Cookie；不依赖内存、localStorage 或 sessionStorage。
- 404 与跨会话 403 不自动重试；网络错误最多按 React Query GET 策略有限重试。

## 3. MinIO 文件获取

用户点击时才调用 `POST /api/v1/downloads/{jobId}/download-url`：

1. 按钮进入 loading，禁止重复请求。
2. 成功后创建临时 `<a>`，设置 `referrerPolicy=no-referrer`，直接访问 MinIO 预签名 URL。
3. URL 不写入 React Query cache、路由、DOM 长期状态、剪贴板、日志或错误上报。
4. 地址获取失败保留 succeeded 任务，可再次点击；任务过期则切 expired。

浏览器不 Fetch 大文件为 Blob，不让视频内容经过 Web 内存；文件名以服务端/MinIO `Content-Disposition` 为准。

## 4. 可访问性与响应式

- 进度同时有文本、数值/不确定状态，不反复抢焦点。
- 成功、失败、过期都有标题、说明、图标和唯一主操作，不只用颜色。
- 375px 下文件元数据换行但不溢出，长标题和 SHA-256 可安全断行。
- 页面标题含安全短 job ID，不含视频 URL、标题或预签名地址。

## 5. Design Acceptance Criteria

| 编号 | 必须证明 | 实现后证据 |
| --- | --- | --- |
| `W003-DAC-01` | queued/running/succeeded/failed/expired/未知状态各有唯一安全视图 | 全状态组件测试与截图 |
| `W003-DAC-02` | 仅活动任务轮询，隐藏/离线/终态/卸载立即停止，恢复准确 | Fake Timer、visibility、online/offline 测试 |
| `W003-DAC-03` | 刷新任务 URL 能由真实 Server+Cookie 恢复，不依赖浏览器持久存储 | 浏览器刷新/重开与存储扫描 |
| `W003-DAC-04` | 网络临时失败保留真实状态，403/404/未知状态不伪成功 | 故障注入与重试计数 |
| `W003-DAC-05` | 点击后才获取预签名 URL，并从真实 MinIO 下载与 SHA-256 一致的文件 | 网络记录、真实下载与 checksum |
| `W003-DAC-06` | URL 不被缓存/持久化/记录，获取失败可重取，过期后不再请求 | cache/DOM/URL/日志扫描与过期测试 |
| `W003-DAC-07` | viewport、浏览器和键盘矩阵中状态与主操作均可用 | Chrome/Safari、1440/768/375px 与键盘证据 |
