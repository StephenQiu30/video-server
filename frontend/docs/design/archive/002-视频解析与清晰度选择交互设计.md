## 1. 页面结构

`/download` 由三个纵向区域组成：

1. 输入卡：可见标签“视频链接”、单行 URL 输入、“解析视频”主按钮和简短合法使用提示。
2. 视频卡：安全缩略图、标题、平台、时长和解析过期时间。
3. 分辨率卡：单选列表、“开始下载”主按钮和必要说明。

首屏直接聚焦主任务，不展示营销大屏、功能宫格、站点 Logo 墙、历史或无关导航。

## 2. 用户流程

1. 用户粘贴一个 HTTP(S) 页面链接并提交。
2. 表单进入 inspecting，禁用重复提交但保留输入。
3. 成功后展示视频与服务端排序后的格式，默认选择第一项。
4. 用户确认格式并创建任务；成功后跳转 `/downloads/:jobId`。
5. 解析结果 15 分钟到期后禁用创建，要求重新解析。

输入新链接或重新解析时清空旧视频、格式、选择和旧错误。浏览器只做基本 URL 校验；服务端是支持性与安全判断的最终来源。

## 3. 分辨率选项

每项显示：

- `label`（如 1080p）、container、FPS。
- 估算大小；null 显示“大小未知”，不显示 0。
- `requires_merge=true` 时显示“将自动合并音视频”。

不显示 source/format/provider ID、selector、codec 调试信息、媒体直链、只有视频或只有音频的原始流。format ID 只随创建请求发送。

## 4. 页面状态

`idle → inspecting → inspected | inspect_failed`，另有 inspected 下的 `expired` 判断。

- idle：只有输入与说明。
- inspecting：按钮 loading，文案“正在解析视频”。
- inspected：显示摘要、格式和创建按钮。
- inspect_failed：保留输入，在输入卡内显示问题与恢复动作。
- expired：保留摘要供解释，禁用创建并提供“重新解析”。

不使用 Mock 数据或客户端猜测显示“解析成功”。未知/缺失响应字段进入安全错误状态。

## 5. 错误与无障碍

- 空值、非 HTTP(S) 和明显非法 URL 就地显示；服务端地址禁止、不支持、DRM、需登录、超限和超时使用 Problem `detail`。
- 错误不得回显完整 URL query、内部 code 之外的调试信息或上游响应。
- URL 输入和 RadioGroup 有可见 label；键盘可提交、切换格式和启动下载。
- loading、error、expired 不能只依赖图标/颜色；动态状态用非打断式 live region。

## 6. Design Acceptance Criteria

| 编号 | 必须证明 | 实现后证据 |
| --- | --- | --- |
| `W002-DAC-01` | 空值/非法协议在前端阻止，合法 URL 只提交一次且 Cookie 正确携带 | 表单参数测试与网络记录 |
| `W002-DAC-02` | 五种页面状态互斥，解析新链接无旧结果残留或伪成功 | 状态矩阵测试和截图 |
| `W002-DAC-03` | 真实服务端摘要、排序、默认项、未知大小和合并提示准确展示 | 真实 API 与 DOM 断言 |
| `W002-DAC-04` | 15 分钟到期后不能创建，重新解析得到新 source/format | 可控时间测试与请求记录 |
| `W002-DAC-05` | 创建 payload 只有 3 个契约字段，重复点击幂等且成功路由正确 | mutation、请求计数与路由测试 |
| `W002-DAC-06` | 底层 selector、媒体直链、完整 URL 和非 MVP 能力不展示或持久化 | DOM/存储/网络/源码扫描 |
| `W002-DAC-07` | 错误矩阵、三种 viewport、Chrome/Safari 和键盘均有正确恢复路径 | 故障注入与浏览器矩阵证据 |
