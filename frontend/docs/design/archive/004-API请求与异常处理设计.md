## 1. 唯一请求体系

- `@umijs/max` Request 是唯一 HTTP client；全局配置位于 `src/app.tsx` 与 `src/requestErrorConfig.ts`。
- `@tanstack/react-query` 管理 inspect/download mutation 与 job query；不把 API 数据复制到 Umi Model。
- 所有 API 请求使用固定 Origin、`credentials: include` 和生成 Service。
- 禁止手写 Axios/fetch client、重复 DTO、裸 URL、`any` 或 Mock fallback。

MinIO 大文件不经过 Request；只有用户点击后，浏览器导航到服务端签发的预签名 URL。

## 2. OpenAPI 生成

契约入口固定分工如下：

- `video-server /docs`：Swagger UI，仅供开发者人工浏览和试调接口。
- `video-server /openapi.json`：OpenAPI 机器契约，是前端代码生成的唯一输入；禁止抓取 `/docs` HTML。
- `src/services/video/`：Umi 生成并提交版本库的唯一 API Service/类型目录；业务代码不得手改或在目录外复制 DTO。

Ant Design Pro 的 `config/config.ts` 启用 `@umijs/max-plugin-openapi`，唯一 `openAPI` 项固定配置为：`schemaPath` 从 `OPENAPI_SCHEMA_URL` 读取、`projectName: 'video'`、`requestLibPath` 引入 `@umijs/max` 的 `request`、`mock: false`。`package.json` 固定配置 `"openapi": "max openapi"`，唯一生成命令为 `npm run openapi`。

生成结果固定 operation 映射：

| 页面动作 | operation |
| --- | --- |
| 解析视频 | `inspectMedia` |
| 创建任务 | `createDownload` |
| 查询任务 | `getDownload` |
| 获取文件地址 | `createDownloadUrl` |

schema 无法读取、operation ID 缺失/重复或产生不兼容类型时，生成/类型/契约检查必须失败，并先更新 Design；页面不得用兼容 mapper 隐藏缺失字段。后端契约变化与重新生成的 Service 必须在同一变更中提交；连续执行两次 `npm run openapi` 后，`src/services/video/` 必须零 diff。

## 3. Mutation 与 Query

- inspect/create/createDownloadUrl 是 mutation，不自动重放 POST。
- 创建任务 body 中 `client_request_id` 在一次用户动作内稳定，重试同一动作仍使用原值。
- job query key 为 `['download', jobId]`；仅 queued/running 启用 2 秒刷新。
- GET 只对超时/断网/5xx 有限重试；403/404/410/422 不重试。
- 请求取消或新 inspect 返回时，不允许旧响应覆盖新状态。

## 4. Problem Details

错误以 `application/problem+json` 进入唯一转换器，UI 只消费 `status/code/title/detail`：

- 表单校验：字段附近显示。
- 可恢复业务问题：当前 Card/Result 显示 detail 与明确动作。
- 连接问题：保留最后数据，显示“连接异常，请重试”。
- 未知 5xx：全局 notification，不展示堆栈、原始响应或 URL。

不得假设 HTTP 200 内还有业务 code；不得解析已删除的 `code/message/data` envelope。

## 5. Cookie、CSRF 与隐私

- HttpOnly `video_session` 由浏览器管理，前端不读取、不复制、不保存。
- 所有 POST 从同站发起；服务端 Origin 拒绝时按安全错误处理，不尝试放宽 CORS。
- 错误上报过滤 request body、视频 URL、Cookie、响应中的预签名 URL和标题。
- source/format/job ID 仅在必要 payload/path 使用；source/format ID 不进入路由。

## 6. Design Acceptance Criteria

| 编号 | 必须证明 | 实现后证据 |
| --- | --- | --- |
| `W004-DAC-01` | `npm run openapi` 经 `max openapi` 从环境指定的 `/openapi.json` 生成并提交 `src/services/video/`，连续生成零 diff | 插件配置、脚本、schema 来源、生成文件与 git diff |

| `W004-DAC-04` | mutation 不自动重放，幂等键稳定；GET 重试和轮询规则准确 | Fake Timer、请求计数与故障注入 |
| `W004-DAC-05` | Cookie、body、URL、标题、预签名地址不进入日志/上报/存储 | 浏览器存储、日志和网络扫描 |
| `W004-DAC-06` | Server/MinIO 不可用时显示真实故障，不使用 Mock 伪装成功 | 真实依赖停启与页面证据 |
