## 1. Web 边界

Web 只提供一个连续闭环：粘贴一个公开视频链接、解析、选择分辨率、创建任务、查看状态、获取文件。

MVP 不显示账号、任务列表、永久历史、播放列表、批量、字幕、音频下载、AI、站点配置、Cookie/Header/代理、底层 selector 或 MinIO 管理能力。浏览器不直接调用 yt-dlp、FFmpeg、RabbitMQ 或 MinIO SDK。

## 2. 开源复用决策

| 项目 | 复用方式 | 决策 |
| --- | --- | --- |
| [Ant Design Pro](https://github.com/ant-design/ant-design-pro) | React/TypeScript/Umi/Ant Design 的 MIT 官方脚手架和页面规范 | 唯一初始化来源；实施时锁定官方 tag/commit，在临时目录运行 `npm run simple` 后移入当前仓库，清理 Demo，不从空项目或其他脚手架搭建 |
| [Pro Components](https://github.com/ant-design/pro-components) | 表单、卡片、描述列表等成熟组件 | 优先组合官方组件，只为业务状态写薄组件 |
| [FastAPI Full Stack Template](https://github.com/fastapi/full-stack-fastapi-template) | OpenAPI 生成客户端、React Query、E2E 的成熟惯例 | 参考契约/测试做法，不引入其账号、邮件或重复前端 |

## 3. 技术栈

Web 技术栈不存在候选项：固定使用 Ant Design Pro v6 simple、React、TypeScript、Umi Max、Ant Design、React Query 与 OpenAPI 生成 Service。服务端数据库固定为 PostgreSQL、消息队列固定为 RabbitMQ、对象存储固定为 MinIO；Web 不提供切换入口。

| 领域 | 确定选型 |
| --- | --- |
| 框架 | Ant Design Pro v6 simple、React 19、TypeScript、Umi Max 4 |
| UI | Ant Design 6、Pro Components、Ant Design Token |
| API | FastAPI OpenAPI + `@umijs/max-plugin-openapi` + `@umijs/max` Request；统一执行 `npm run openapi`（`max openapi`）生成 Service |
| 服务端状态 | `@tanstack/react-query`；任务轮询和 mutation 的唯一缓存 |
| 客户端状态 | React 本地状态；MVP 不引入 Redux/Zustand/DVA/Pinia |
| 质量 | Biome、TypeScript、Vitest、Testing Library、Playwright |
| 包管理 | npm 与 `package-lock.json` |

请求链固定为：`Page → feature hook → generated Service → Umi Request → video-server`。FastAPI `/docs` 是供人审阅和调试的 Swagger UI，`/openapi.json` 才是 Umi 代码生成的机器契约；前端不安装或内嵌第二套 Swagger UI。

`config/config.ts` 必须启用 `@umijs/max-plugin-openapi`，并在唯一的 `openAPI` 配置中定义：`schemaPath` 读取 `OPENAPI_SCHEMA_URL`、`projectName: 'video'`、`requestLibPath` 使用 `@umijs/max` 的 `request`、`mock: false`。`package.json` 固定提供 `"openapi": "max openapi"`。生成目录只读并提交版本库；页面不手写 URL、DTO、API 文件或第二个 HTTP Client。

## 4. 路由和页面

| 路由 | 责任 | 菜单 |
| --- | --- | --- |
| `/` | 重定向 `/download` | 否 |
| `/download` | 链接解析、视频摘要和分辨率选择 | 是，“视频下载” |
| `/downloads/:jobId` | 单任务状态与文件获取 | 否 |
| `*` | 404 | 否 |

不创建 Dashboard、登录、个人中心、管理菜单或空白占位页。URL 只含随机 job ID，不含原始视频 URL、source ID、format ID 或 MinIO 地址。

## 5. 未来源码目录

当前只定义结构，不创建目录或源码：

```text
video-web/
├─ config/{config.ts,routes.ts,proxy.ts}
├─ src/
│  ├─ app.tsx
│  ├─ requestErrorConfig.ts
│  ├─ pages/
│  │  ├─ Download/{index.tsx,index.less,components/MediaSummary.tsx,components/FormatList.tsx,hooks.ts}
│  │  ├─ DownloadJob/{index.tsx,index.less,components/JobStatus.tsx,hooks.ts}
│  │  └─ 404.tsx
│  ├─ services/video/{typings.d.ts,*.ts}  # Umi OpenAPI 自动生成
│  ├─ components/LegalNotice.tsx
│  └─ utils/{format.ts,time.ts}
├─ tests/{unit,e2e}/
├─ .env.example
```

`src/services/video/` 由真实 OpenAPI 生成，不手改。功能私有组件和 hook 与页面同目录；只有两页都使用且与业务无关的能力才能进入全局 `components/utils`。

## 6. 全局体验

- 桌面内容最大宽度 1000px；768px 以下单列；375px 宽度主操作仍完整可见。
- 每个异步动作只有一个主按钮和明确 loading/disabled 原因，不依赖颜色表达状态。
- 表单、Radio、进度和动态提示有可见标签、键盘操作、焦点与辅助技术语义。
- 页面始终显示“仅下载你有权使用的公开内容”；不使用“支持所有网站”等绝对文案。
- 刷新任务页以服务端状态恢复，不把任务、URL 或预签名地址放 localStorage。

## 7. 安全边界

- 所有 API 请求同站携带 HttpOnly 匿名会话 Cookie；JS 不读取或复制 Cookie。
- 标题、错误和文件名按普通文本渲染，禁止 `dangerouslySetInnerHTML`。
- 预签名 URL 只在用户点击后请求，立即用带 `referrerPolicy=no-referrer` 的链接导航，不缓存、不记录。
- `VIDEO_API_BASE_URL`、`VIDEO_API_PROXY_TARGET`、`OPENAPI_SCHEMA_URL` 由根目录 `.env`/同名环境变量提供；`.env.example` 只含非敏感示例，源码和镜像不得写死地址。
- 生产 API Origin 由部署固定；不提供用户切换 Endpoint、Bucket 或代理的界面，前端环境变量不得包含 Secret。

## 8. Design Acceptance Criteria

| 编号 | 必须证明 | 实现后证据 |
| --- | --- | --- |
| `W001-DAC-01` | 工程来自锁定的 Ant Design Pro 官方 tag/commit，执行官方 `npm run simple` 后形成唯一基线且依赖可重复安装 | 模板 tag/commit、初始化记录、`npm ci`、lockfile 与依赖树 |
| `W001-DAC-02` | 只有本文三条正式路由、一个请求体系和一个服务端状态缓存 | 路由/依赖/源码扫描与页面测试 |
| `W001-DAC-03` | Umi 从 `/openapi.json` 生成 `src/services/video/` 且重复生成零手工差异，无手写 API/DTO/URL，也无 AI/账号/字幕/批量等越界页面 | `npm run openapi`、生成 diff、源码扫描和构建检查 |
| `W001-DAC-04` | 1440/768/375px、Chrome/Safari、键盘主流程无阻断或横向溢出 | 浏览器矩阵截图/录屏与控制台记录 |
| `W001-DAC-05` | URL、Cookie、预签名地址和底层 selector 不进入浏览器持久存储、路由或错误上报 | 存储、URL、网络与日志扫描 |
| `W001-DAC-06` | 实现严格使用本文 Web 技术栈，只消费 FastAPI/OpenAPI 与 MinIO 预签名 URL，不出现基础设施选择界面 | 依赖、配置、路由和源码扫描 |
| `W001-DAC-07` | API、开发代理和 OpenAPI schema 地址只来自 `.env`/环境变量，源码、构建配置和镜像无硬编码 Endpoint 或 Secret | 配置缺失/覆盖测试、`.env.example` 对照和 Secret 扫描 |
