## 4.1 实际执行证据与结论

- 使用真实容器 `/openapi.json` 连续执行两次 `npm run openapi`，生成目录哈希零差异；生成文件位于 `src/services/video/`，未手写第二份 DTO/API。
- `npm test -- --run`：退出码 0，8 个测试文件/42 个测试通过；`npm run test:coverage` 退出码 0（Statements/Lines 99.50%、Branches 93.24%、Functions 96.07%）；`npm run lint`、`npm run format:check`、`npm run typecheck`、`npm run build` 均退出码 0。生成 Service 使用 Umi Request，适配层通过 `credentials: include`。
- 未提供 `OPENAPI_SCHEMA_URL` 时，`npm run dev` 可在端口 8000 正常启动；配置回归测试覆盖 schema 可选和代理前缀保留，避免 Umi 启动崩溃或将 `/api/v1/...` 错发为 `/v1/...`。
- 未提供 `OPENAPI_SCHEMA_URL` 时直接执行 `npm run openapi` 会以退出码 1 结束，并报告 `Invalid command openapi, it's not registered.`；这能阻止无 schema 的静默生成，但仍需在真实 schema 环境复核连续生成零 diff。
- Plan 预期全局异常配置位于 `src/requestErrorConfig.ts`，当前实现实际集中在 `src/utils/problem.ts` 并由 `src/app.tsx` 接入。行为测试已覆盖主要映射，但文件边界与冻结 Plan 不一致，须在 Acceptance 前完成实现或文档基线对齐；`W004-T03` 当前不得标记为 `passed`。
- 真实临时 Compose（API `http://localhost:19090`）与 Chrome 浏览器联调：`VIDEO_API_PROXY_TARGET=http://localhost:19090 npm run dev` 后，`POST /api/v1/media/inspect` 的代理目标记录为 `http://localhost:19090/api/v1/media/inspect`，服务端返回 `403 application/problem+json`，页面展示 `Origin Forbidden` 与“重新解析”恢复动作；375/768/1440 视口均完成页面快照，浏览器 errors 为空。
- JSDOM 交互测试覆盖 Problem Details 归一化、瞬态/终态错误分类、请求计数、幂等 payload、生成 Service credentials、GET/Mutation 错误和临时地址安全导航。
- video-server Acceptance 004 当前为 `Blocked`；Server/MinIO 停启故障恢复、完整请求错误矩阵、浏览器网络/敏感信息扫描及上述文件边界对齐尚未完成，故 W004 强制项与阶段结论为 `Blocked`。
