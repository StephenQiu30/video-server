## 1. 用户价值

用户粘贴一个公开视频页面链接后，应看到真实视频摘要和可理解的清晰度选项，并能在解析有效期内创建唯一下载任务，而无需理解 format ID 或媒体流。

## 2. 核心流程

1. `/download` 首屏显示可见标签的 URL 输入、解析按钮和合法使用提示。
2. 合法 URL 只提交一次；解析期间保留输入并禁止重复提交。
3. 成功后展示标题、平台、缩略图、时长和到期时间。
4. 展示服务端排序的清晰度，默认选择第一项。
5. 用户创建任务后跳转 `/downloads/:jobId`；到期后必须重新解析。

## 3. 展示与状态规则

- 页面状态固定为 idle、inspecting、inspected、inspect_failed，以及 inspected 下的 expired。
- 新链接或重新解析必须清除旧摘要、格式、选择和错误。
- 每个选项显示 label、container、FPS、估算大小和自动合并提示；未知大小显示“未知”。
- 不显示 provider ID、selector、codec 调试、媒体直链或原始音视频流。
- 浏览器只做基础输入校验；服务端是支持性、安全性和错误分类的最终来源。

## 4. Product Acceptance Criteria

| 编号 | 验收行为 |
| --- | --- |
| `W002-AC-01` | 空值/非法协议在前端阻止，合法 URL 只提交一次且携带匿名 Cookie |
| `W002-AC-02` | 五种页面状态互斥，新解析没有旧结果残留或伪成功 |
| `W002-AC-03` | 真实摘要、服务端排序、默认项、未知大小和合并提示准确展示 |
| `W002-AC-04` | 解析到期后不能创建任务，重新解析使用新的 source/format |
| `W002-AC-05` | 创建请求只有契约字段，重复点击不重复创建，成功路由正确 |
| `W002-AC-06` | selector、媒体直链、完整 URL 和非 MVP 能力不展示、不持久化 |
| `W002-AC-07` | 全错误矩阵、三种 viewport、Chrome/Safari 和键盘均有清楚恢复动作 |

## 5. 非目标

不显示支持平台名单、下载历史、批量输入、Cookie/Header/代理、字幕/音频选项或可编辑下载参数。
