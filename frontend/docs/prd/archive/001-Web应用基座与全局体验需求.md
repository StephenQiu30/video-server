## 1. 用户价值

用户打开 Web 后应直接进入“粘贴链接并下载”的单一任务，不被 Dashboard、账号、营销内容或基础设施配置干扰。页面在桌面和手机上都可理解、可操作且不会保存敏感下载信息。

## 2. 必须能力

1. 工程必须从锁定 tag/commit 的 Ant Design Pro 官方仓库初始化，并执行官方 `npm run simple` 形成唯一脚手架；不得从空 React 项目、Vite 或其他脚手架重新搭建，依赖必须可重复安装。
2. 正式路由只有 `/download`、`/downloads/:jobId`、根重定向和 404。
3. 只使用 React、TypeScript、Umi Max、Ant Design、React Query 和生成 Service。
4. 全局布局、合法使用提示、加载/错误反馈、响应式和键盘焦点保持一致。
5. 标题、错误和文件名按普通文本处理；不得持久化 URL、Cookie、selector 或预签名地址。
6. Web 只调用 FastAPI/OpenAPI 和预签名 URL，不暴露 PostgreSQL、RabbitMQ、MinIO 管理或切换入口。
7. API、开发代理和 OpenAPI schema 地址由 `.env`/环境变量提供；缺失或非法配置在启动/构建阶段失败。

## 3. 明确不做

- 不提供登录、用户中心、Dashboard、任务列表、历史、支付、主题系统或多语言。
- 不提供 AI、字幕、播放列表、批量、音频、预览、编辑或平台 Logo 墙。
- 不引入 Redux、Zustand、DVA、第二 HTTP client、自建组件库或第二套构建工具。

## 4. 全局体验规则

- 每个步骤只有一个主操作，loading 时说明原因并防止重复操作。
- 1440、768、375px 均无横向溢出；Chrome、Safari 和键盘可完成主流程。
- 动态状态具有文本和辅助技术语义，不只依赖颜色或图标。
- 页面持续提示“仅下载你有权使用的公开内容”，不承诺支持全部网站。

## 5. Product Acceptance Criteria

| 编号 | 验收行为 |
| --- | --- |
| `W001-AC-01` | 能追溯 Ant Design Pro 官方 tag/commit 和 `npm run simple` 初始化记录，`package-lock.json` 可在冷环境重复安装和构建 |
| `W001-AC-02` | 应用只有冻结路由、一个请求体系和一个 React Query 服务端状态缓存 |
| `W001-AC-03` | 目录、页面和依赖中不存在 Demo、账号、AI、字幕、批量或其他非 MVP 能力 |
| `W001-AC-04` | 1440/768/375px、Chrome/Safari、键盘和辅助技术均可使用主流程 |
| `W001-AC-05` | URL、Cookie、selector、预签名地址和不可信标题不进入持久存储、路由或错误上报 |
| `W001-AC-06` | Web 只使用冻结技术栈、生成 Service 与 MinIO URL，不出现基础设施选择或第二套 API/状态体系 |
| `W001-AC-07` | API/代理/schema 地址可由环境覆盖，源码、构建配置、镜像和日志中没有硬编码 Endpoint 或 Secret |

## 6. 冻结决策

1. 使用 Ant Design Pro 官方脚手架：锁定 tag/commit，在临时目录初始化并执行 `npm run simple`，再移入当前 `video-web` 仓库；不保留模板自身 `.git`，不自行从空白搭建 React 工程。
2. npm 与 `package-lock.json` 是唯一包管理方案。
3. 本 PRD 通过只表示可进入 Plan，不表示已实现。
