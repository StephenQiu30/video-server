## 1. 用户价值

所有页面应以同一种方式调用服务端、解释错误和恢复状态。服务端契约变化必须在生成或类型检查阶段暴露，不能让用户遇到静默兼容或 Mock 伪成功。

## 2. 唯一请求体系

- `@umijs/max` Request 是唯一 HTTP client，全部请求经生成 Service。
- React Query 是唯一服务端状态缓存；不复制到 Umi Model 或自建 store。
- inspect/create/createDownloadUrl 是 mutation，不自动重放；GET 只按冻结规则有限重试。
- `client_request_id` 在一次用户动作内稳定；请求取消和并发 inspect 不允许旧响应覆盖新状态。

## 3. 契约与错误

- `/docs` Swagger UI 只用于人工查看/试调，Umi 不读取其 HTML；`/openapi.json` 是代码生成的唯一机器契约。
- Ant Design Pro 通过 `@umijs/max-plugin-openapi` 和 `npm run openapi`（`max openapi`）从真实 OpenAPI 生成四个 operation 与类型到 `src/services/video/`；生成目录只读并提交版本库。
- 业务页面禁止手写 API 文件、URL、DTO、Axios/fetch 封装或 Mock Service；契约变化必须重新生成并通过类型检查。
- 只消费真实 HTTP 状态和 Problem Details `status/code/title/detail`，不解析旧 envelope。
- 表单问题就地显示，可恢复错误留在当前卡片，连接错误保留最后状态，未知 5xx 不展示内部信息。
- Server/MinIO 不可用时展示真实故障，不使用 Mock fallback。

## 4. 隐私与安全

- 请求携带 HttpOnly Cookie，前端不读取、复制或保存。
- API Origin、开发代理和 OpenAPI schema 地址由 `.env`/环境变量确定，产品不提供 Endpoint/Bucket/代理切换。
- 错误上报过滤 body、视频 URL、Cookie、标题和预签名 URL。

## 5. Product Acceptance Criteria

| 编号 | 验收行为 |
| --- | --- |
| `W004-AC-01` | `npm run openapi` 从环境指定的 `/openapi.json` 生成并提交 `src/services/video/`，连续生成两次零 diff |
| `W004-AC-02` | `/docs` 可供人工审阅但不参与生成；页面只经生成 Service、Umi Request 和 React Query 调用 API，无手写 API、第二 client/DTO/URL/`any` |
| `W004-AC-03` | credentials、四个 operation、HTTP 状态和 Problem Details 映射准确 |
| `W004-AC-04` | mutation 不自动重放，幂等键稳定，GET 重试/轮询和请求竞态符合规则 |
| `W004-AC-05` | Cookie、body、URL、标题和预签名地址不进入日志、上报或持久存储 |
| `W004-AC-06` | Server/MinIO 真实故障有正确恢复行为且没有 Mock 伪成功 |

## 6. 非目标

不建立 BFF、GraphQL、第二 Axios/fetch client、前端内嵌 Swagger UI、WebSocket/SSE、旧 DTO 兼容层或离线下载能力。
