## 1. 用户价值

用户进入单任务页面后，需要看到服务端真实排队、处理、成功、失败或过期状态；刷新和短暂断网不能丢失任务。成功时只需点击一次即可从 MinIO 获取经过校验的文件。

## 2. 状态规则

- 视图固定为 loading、queued、running、succeeded、failed、expired 和安全未知态。
- queued 不显示伪进度；running 显示真实 stage，有百分比才显示确定进度。
- succeeded 展示安全文件名、类型、大小、SHA-256、到期时间和唯一下载按钮。
- failed 给出返回重新提交动作；expired 禁止下载；未知状态绝不按成功渲染。

## 3. 轮询与刷新

- 只有 queued/running 每 2 秒轮询；终态、页面隐藏、离线和卸载立即停止。
- 恢复可见或在线后立即查询；临时 GET 失败保留最后真实状态。
- 刷新和前进/后退只依赖 route job ID 与 HttpOnly Cookie，不依赖浏览器持久存储。

## 4. 文件获取

- 用户点击时才请求预签名 URL，期间禁止重复操作。
- 成功后使用 `referrerPolicy=no-referrer` 的临时链接导航，不 Fetch 为 Blob。
- URL 不进入 cache、DOM 长期状态、路由、剪贴板、日志或错误上报。
- 签发失败保留 succeeded 状态以便重取；任务过期后不再请求。

## 5. Product Acceptance Criteria

| 编号 | 验收行为 |
| --- | --- |
| `W003-AC-01` | 所有任务状态和未知值都有唯一、安全且可理解的视图 |
| `W003-AC-02` | 仅活动态轮询，隐藏、离线、终态和卸载停止，恢复后状态准确 |
| `W003-AC-03` | 刷新/重开任务 URL 可由真实 Server+Cookie 恢复且无持久状态依赖 |
| `W003-AC-04` | 网络故障保留真实状态，403/404/未知状态不重试或伪成功 |
| `W003-AC-05` | 点击后才获取 URL，并从真实 MinIO 下载与服务端 SHA-256 一致的文件 |
| `W003-AC-06` | 预签名 URL 不被缓存、持久化或记录，失败可重取且过期后停止 |
| `W003-AC-07` | Chrome/Safari、1440/768/375px、键盘与辅助技术下状态和主操作可用 |

## 6. 非目标

不提供任务列表、取消、暂停、原任务重试、改格式、分享、在线播放或浏览器内大文件缓存。
